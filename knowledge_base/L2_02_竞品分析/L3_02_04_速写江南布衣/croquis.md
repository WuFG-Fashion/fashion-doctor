## 三、会员运营核心逻辑（行业标杆，可直接学）

### RFM+LTV分层体系

```
高价值会员（年消费>5000元）
└─ 34万人
└─ 享：新品优先购 + 专属折扣 + 定制服务

活跃会员（近12个月有消费）
└─ 56万+
└─ 享：积分兑换 + 生日礼 + 活动邀约

沉睡会员（12-24个月未消费）
└─ 重点召回对象
└─ 策略：定向优惠 + 流失原因调研

流失会员（>24个月未消费）
└─ 放弃成本高
└─ 策略：定期触达，不强推
```

### 会员护城河分析

江南布衣会员贡献率 >80% 的含义：
- 极强的抗风险能力（客流下滑时会员复购可支撑）
- 高客单价×高复购率 = 高LTV（生命周期价值）
- **卡宾当前**：会员覆盖率71.3%，但会员GMV贡献率未知

- 卡宾定位"都市时尚"，同样面临运动化冲击
