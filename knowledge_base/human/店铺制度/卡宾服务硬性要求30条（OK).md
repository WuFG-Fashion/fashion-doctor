| 1.面带微笑，亲切热情 |
| 2.使用规范迎宾语，保持声音洪亮愉悦 |
| 3.理解和把握顾客的需求 |
| 4.主动介绍、展示货品，推荐适合的货品 |
| 5.接一招二待三,主动宣传店内活动信息 |

| 7.目测顾客着装尺码的准确性，鼓励顾客成套试穿 |

| 9.使用规范手势，引导协助顾客进行试衣 |
| 10.引领顾客到试衣间后，使用礼貌用语并报小名 |
| 11.清晰顾客试衣件数，及时取出试穿过的衣物 |
| 12.注意及时对试衣间环境进行维护，顾客试穿过的衣物不可随意堆放于卖场 |
| 13.对试衣较多的顾客商品不可抓在手上或搭在肩上,及时收起 |
| 14.试穿后应及时为顾客整理衣物（事先征求顾客的意见) |
| 15.试穿过程中主动讲解产品设计工艺、穿着搭配，宣传品牌文化 |
| 16.顾客试完裤子根据裤长,为顾客提供单膝着地整理服务 |
| 17.与顾客确认改裤长度,告知顾客等候所需时长 |
| 18.顾客试鞋过程中提供单膝着地服务,顾客未站立时导购不可起立. |
| 19.给顾客量裤长时单膝着地,动作流畅自然,不可有小动作. |
| 20.主动给顾客进行成套搭配推介 |
| 21.试穿后再次对顾客进行产品附加推销 |
| 22.专业处理顾客所提出的异议 |
| 23.积极主动跟进销售的整个过程直至完成接待顾客 |
| 24.指引(带领)顾客买单，确保成交 |
| 25.迅速将顾客所购衣物整齐包装,核对购买件数及尺码 |
| 26.告知顾客衣物正确洗涤保养方法及售后服务 |
| 27.登记顾客联系方式，宣传品牌VIP优惠 |
| 28.送顾客至门口，双手递交票据及购物袋 |
| 29.建立有效的顾客电子档案资料，便于品牌VIP拓展 |
| 30.定期对VIP进行电话的回访 |

**卡宾个性服务15点：**

1、推荐服务（手势）

2、顾客坐时服务（休息区体验）

3、手提袋服务 （亲切温馨）

4、领到试衣间 （重视尊贵身份）

5、倒水服务（贴切关心）

6、赞美服务 （让顾客有愉快的心情）

7、改裤服务 （体验专业的操作步骤）

8、回应声（良好的店铺氛围带动）

9、报小名（让顾客记住你，学会推销自己）

10、目光接触（体现真诚、尊重）

11、工作术语的运用（礼貌用语及暗语的规范）

12、试鞋试衣服务（体现专业）

13、买单服务（小饰推销、唱收偿付、VIP登记、温馨提示、节日问候）

14、送客服务（最后的服务体现）

15、招呼声（顾客与工作人员）

**优质的服务五原则：**

1. 最亲切的笑容：只要我站在岗位上，我就能以发自内心的微笑面对顾客与同事;
2. 最动听的声线：我能让声音也微笑起来;
3. 最自然的招呼：我的招呼语多元化，能让客人感觉自然舒服;
4. 最精彩的配搭：有精彩的搭配，才有成功的推动力;
5. 最利落的动作：我的勤快是打动顾客的唯一法宝，3分钟之内我就能为顾客找到他想要的货品;

**卡宾终端服务准则：**（无论顾客买还是不买服务始终如一）

1、不因为顾客的不购买而露出失望或反感的表情;

2、不因为顾客的大量购买而露出兴奋或狂喜的表情 ;
