1. **主要店铺表现指标管理启示：**

**销售数据**

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **销售额**  总营业销售额 | * 了解生意走势 | 每天定期跟进,每周总结  调整促销及推广活动 |
| * 为员工订立目标 | 激励员工,鼓励员工冲上更高销售额 |
| * 比较各分店销售情况 | 比较各分店情况,评估店铺主管员工及货品的组合 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **客单件**  （销售件数÷交易单数） | * 了解货品搭配销售情况 | 比率低于1.5者为低,应立即提升员工的附加销售力度 |
| * 掌握客人的消费心理 | 检查陈列是否与货品搭配相符, 适当更换货品位置,令相互可搭配产品放在邻近位置 |
| * 了解员工附加销售技巧和服装搭配技巧 | 检讨促销政策,鼓励多买 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **客单价**  (销售额÷交易单数) | * 寻找消费者承受能力 | 增加以平均单价为主的产品数量 |
| * 比较货品与客人购买能力是否相符 | 将高于平均单价的产品特殊陈列 |
| * 以平均单价作为货品价位的参考数 | 以低于平均单价的产品吸引实用型顾客 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **同比**  同比=（今年本期金额－去年同期金额）÷去年同期金额×100% | 是指当期与去年同期相比较的[增长率](http://baike.baidu.com/view/1368314.htm)； | **.** 本期销售目标：需同时借鉴去年同期销售的水平及预算同比增长率来制定总目标。 |
| 同比增长是指和上年同一时期、上一年度或历史相比的增长（幅度）； | 整体反应店铺的经营水平及人员贡献率； |
| 表明这种现象在较长时期内总的发展速度； | 判断商圈销售额是否呈正常增长状态。 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **环比**  (本月同期销售-上月同期销售）÷上月同期销售 ×100%  改为“环比” | * 对比上个月，本月的销售增长率 | 反映销售业绩变化情况 |
| * 表明一个店铺销售增长趋势 | 整体反应店铺的经营水平及人员贡献率； |
| 判断商圈销售额是否呈正常增长状态 |

**货品数据:**

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **售罄率**  （一周期内销售货品零售金额÷总进货零售吊牌额×100%） | **.**关注一周期内货品品类销售数量及进度； | 售謦率计算期间通常为一周，一个月或一个季； |
| 新品上货的市场反应及是否达到销售贡献占比； | 售罄率反映了产品的销售速度——是否受顾客欢迎； |
| 密切关注商圈内货品的销售情况，作出及时的信息反馈，以便于货品管控作出相应的调整。 | 充分关注新货上市的售罄率，反应货品的运营水平及货品监管问题。 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **类别销售占比**  当月中类销售金额/当月总销售额 | 了解店铺各品类销售占比，关注核心品类销售情况 | 分析店铺核心品类销售，加强销售占比低品类销售，做好库存预警 |
| 了解该店/该区消费者取向 | 将销售低品类在店内加强促销 |
| 比较本店与正常销售比例，得知本店销售的特性 | 将慢流品类展示，加强配搭 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **畅销10款**  **滞销5款** | * 得知前10名热卖产品，了解畅销原因 | 检查前10名产品库存，订立库存安全线，准备补货 |
| 了解畅销产品情况，准备替代品 |
| * 了解后五名滞销原因，进行相应的促销手段 | 增强员工对滞销货品的销售技巧 |
| 安排滞销货品促销 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **月库销比**  （库存件数÷ 月销售件数）  预估售清库存所需周数 | * 检讨货品销售情况 | 分析销售进度是否正常（如：单店库销比与区域库销比对照） |
| 改善货品展示 |
| * 检讨畅、滞销产品 | 辅导提高员工销售技巧 |
| 对照产品生命周期，对于滞销品及时做出调整 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **货品齐码率**  （店铺现有SKU的齐码数量÷店铺总SKU数量 ）×100% | 1. 货品齐码率直接反应出店铺的有效库存； | 密切关注及分析店铺货品的有效库存情况； |
| 2. 常规当季的货品的齐码率在70%为正常库存； | 上装类连续,3个尺码为齐码,裤装类连续5个尺码为齐码； |
| 3、有效库存是判断一间店铺货品库存的最佳数据。 | 并非自我感觉意识的“感觉误区”判断断码现象。 |

**店铺经营:**

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **坪效**  （每天每平方米的销售额） | * 分析店铺面积的生产力 | 确认店铺生产力而调整策略  1、是否需要增大店铺面积  2、店内存货是否足够  3、检讨生产力低的原因  —员工技巧  —陈列不当  —种类太少  —配搭不齐 |
| * 确认店内存货数量与销售的对比 |
| * 深入了解店铺销售真实情况 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **人效**  （每天每人的销售额） | * 检讨员工产品知识及销售技巧 | 实地教练员工提高产品姿势与销售技巧 |
| * 检讨员工与货品匹配 | 重新根据员工最擅长销售的产品安排销售区域 |
| * 检讨员工排班合理性 | 旺场时段均须安排销售能力强的同事 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **折扣率**  折扣率＝销售金额/吊牌基恩\*100% | 反映给客户让利情况 | 提升折扣率，增加毛利 |
| 加强当季新品销售，提升折扣率 |
| 新旧货店铺区分，引导顾客消费新品 |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **VIP占比**  VIP占比＝VIP消费金额/总销售金额\*100% | 检验店铺老顾客消费能力 | 提升老VIP消费能力，开发新VIP； |
| 反映销售业绩增长情况和市场规模变化 | 维护VIP关系，增加回访，提升进店率 |
|  |  |

|  |  |  |
| --- | --- | --- |
| 主要店铺|表现指标 | 启示 | 行动 |
| **货品流失率**  （失货吊牌价÷ 期间销售额×100%） | * 检讨货品丢失情况 | 检查店内盲点/经常丢失货品的地方/采取相应措施（鱼线、对小货品多个货品一起包装等） |
| * 检讨货品损耗 | 改善货品展示方式，改善仓库保管情况 |
| * 检讨员工防盗意识 | 提高经常丢失货品的员工的防盗意识 |
