## 四、关键计算口径

### 1. 季中售罄率
```
= 销售吊牌额 / (销售吊牌额 + 库存吊牌额) × 100%
```
- 季中：到货后75天（男装）/ 60天（女装）以内
- 与同期对比时，需剔除年份因素

### 2. 季末售罄率
```
= 到货75/60天后累计销售吊牌额 / 到货总量 × 100%
```

### 3. 未动销库存占比
```
= 当年当季统计周期内零销售的库存量 / 当年当季总库存量 × 100%
```
- **必须限定当年当季**，否则旧货稀释分母
- 服装行业标准口径：90天

### 4. 存货周转天数
```
= 平均库存量 × 365 / 年销售量
```

### 5. VIP判断
```
member_id IS NOT NULL AND member_id != ''
```

### 6. 连带率
```
= 销售件数 / 销售订单数
```

### 7. 客单价
```
= 销售金额 / 订单数（或销售笔数）
```

## 七、行业对比数据（2026年5月更新）

### 7.1 服装零售行业周转效率基准

| 品类类型 | 平均周转天数 | 国际优秀水平 | 国内头部水平 |
|----------|-------------|-------------|-------------|
| 传统服装零售 | **180天以上** | — | — |
| **国际快时尚**（ZARA/H&M/优衣库） | — | **60-90天** | — |
| 卡宾实测 | **55-83天** | — | 接近快时尚 |
| 太平鸟 | **192天** | — | 🔴 远超警戒线 |

> 数据来源：《2025至2030服装零售库存周转效率提升与全渠道融合研究》（2025-10），传统服装企业平均库存周转天数高达180天以上，远高于国际快时尚品牌60-90天的水平

### 7.2 关键发现

1. **行业整体承压**：传统服装零售180天+周转是常态
2. **快时尚优势明显**：ZARA/H&M/优衣库维持60-90天高效周转
3. **卡宾相对领先**：55-83天已接近快时尚水平，但未动销率65-80%仍需警惕
4. **太平鸟是反面教材**：192天周转说明期货模式风险极大

### 7.3 2026年行业KPI关注方向

- **售罄率**：从利润到售罄率成为时尚行业核心指标（FashionUnited 2025-09）
- **库销比**：结合售罄率的综合评估维度
- **坪效**：单店效率核心指标
- **连带率**：衡量导购能力的关键
- **毛利率**：折扣管理能力的直接体现

## 八、2026年Q2 KPI方法论更新（2026-05-11采集）

### [2026服装商品数据分析新范式]（来源：酷番云，日期：2026-05-10，可信度：中高）
- **核心转变**：从单纯的"销量复盘"转向**"全链路动态预测"**
- 三大驱动力：
  1. **AI驱动的需求预测模型** → 从设计端到售罄全程数据化
  2. **实时库存周转监控** → 不再依赖月度/季度静态报告
  3. **用户生命周期价值(LTV)** → 从单次交易视角转向长期价值
- **关键结论**：传统KPI（售罄率/周转天数）仍是基础，但必须叠加**预测性指标**

### [时尚行业重要指标详解]（来源：FashionUnited，日期：2025-09-01，可信度：高）
- 售罄率<65% = 库存大量积压 + 大幅打折导致亏损
- 售罄率与产品价位基本无关（高价位也可高售罄）
- **通过售罄研究指导定补货决策**
- 行业标准：服装销售生命周期3个月（鞋子5个月），3个月内售罄<60%大致判断为滞销

### [简道云服装库存管理核心指标]（来源：简道云，日期：2025-12-22，可信度：中高）
- 关键指标体系：**周转率 / 库龄 / GMROI(商品毛利回报) / 售罄率 / 缺货率 / MAPE(预测准确率)**
- GMROI = 毛利 ÷ 平均库存成本 → 衡量每投入1元库存能产生多少毛利
- MAPE用于衡量需求预测精度，越低越好

### [2025服装行业利润下降27%的根因分析]（来源：知乎/中国服装协会，日期：**2026-03-05**，可信度：**高**）
- **核心根因**：
  1. **研发端**：款式开发靠模仿，版型调整凭感觉
  2. **供应链**：一个款改版需三天，等改好热度已过
  3. **销售端**：线上价格战+退货率高，线下客流持续下滑
  4. **库存端**：期货铺货模式导致库存积压→打折清仓→毛利恶化
- **行业判断**：传统期货制正在被柔性快反模式全面替代
- **对卡宾启示**：卡宾当前55-83天周转已属行业领先，核心挑战在未动销率而非周转速度
