# 2026-06-15 快反供应链与OTB协同更新

> **同步自**: wiki/sources/ → wiki/concepts/动态OTB管理
> **元页面**: [[2026-06-15_武汉女装快反供应链120工厂5件混批]]

## 新增内容摘要

### 快反供应链改变OTB底层逻辑
- 季前订货占比：100% → 25-40%
- 追单门槛：单款百件 → 5件灵活混批
- 追单周期：7-14天 → 天级极速补货
- 滞销处理：被动折扣 → 主动滞销款调剂

### OTB与快反协同公式
```
有效OTB = 传统季初预算 × (1 - 快反可补比例) + 季中滚动预算
```
关键：120+工厂+5件混批使40-60%货品需求可通过季中快反满足

### SKU生命周期管理优化
- 导入期：5件试销→数据验证→快速决策
- 成长期：天级追单→不流失爆款窗口
- 衰退期：滞销款调剂→及时止损
- 周转效率：天天上新+小批量→售罄率动态优化
