# 人工区 / Human Notes

本目录为**人工专属区**：由你（人类）手动编辑的运营手册、复盘、灵感、草稿等。

## 规则
- ✅ 你可以自由新建、编辑、删除本目录下的任何文件。
- 🤖 AI（WorkBuddy / Hermes）**默认仅可读取，禁止写入或修改**本目录内容。
- ✍️ **代笔例外**：你**明确授权**时（如 2026-08-25 授权将桌面《培训课件》《店铺制度》转存至此），AI 可在本目录代笔转存/整理，并遵守下文"代笔规范"。
- 本目录内容不参与自动编译（不会自动生成 wiki 词条），但可被知识库其他页面通过 `[[human/你的笔记]]` 引用关联。

## 子目录（2026-08-25 起，AI 代笔存档）
- `培训课件/` ← 桌面《培训课件》Markdown 原文存档（初级/中级/高级 按原层级）
- `店铺制度/` ← 桌面《店铺制度》Markdown 原文存档
- `*_media/` ← 从课件提取的排版图片附件（供 `![[...]]` 引用）

## 代笔规范（AI 授权写入时）
- 只把**原始资料转存**为 Markdown 存档，不在此做提炼/改写（提炼产物放 `wiki/`）
- 文件名保留源文件语义；表格转 md 表格；不删改你的原始桌面文件
- 提炼后的 wiki 页面用 `sources: human/培训课件/<文件名>` 指向本目录原文

## 用法建议
- 门店运营手册、导购话术模板、复盘笔记 → 直接在此新建 `.md`
- 想沉淀进知识库的内容 → 在 Obsidian 里用双链 `[[...]]` 关联，或交给自动化轮次编译进 `wiki/`
