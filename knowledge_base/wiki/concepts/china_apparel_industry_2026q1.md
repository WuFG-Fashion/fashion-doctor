# 2026Q1中国服装行业运营基准

> **一句话摘要**：2026Q1服装行业内销回暖(+9.4%)但利润承压(-17.76%)，营收利润率仅2.23%、亏损面35.60%、产成品周转9.13次/年——这些是判断企业经营是否跑赢行业的对标基准。

## 对 Fashion Doctor 的意义

1. **营收利润率2.23%** 是对标红线 — 卡宾/竞品利润率低于此为危险信号
2. **产成品周转9.13次/年(≈40天)** — 可对比分析卡宾的库存周转健康度
3. **亏损面35.60%** — 行业中1/3企业亏损，结合卡宾数据判断竞争位次
4. **三费比例11.65%** — 费用率超过此值意味着运营效率低于行业均值
5. **出口"量升价跌"** — 如果卡宾有外贸业务，需关注单价下行风险

### 1-4月关键洞察
1. **利润边际改善但营收恶化** — 利润率从2.23%→2.55%(+0.32pp)，但营收降幅从1.71%→3.42%
2. **内销增速二连降** — Q1: +9.4% → 1-3月: +8.3% → 4月当月: +4.0%，逐月放缓
3. **对美出口逆势暴增** — 累计+6.9%，4月当月+41.8%（单月28.4亿美元）
4. **投资信心跌入谷底** — 固定资产投资-9.3%，较Q1的-4.1%大幅恶化
5. **穿类网上零售增速腰斩** — Q1: +11.6% → 1-4月: +6.8%，放缓4.8pp
