# 售罄率考核基准2026

> **一句话摘要**：2026年服装零售售罄率正式考核标准：服装类30天≥45%/60天≥65%/90天≥80%，鞋类50天≥45%/100天≥65%，由商品管理中心主责，POS+WMS+财务三方数据联动考核。

> **来源**：百度文库《2026服装零售售罄率考核与绩效激励管理制度》(2026年)
> **最后更新**：2026-06-27


## 结论

> **AI 合成洞察（判断 / 推论，非数据复述）**：
>
> 1. **售罄率考核正式标准化**：服装 90 天生命周期、三节点 30 天≥45%/60 天≥65%/90 天≥80%，由商品管理中心主责、POS+WMS+财务三方联动——售罄率从"感觉"变"制度"。
> 2. **本制度阈值高于行业通用基准**（30 天 45% vs 通用 30%）：说明头部品牌在拉高考核线，达标率直接挂钩绩效激励与品控等级。
> 3. **售罄率是商品企划的"结果仪表盘"**：订货会定多少、OTB 怎么分，最终都落在售罄率上，低于阈值就要压缩订单（见 [[服装订货会精准策划]]）。
> 4. **考核口径统一是 RAG 可查的前提**：三方数据源联动避免"各算各的"，让跨店跨品牌售罄率可比（下游详见 [[商品企划体系2026]]）。

## 核心要点

1. **服装标准生命周期 90天**，起始日为 SKU 首单入库日
2. 服装三节点售罄率: 30天≥45% / 60天≥65% / 90天≥80%
3. 鞋类生命周期 150天，两节点: 50天≥45% / 100天≥65%
4. 考核主体商品管理中心，数据POS+WMS双源，财务复核
5. 售罄率达标率直接影响绩效激励与品控等级

### 考核架构

```
商品管理中心 (主责)
    ├── POS 系统 → 实时销售数据
    ├── WMS 仓储系统 → 库存数据
    └── 财务管理中心 → 复核校验
```

### 品控联动
- 售罄率达标率 → 品控等级评定
- 品类售罄偏差 → 波段上货调整
- 季末库存管控 → 绩效激励

## 最新补充（2026-08-07 · Round B）

- **售罄率作为 SKU 退出的判定阈值**：[[2026-08-07_retailnorthstar_SKU合理化五步减法与复杂度五区间]] 给出可执行阈值——**售罄率低于品类均值 15 个百分点**，与"销量后 20%""毛利率低于品类均值"取交集构成退出候选池。这把售罄率从"事后考核指标"变成了"事前决策阈值"。
- **改善幅度基准（区别于绝对目标）**：执行 SKU 合理化后，季末售罄率典型提升 **3–8 个百分点**。注意这是**相对改善量**，与季末售罄率 80% 目标值、70% 优秀值属不同维度，不可混用。

## 2026-08-30 B轮补充（折扣-售罄联动方法论）

> 来源：[[2026-08-30_B_售罄率与折扣毛利管理方法论]]

- **自动降价触发**：第 8 周 STR<40% 启动阶梯 25/40/60% 降价；盈亏平衡 = COGS + 持有成本 + 履约成本（cognira）。
- **折扣侵蚀正价售罄**：深折扣将正价售罄率从 70-75% 拉低至约 50%（eightx），印证"高总售罄靠折扣"牺牲正价效率——本页考核基准须以正价售罄为锚。
- **ST% 公式统一定义**：ST% = Sold ÷ Received；>90% 补货 / 80-90% 强 / 60-80% 健康 / <60% 调查；季末目标 80%（modanomics，与 kb end_season_target 0.8 口径一致）。
