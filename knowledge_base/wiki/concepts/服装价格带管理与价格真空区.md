# 服装价格带管理与价格真空区

> **一句话摘要**：价格带（price band）不是定价结果，而是竞争位置的坐标系。同一价格带里的品牌真正互为对手，跨带品牌即使品类相同也不直接竞争。本页把库内已采集的品牌价格锚点汇成一张可比地图，并定义两个必须区分的概念——**拥挤带**（多品牌贴身竞争、只能靠差异化版型/速度取胜）与**价格真空区**（无人占位、可能是机会也可能是伪需求）。
> **置信度**：第三方数据（多来自媒体/榜单/品牌自宣的客单价与定价区间，非 POS 实测）
> **brand_specific**：false（行业通用方法论；品牌锚点仅作案例）

> ℹ️ **与既有方法论源页的关系（非重复）**：[[2026-08-17_服装价格带管理与价格真空区]]（B轮，`brand_specific: false`）已沉淀**通用方法论层**——渠道价格带观测（正价店 300-500 / 线上 150-300 / 奥莱 <100）、三层价格体系（100-300 / 300-800 / 800+）、真空区识别口径、MO&Co. 垂直渗透案例。本概念页是其**概念 hub 升级**，新增三件在源页中不存在的东西：① 库内竞品的**实际价格锚点地图**；② **拥挤带**这一判别维度（源页只讲真空区与超载区，未讲"多品牌贴身"）；③ **平行渠道使定价上限外生**的约束（源页假设定价权在品牌内部）。两页分工：源页=怎么算，本页=当前谁站在哪、以及定价权是否在自己手里。

## 核心要点
- **价格带定义竞争集**：判断"谁是对手"的第一顺位不是品类、不是渠道、不是风格，而是**客单价所处的带**。同带同品类=直接竞争；同品类跨带=错位共存。
- **渠道内先分层（承接源页）**：同一款在正价店 / 线上 / 奥莱 分属三套带（约 300-500 / 150-300 / <100 元），因此"品牌带位"必须按渠道分别成立，不能用单一数字代表品牌。
- **拥挤带 vs 真空区**：拥挤带里涨价即失客、降价即毁牌，可用杠杆只有版型差异、上新速度、联名溢价；真空区先要证伪"为何无人占位"——多数真空区是需求断层而非机会。
- **平行渠道是价格带的天花板**：当第三方集合店以"国内外同价"平行销售同一品牌，自营/代理渠道的定价上限被外部锁定（见 [[nerdy]] × [[thisisizi8]] 案例）。
- **价格带必须与折扣结构一起看**：吊牌价带 ≠ 成交价带。只记吊牌价会把常年 5 折的品牌与刚性折扣品牌错放同带。
- **本库缺口**：主体品牌 [[peacebird]]、[[cabbeen]] 的分品类价格带数据**尚未入库**，导致对手比对目前只能在竞品之间做，无法把主体放进同一坐标系。

## 方法与规则
1. **建带**：按成交客单价分带（例：<200 / 200-400 / 400-600 / 600-1000 / >1000），而非按吊牌价。
2. **填品牌**：每带填入直接对手 + 自有品牌/子系列，标注品类与风格标签。
3. **测密度**：一带内 ≥4 个同品类同风格品牌即判定为拥挤带。
4. **验真空**：某带无人占位时，先回答三问——需求是否存在？供应链是否支持该成本结构？渠道（商场楼层）是否愿意给点位？三问皆是才算机会。
5. **查天花板**：核查是否存在平行渠道（集合店、代购、跨境电商）以更低价销售同款，若有则该带定价上限外生。
6. **联动折扣**：把带位与折扣深度、售罄率一起看，避免用吊牌价制造虚假带位。

## 结论
1. **在拥挤带里，"差异化"能用的杠杆比想象的少得多，而版型是成本最低的一个**。400-600 元带上 [[chuu]]、[[no_one_else]]、rolarola、W.Management、Subdued 已贴身站满，此时涨价直接掉客、降价直接毁掉品牌溢价，营销投入又被同带对手同步抬高。[[no_one_else]] 选择"无性别 + 身材包容版型"作为差异点，是因为它**不需要更换供应链、不需要重建价格体系，只改版型与陈列逻辑**——这是拥挤带里性价比最高的差异化路径。对国内女装企划的直接含义：先问"我能在不动成本结构的前提下改什么"，再问"我要不要换带"。
2. **价格真空区大多是需求断层，不是无人发现的机会**。空位通常有原因：该价位的消费者要么在上一带买品牌溢价，要么在下一带买性价比，中间带缺乏清晰的购买理由。因此"真空区=机会"这个直觉必须先证伪：**只有当供应链能支撑该带的成本结构、且商场愿意给对应楼层点位时，真空区才是可进入的**。否则进去就是两头不靠——比同带更贵没品牌，比下一带更贵没理由。
3. **平行渠道让"价格带"从内生变量变成外生约束，这是韩系/海外授权品牌在华毛利难改善的结构性原因**。[[thisisizi8]] 这类集合店以国内外同价销售 [[nerdy]] 等品牌，同城消费者可按原价买到，自营/代理渠道的定价上限被外部锁死，而代理商仍要承担关税、租金、库存。**可操作规则：引进海外品牌时必须把"是否允许第三方集合店平行销售"写进授权谈判条款**，否则价格带治理权不在自己手里。
4. **本库最紧的缺口是主体品牌自身的价格带数据未入库**——这使得所有竞品价格带分析都停在"竞品之间互比"，无法回答"太平鸟/卡宾各品类分别站在哪一带、对手是谁"。这个缺口不是采集难度问题（自有 POS 数据完全可得），而是**知识库与自有数据仓库尚未打通**。下一步应从自有数据侧补 `分品类 × 分季 × 成交客单价带` 分布，把主体品牌放进同一坐标系，价格带分析才真正具备决策价值。
