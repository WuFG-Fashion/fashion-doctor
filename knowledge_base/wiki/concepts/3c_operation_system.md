# 3C 经营体系（3C Operation System）

> **一句话摘要**：韦孚咨询（李炳辰创立）面向服饰零售品牌的总部-终端一体化方法论，3C = **商品 × 顾客 × 商业模式**，以商品体系为核心、顾客需求为导向、围绕"七次人货对接"打总部-终端-顾客端到端、构建"商品经营+客资经营+人才育成"三大子系统，实现"顾客增量×商品增量=毛利增量"。
>
> **来源**：搜狐号韦孚咨询 467523956（李炳辰 3C 商品零售体系 2 日课程详单）、534126572（3C 品牌经营方案研究中心）、534107127（基于核心顾客大企划增量方案）、453905487（销售联动订货 3C 经营复盘 7984 字演讲）、461781409（韦孚×安踏 3C 合作）、534521337（疫情下 3C 是什么/怎么嫁接买手快消）、535937705（地素 3C 战略合作 18.7%/+20% 案例）、534829270（艾诺丝雅诗 3C 战略合作）。
>
> **最后更新**：2026-08-25

## 核心要点

- **3C 定义**：3C = **C**ommodity（商品） × **C**ustomer（顾客） × **C**ommercial Mode（商业模式）。三件事围绕"商品转、商品围绕顾客转"的商业模式。
- **核心公式**：**顾客增量 × 商品增量 = 毛利增量**。这是 3C 的根本经济模型，所有动作都奔毛利。
- **核心流程**：**七次人货对接**——品牌定位 → 产品战略 → 设计研发 → 样衣评审 → 订货采买 → 零售渠道 → 顾客。每一次对接都应是毛利的形成，每一次偏离都会形成未来库存。
- **三大子系统**：① 商品经营体系（选/练/卖/价值呈现）② 客资经营体系（新客开发/老客维护）③ 人才育成体系（3C 经营型团队）。
- **业务体制 vs 管理体制**双轨：业务体制保流畅（端到端打通），管理体制算毛利（出多少货挣多少钱）。
- **方法论演化**：销售力体系（2008 最早）→ BMTE 终端零售体系（2014-2016）→ 3C 经营体系（2018 至今，以商品为核心）。
- **行业适用性**：买手品牌、快时尚、快反品牌均可嫁接；3C 不止解决现金流，而是解决品牌核心竞争力。

## 3C 体系全貌（从信息图）

| 板块 | 子模块 | 关键动作 |
|------|--------|----------|
| **调性稳定的产品** | 千店一面 / 千店千面 | 保证品牌调性 / 保证店铺业绩 |
| **盈利的业务体系** | 产品销售 / 客资规模 | 商品经营体系 / 客资经营体系 |
| **持续盈利的管理体系** | 成长内动力 / 战略与实施 | 人才复制体系 / 目标达成体系 |

## 七次人货对接（核心流程）

> 来源：搜狐 467523956 img_5.png 信息图

```
品牌定位 → 产品战略 → 设计研发 → 样衣评审 → 订货采买 → 零售渠道 → 顾客
```

每一次对接都应是"毛利的形成"；每一次偏离都会形成"未来的库存"。**品牌定位**与**顾客**是端到端的两端（虚/实）。

### 各次对接的关键工具

| 环节 | 关键工具/动作 |
|------|----------------|
| 品牌定位 | 创意总监/品牌总监定方向、调性 |
| 产品战略 | 感性工学©（量化美学核心技术）|
| 设计研发 | 风格管理系统、色彩管理系统（量化美学）|
| 样衣评审 | 人货对接 PDCA 复盘体系 |
| 订货采买 | 商品二次企划（科学订货/精准订货）|
| 零售渠道 | 3C 经营会议 1.0、总部铁三角 → 终端 |
| 顾客 | 客资经营体系（新客开发 + 老客维护）|

## 商品经营体系（DAY1 课程详单）

> 来源：搜狐 467523956

### 总部侧：商品选货 + 练货 + 活用

- **商品选货策略的共识与公示**：总部核心主推商品策略 / 库存量 / 生命周期 / 商品流转 / 终端零售联动产品研发 / **通情杆**运作体系
- **练货体系**：商品搭配、呈现商品美感
  - 战略目的：提升自信/美感
  - 战术目的：销售、大单
  - 内容：① 商品搭配 ② 人货对接 ③ 商品解读
- **活用商品策略关键节点**：联动库存 / 锁定顾客 / 惊艳搭配 / 生活状态呈现

### 终端侧：选货 / 练货 / 卖货

- **终端店铺选货体系**：解决库存量大；包容顾客需求；体现聚焦原则；店铺**通情杆**运作
- **终端店铺练货体系**：**集体过款 / 杆挂联动 / 店长质询**；**单练/对练/群练**，重在展示商品美感而**不在 FAB 话术**
- **终端店铺卖货体系**：
  - 销售训练：商品力（人货对接搭配）/ 亲和力（三赞三问）/ 共情力（顾客响应）
  - 商品连单、大单模型
  - 单单复盘 PDCA

### 商品经营体系的价值链

```
顾客使用价值愉悦 ◁ 顾客现场愉悦 ◁ 卖货 ◁ 商品价值呈现 ◁ 练货 ◁ 选货
```

> 注：◁ 表示"由后者驱动前者"——选货是源头，练货是把商品价值呈现给顾客的转化动作，卖货是终端动作，顾客现场愉悦是当场感受，顾客使用价值愉悦是穿着后的复购/口碑。

## 客资经营体系（DAY2 课程详单）

> 经营理念：**价值关系 > 情感关系**（但情感是底色）
> 详见 [[customer_asset_system]] 概念页

### 新客开发运营体系
- 增量计划：店铺节点开发 60% / 非店铺节点开发 35% / 顾客投诉 3-5%
- 核心：精准人货对接

### 老客维护经营体系
- 老客三计划：① 惊艳计划 ② 衣橱计划 ③ 情感计划
- 老客的分类管理和情感温度管理
- 老客的回店计划与频率
- 客资的价值链：**成交 ◁ 分类管理 ◁ 情感经营 ◁ 大单计划 ◁ 回店计划 ◁【邀约计划+引流计划】**

## 业务体制 vs 管理体制（李炳辰演讲《销售联动订货-3C 经营复盘》7984 字精要）

> 来源：搜狐 453905487

### 业务体制
- **业务体制要顺畅**（不是部门架构，是端到端业务流）
- 业务流两端：起点是顾客，终点也是顾客
- 帮助企划部/商品部/销售部建立**以顾客为中心的模型**
- "**部门墙解不了，意味着从需求端到端打不通**"

### 管理体制
- 管理体制要算这条线的毛利
- "出多少货，挣多少钱"
- 关键岗位的团队毛利分红：增了多少商品 / 保了多少折扣 / 上多少营业额 → 增了多少毛利 → 毛利按工资增量分配
- **核心岗位占工作时间 60% 以上的算这条线的人；普通岗位 20% 以上算这条线的人**
- 管理体制解决积极性：工资、绩效、胜任力、股份

### 创意总监的双向领导机制

| 关系 | 内容 |
|------|------|
| 角色 A 向**市场部**汇报 | 市场部负责 A 角色**能力的提升** |
| 角色 A 向**创意总监**汇报 | 创意总监负责 A 角色**业绩的提升** |
| 角色 A 的**基本工资** | 由**市场部**来定 |
| 角色 A 的**绩效工资** | 由**角色 A 自己这条线**算的毛利定 |

> 关键创新：商品经营这条"线"不是新组织结构，而是新工作流水——"不增人也不增加工作量，只改变工作流水"。

## 部门演进的"从虚到实"链

```
市场部（虚）→ 企划部（虚）→ 商品部（半虚半实）→ 技术部（半虚半实）→ 设计部（实）→ 生产部（实）→ 销售部（实）
```

- 虚的部门工资要更高（市场部、企划部工资应高于一般部门）
- 虚的部门是品牌的"大脑"和"方向"，玩的是虚
- 实的部门（设计/生产/销售）强在执行和活用

## 关键评价指标（韦孚三指标）

| 指标 | 含义 | 含金量 |
|------|------|--------|
| ① 财务成功 | 出多少货挣多少钱 | 最外围，不一定有竞争力 |
| ② 市场成功 | 顾客对你的认同度 | **有含金量** |
| ③ 员工能力与深度的提升 | 员工创意、开朗程度 | **最关键**（越高，团队越能持续创新）|

## 3C vs 买手/快消/快反的嫁接

> 来源：搜狐 534521337

- **买手品牌**：终端还原度高是因为很多功夫在企划层。买手品牌对 3C 是一样的——核心都是总部层面的人货对接。
- **快时尚**（优衣库 = 技术路线；无印良品 = 调性路线）：终端导购只执行即可。3C 最强调从总部战略层面来做。
- **快反品牌**：终端练货来不及，就把总部层面解决好。3C 的强项就是总部能力+终端带教双轨。

## 落地方法论（来自核心案例）

### 地素（2022 案例）

- **直营单店零售额同比 +18.7%（上半年）**
- **Q3 同店 +10%**
- **全国同比业绩 +20%**（主要来源客单件关键指标提升）
- 三个抓手：① 源头和终端联动解决 VIP 粘性和高连带 ② 3C 体系工具复制（人货对接 PDCA/总部铁三角美感/练货能力）③ 直营系统业绩稳步提升
- 关键动作：每月度经营会议，总部和店长**摸着商品**开会；**千店千面**（每店结合顾客原型可落地的方案）

### 艾诺丝雅诗（2022 案例）

- 河南江阴店长龚琴琴，3C 体系下两天做了 **48 件大单**
- 长沙王府总代年营业额 **800 万**
- 18-19 年人员离职，员工出去后持续复制 3C 体系
- 营销老总张琼反馈：选择韦孚是因为 3C 是**以商品为导向**，解决"从订到销"的链路打通

### 歌力思（2015-2016 BMTE 案例）
- BMTE 终端零售体系导入歌力思全国 35+ 标杆店铺，**完成 20%+ 销售业绩增长**
- CEO 夏国新参与

### VERRI（2014-2015 BMTE 案例）
- BMTE 终端零售体系导入 VERRI 35 家店铺，**完成 20%+ 销售业绩增长**
- 总经理张潮

### 安踏（2021 案例）
- 安踏集团 2020 集团收益 **355.1 亿元**（+4.7%，连续 7 年增长），经营溢利 91.5 亿元（+5.3%），经营利润率 25.8%
- 量化美学基于终端畅销的企划（详见 [[quantified_aesthetics]]）

## 关键概念名词解释

| 术语 | 含义 |
|------|------|
| **3C** | Commodity（商品） × Customer（顾客） × Commercial Mode（商业模式）|
| **七次人货对接** | 品牌定位→产品战略→设计研发→样衣评审→订货采买→零售渠道→顾客 |
| **通情杆** | 商品组合陈列杆位，要通达顾客情感（人货对接的视觉载体）|
| **BMTE** | 韦孚早期终端零售体系（B=M？T=E？早期命名，已被 3C 迭代；李炳辰 2014-2016 主导）|
| **铁三角** | 商品、陈列、销售（3C 经营会议 1.0 的三个核心部门）|
| **美感生活提升方案** | 量化美学核心技术之一，对应总部品推/商品推广/落地陈列 |
| **目标顾客精准洞察** | 量化美学核心技术之一，对应目标客群画像+商品定位 |
| **单练/对练/群练** | 终端练货的三种形式：单练（个人过款）/对练（两两模拟）/群练（集体练货+店长质询）|
| **三赞三问** | 终端卖货的亲和力话术：三赞美（场景/搭配/顾客特质）+ 三问（需求/场合/偏好）|
| **部门墙** | 部门间协同障碍，3C 视为"端到端打不通"的根本原因 |

## 结论

- **3C 经营体系是中国服饰零售咨询中"商品×人货对接"最系统的方法论**：它把"端到端"做成可量化的"七次对接 + 三指标 + 部门墙破解 + 毛利分红"四件套，是 **A 轮采集的品牌方"商品经营痛点"的标准对照模板**。
- **3C 特别契合 focus_brands 中的卡宾/太平鸟/赢家/歌力思/地素/艾诺丝等品牌现状**（卡宾 2026 中报后商品经营问题已显；地素 3C 案例可作为对照）。建议 pdca-season-kpi 决策页引入"七次人货对接"作为分阶段诊断框架。
- **核心反常识**：3C 强调"虚的部门（市场部/企划部）工资要高于一般部门"——这与许多品牌"重销售轻设计/商品"的现实冲突；但这正是 3C 在赢家/歌力思/地素获得 +20% 业绩的根本机制。
- **数据可信度提示**：3C 体系本身是品牌自宣方法论，所有量化案例数据（地素 18.7%/+20%、歌力思 +20%、VERRI +20%）均为品牌/韦孚自宣，**confidence=品牌自宣**，不能与上市公司审计财报数据混用。
