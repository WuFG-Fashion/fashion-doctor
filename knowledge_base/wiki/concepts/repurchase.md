### 2.1 生命周期五阶段

```
入会 → 首购(30天内) → 培育(60天内复购) → 稳定(季度复购) → 升级/流失
```

### 2.2 关键节点干预

| 节点 | 触发条件 | 干预动作 |
|------|---------|----------|
| **首购后7天** | 入会未满7天 | 满意度回访+搭配推荐 |
| **30天未复购** | 首购后30-45天无订单 | 限时券触达 |
| **60天沉默** | 60-90天无互动 | 大额唤醒券 |
| **90天流失预警** | 90天内无消费 | 重大节点召回 |

## 四、复购分析SQL

```sql
-- 复购周期分析
WITH first_purchase AS (
    SELECT 
        member_id,
        MIN(sale_date) as first_date,
        MIN(DATE(sale_date || ' 00:00:00')) as first_dt
    FROM sales
    WHERE member_id IS NOT NULL AND member_id != ''
    GROUP BY member_id
),
second_purchase AS (
    SELECT 
        s.member_id,
        MIN(s.sale_date) as second_date
    FROM sales s
    INNER JOIN first_purchase fp ON s.member_id = fp.member_id
    WHERE s.sale_date > fp.first_dt
    GROUP BY s.member_id
)
SELECT 
    CASE 
        WHEN julianday(sp.second_date) - julianday(fp.first_date) <= 30 THEN '30天内复购'
        WHEN julianday(sp.second_date) - julianday(fp.first_date) <= 60 THEN '31-60天复购'
        WHEN julianday(sp.second_date) - julianday(fp.first_date) <= 90 THEN '61-90天复购'
        ELSE '90天+复购'
    END as repurchase_window,
    COUNT(*) as member_count
FROM first_purchase fp
LEFT JOIN second_purchase sp ON fp.member_id = sp.member_id
GROUP BY 1;
```
