## 1. SKU生命周期五阶段

```
导入期 → 成长期 → 成熟期 → 衰退期 → 清仓期
  2周     4-8周    4-8周     2-4周      2周
```

### 各阶段特征与动作

| 阶段 | 销售特征 | 库存特征 | 关键动作 |
|------|----------|----------|----------|
| **导入期** | 日均销量低，波动大 | 首批到货，库存充足 | 观察试穿率，收集顾客反馈 |
| **成长期** | 销量快速上升 | 开始补货 | 及时补货，加大推广 |
| **成熟期** | 销量平稳峰值 | 库存周转正常 | 维持陈列面，控制补货 |
| **衰退期** | 明显下滑趋势 | 库存开始积压 | 减少补货，启动打折 |
| **清仓期** | 极低/零散 | 大量尾货 | 打折清仓，调拨至 Outlet |

## 2. SKU分级标签

| 标签 | 定义 | 判断标准 | 处理策略 |
|------|------|----------|----------|
| 🌟 爆款 | 远超预期 | 售罄率>80%，且仍在上升 | 加急补货，扩大陈列 |
| ✅ 畅销款 | 表现良好 | 售罄率50-80% | 正常补货，保持关注 |
| ➖ 平销款 | 表现一般 | 售罄率20-50% | 控制补货，尝试搭配推荐 |
| ⚠️ 潜力款 | 有机会 | 售罄率<20%，但试穿率高 | 调整陈列位置/搭配 |
| ❌ 死款 | 无销售 | 售罄率=0 或 <5% | 尽早打折或调拨 |

## 3. 新品上架后的关键监控节点

| 天数 | 监控指标 | 阈值 | 动作 |
|------|----------|------|------|
| 第3天 | 试穿率 | >10%为合格 | 不合格则检查陈列/价格 |
| 第7天 | 首周销量 | >5件/SKU为及格 | 不合格则调整位置 |
| 第14天 | 售罄率 | >15%为健康 | 低于则进入观察名单 |
| 第30天 | 月售罄率 | >30%为达标 | 低于则考虑降价 |
| 第60天 | 累计售罄率 | >50%为合格 | 低于则进入清仓计划 |

## 4. 季末库存清理策略

### 清仓阶梯
| 时间点 | 折扣力度 | 目的 |
|--------|----------|------|
| 季末前4周 | 7-8折 | 回笼资金优先 |
| 季末前2周 | 5-6折 | 快速去库存 |
| 季末最后1周 | 3-4折 | 清仓甩货 |
| 过季后 | 2-3折/Oulet | 最后处理 |

### 注意事项
- ❌ 避免"硬打折"伤害品牌形象 — 用"特卖会""会员专场"包装
- ✅ 先调拨至低效门店再打折
- ✅ 分析死款原因，反哺下一季企划

## 5. 行业最新动态（2026-05-11采集）

### [SKU进销存管理效率提升]（来源：简道云/jiandaoyun.com，日期：2026-04-13，可信度：高）
- **服装库存核心痛点**：季节性强 + 款色码复杂 + 滞销风险高 + 渠道分散数据割裂
- 服装SKU必须具备**"快进快出"能力**，而非单纯追求库存量稳定
- 春夏款/秋冬款/节庆款/联名款有明显销售窗口，**错过周期价值快速下降**
- 全渠道库存协同成为2026年标配：线下门店+直营网店+跨境平台+社交电商

### [季中OTB失控的解法]（来源：搜狐/business.sohu.com，日期：2026-04-29，可信度：高）
- **核心矛盾**：销售预测/库存结构/OTB计划三者分散在不同工具和人工环节 → 信息滞后导致OTB失控
- **系统化解法**（以第七在线AI商品管理系统为代表）：
  - 把**滚动OTB + 款式生命周期判断 + 门店差异化补货**整合到同一决策链路
  - AI动态预测替代静态OTB预算
  - 畅滞款自动识别与库存重新分配联动
- **关键结论**：工具解决的是"信息处理效率"，决策仍需人工判断

### [全渠道OMS与一盘货策略]（来源：搜狐/business.sohu.com，日期：2026-04-28，可信度：高）
- **服饰行业全渠道OMO三大策略**：
  1. **一盘货库存共享**：打破渠道壁垒，统一库存池
  2. **数据驱动分级运营**：A/B/C级门店差异化配货
  3. **智能订单履约**：就近发货/门店发货/仓店调拨
- 核心目标：当季(Q2)业绩最大化 + 季末(7月)高效清库存
- 推动品牌从**经验运营向数据智能运营转型**

### [优衣库售罄价值再造工程]（来源：网易/163.com，日期：2025-07-07，可信度：中）
- 优衣库2025年引入**"残值激活模型"**，为每个SKU构建全生命周期档案
- 案例：【空气胶囊5代防晒衣】季末余货经AI拆解再利用：
  - 防晒膜 → 露营天幕原料
  - 面料 → 改造成宠物户外装
- **启示**：未动销SKU不只有"打折清仓"一条路，材料回收/跨界再利用可创造第二收入曲线

### [门店SKU数量合理规划方法]（来源：微博行业分享，日期：**2025-07-11**，可信度：中）
- **两种核心计算法**：
  1. **销售量计算法**：以销售额为依据进行SKU规划（仅适用于门店面积/陈列道具不变的情况）
  2. **周转率计算法**：以店铺商品周转时间为依据（更推荐）
     - 周转次数 = 销售金额 / 平均库存金额
     - 平均库存金额 = (期初库存数+期末库存数)/2 × 件均价
- **某男装公司实际案例**：通过周转率计算法优化SKU数量
  - SKU数精简25% but 销售额反而提升12%
  - 关键：砍掉长尾SKU资源集中给潜力款
