# 七次人货对接（韦孚 3C 核心流程）

> **一句话摘要**：韦孚 3C 经营体系**最核心的流程框架**——"品牌定位→产品战略→设计研发→样衣评审→订货采买→零售渠道→顾客"七次人货对接；每一次对接都应是**毛利的形成**，每一次偏离都会形成**未来的库存**。该框架把"端到端"业务流（顾客↔顾客）分解为 6 个可量化、可管控的中间环节。
>
> **来源**：搜狐 467523956 img_5.png 信息图（3C 商品零售体系 2 日课程）；453905487（李炳辰 销售联动订货 3C 经营复盘 7984 字演讲详述）。
>
> **最后更新**：2026-08-25

## 核心要点

- **七步流程**：品牌定位 → 产品战略 → 设计研发 → 样衣评审 → 订货采买 → 零售渠道 → 顾客
- **两端闭环**：起点是顾客，终点也是顾客（业务流"端到端"）
- **"虚→实"递进**：品牌定位（最虚）→ 产品战略 → 设计研发 → 样衣评审 → 订货采买 → 零售渠道（最实）
- **三原则**：
  - 每一次对接都应是**毛利的形成**
  - 每一次偏离都会形成**未来的库存**
  - 至少**7 次**对接
- **核心工具映射**：
  - 品牌定位 ← 创意总监/品牌总监
  - 产品战略/设计研发 ← 量化美学（感性工学、风格管理）
  - 样衣评审 ← 总部-终端 PDCA
  - 订货采买 ← 商品二次企划（科学订货）
  - 零售渠道 ← 3C 经营会议 + 铁三角（商品/陈列/销售）
  - 顾客 ← 客资经营体系

## 七步详解

| 步骤 | 名称 | 关键工具/角色 | 失败后果 |
|------|------|----------------|----------|
| ① | **品牌定位** | 创意总监/品牌总监 | 调性摇摆、客群错位 |
| ② | **产品战略** | 感性工学©（量化美学）| 商品方向错位 |
| ③ | **设计研发** | 风格管理系统、色彩管理系统 | 设计稿不符合调性 |
| ④ | **样衣评审** | 人货对接 PDCA 复盘 | 大量删款、改款浪费 |
| ⑤ | **订货采买** | 商品二次企划（科学订货）| 库存结构错配 |
| ⑥ | **零售渠道** | 3C 经营会议 + 总部铁三角 | 终端不执行主推 |
| ⑦ | **顾客** | 客资经营体系 | 客单件低、复购差 |

## 三原则详解

### 原则 1：每一次对接都应是"毛利的形成"

> 反过来：每一次"未对接"或"对接失败"都直接侵蚀毛利。

| 失败模式 | 毛利损失 |
|----------|----------|
| 品牌定位不清 | 调性反复 → 客群错位 → 复购低 |
| 产品战略与定位脱节 | 研发无效投入 |
| 设计研发不符合调性 | 样衣改稿浪费 |
| 样衣评审不严 | 上柜 SKU 大量滞销 |
| 订货采买错配 | 库存积压 |
| 零售渠道终端不执行主推 | 连带率低 |
| 顾客端不接住 | 客单件低、退货高 |

### 原则 2：每一次偏离都会形成"未来的库存"

> 库存不是设计出来的，是"七次对接"中某次偏离累积出来的。

- 1 次偏离（轻微）→ 季末少量库存
- 2 次偏离 → 季末明显库存，开始打折
- 3 次+ 偏离 → 库存积压、恶性折扣、毛利侵蚀

### 原则 3：至少 7 次（不是 5 次也不是 10 次）

> "至少"二字暗示：实际可能更多（如安踏集团案例提到 8+ 个部门）——七次是**最小必要**对接数。

## "端到端"业务流

> 来源：搜狐 453905487 李炳辰演讲

```
第一个端：需求（=顾客）
第二个端：终端（=顾客）
从需求到从顾客到顾客的端到端不能打通，意味着我们今天讲的内容还是不通！
```

> **3C 的"端到端"指从"作为需求方的顾客"到"作为最终消费方的顾客"，中间经过 6 次人货对接。**

## 部门墙的破解

七次人货对接的最大障碍是**部门墙**：

| 部门 | 位置 | 角色 |
|------|------|------|
| 市场部 | 最虚 | 定方向、定需求 |
| 企划部 | 虚 | 开始产生方案 |
| 商品部 | 半虚半实 | 既有货又有数据 |
| 技术部 | 半虚半实 | 有核心技术 |
| 设计部 | 实 | 落实 |
| 生产部 | 实 | 生产 |
| 销售部 | 实 | 销售 |

> "从虚到实的演进过程，就是打通产销一条线的过程"

## 应用价值

### 对 PDCA 决策页的借鉴

将"七次人货对接"作为 PDCA 决策的**结构性诊断框架**：

| PDCA 步骤 | 对应七次对接 | 诊断问题 |
|-----------|---------------|----------|
| Plan | ①②③品牌/产品/设计 | 品牌定位-产品战略-设计研发是否对齐？ |
| Do | ④⑤样衣-订货 | 样衣评审-订货采买是否执行到位？ |
| Check | ⑥零售 | 总部-终端主推带货是否一致？ |
| Act | ⑦顾客 | 客单件/复购是否达到目标？ |

### 对 focus_brands 诊断的适用

| 品牌 | 七次对接现状（推测）| 诊断重点 |
|------|----------------------|----------|
| 卡宾 | 港股上市，2026 中报后商品经营问题 | ④⑤样衣-订货环节库存问题 |
| 太平鸟 | 多品牌矩阵，2025 后降速 | ⑥零售环节总部-终端联动 |
| 艾诺丝雅诗 | 韦孚深度合作 | 整套 3C 体系已植入 |
| 地素 | 韦孚深度合作 | 直营 3C 体系成熟（+18.7%） |
| 赢家 | 韦孚 18 年长期合作 | 最早合作客户，3C 体系成熟 |

## 结论

- **七次人货对接是 3C 体系最具操作性的"骨架"**：与"商品×顾客×商业模式"3C 公式互补——公式是经济模型，七次对接是操作流程。
- **该框架对 focus_brands 现状诊断有直接价值**：A 轮采集时，可对照七步对每个品牌做"在哪一步偏离最大"的诊断，**比单纯"售罄率/库存周转"指标更早发现问题**。
- **可作为 PDCA 决策页的核心结构**：把"七次对接"作为 PDCA 的天然结构（Plan=①②③、Do=④⑤、Check=⑥、Act=⑦）。
- **数据可信度**：七次人货对接是韦孚方法论，confidence=品牌自宣；其衍生诊断应用属于方法论迁移，无独立数据可信度问题。
