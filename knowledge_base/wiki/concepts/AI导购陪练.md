# AI导购陪练

> **一句话摘要**：基于大语言模型的零售导购智能培训系统，通过场景化模拟、个性化训练、量化评估三大能力，破解传统导购培训"学用脱节、成本高、效率低"困局。2026年市场规模72.8亿元，CAGR 47.3%。

## 核心要点

1. **行业基准(KPMG)**：专业导购使成交率+42%、客单价+35%；仅38%导购接受系统培训
2. **培训痛点**：CCFA数据67%培训脱节；传统带教800元/月/人，新人上岗需45天
3. **AI四维评分**：话术准确性/需求挖掘/沟通技巧/情绪把控力，NLP+行为切片0.5秒响应
4. **效果数据**：能力达标时间-42%，30天遗忘率-35%，场景真实度8.7/10 vs 传统6.2/10
5. **趋势预测**：2026年74%零售企业将规模化应用AI(KPMG)

## 详细内容

### AI陪练核心功能

| 功能 | 说明 |
|------|------|
| AI陪练 | 12类客户画像+6大核心场景，实时语义交互 |
| AI建课 | 基于10万+真实客户对话数据构建模拟场景 |
| AI演讲 | 新一代智能培训体验，全覆盖导购培训场景 |
| AI点评 | 四维度量化评分，NLP+行为切片0.5秒级响应 |

### 12类核心客户画像

目标明确型、犹豫型、价格敏感型、礼品型、挑剔型、砍价型、纠结型、沉默型、从众型、冲动型、理性分析型、社交型

### 六大核心场景

迎客接待、需求挖掘、产品推荐、异议处理、成交促成、客户维护

### 三阶训练模式

| 阶段 | 内容 |
|------|------|
| 第一阶段：首轮全流程评估 | 生成专属能力画像，精准定位短板 |
| 第二阶段：个性化训练推送 | 新人→基础话术；资深→异议处理与客户维护 |
| 第三阶段：阶梯式强化训练 | AI角色扮演+多轮对话生成+真实客户沟通逻辑 |
