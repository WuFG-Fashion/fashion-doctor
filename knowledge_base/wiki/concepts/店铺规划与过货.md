# 店铺规划与过货

> **一句话摘要**：门店"陈列规划 + 货品培训"双主题——陈列三易（易看/易挑/易取）与过货四大法宝（新品过货/通情杆/陈列走墙/情景演练），把"货品上架"与"员工会讲货"做成标准动作。
> **来源**：human 培训课件《店铺规划》（太平鸟风尚男装）、《过货方式及流程》（企业内部课件，置信度：品牌自宣）
> **最后更新**：2026-08-25

## 核心要点

1. **陈列三易**：容易看到 / 容易挑到 / 容易取到——顾客动线设计的三个基准（[[2026-08-25_human_店铺规划]]，太平鸟风尚男装出品）。
2. **过货四大法宝**：新品过货（让员工爱上货品）/ 通情杆过货 / 陈列走墙 / 情景模拟演练（[[2026-08-25_human_过货方式及流程]]）。
3. **过货目的**：员工熟悉货品、会讲卖点——"货品知识→销售话术"的转化器。
4. **节奏衔接**：新品上市→全员过货，对应商品企划的上货波段。

## 结论

1. **陈列三易是转化漏斗的视觉化表达**：易看（曝光）→易挑（选择效率）→易取（成交便利）——与 [[卖场管理SOP]] 的陈列维度配套，是"陈列即销售"的方法论总纲。
2. **过货 = 货品知识的终端落地**：员工通过过货把 [[面料知识与洗涤保养]] 等产品知识变成接待话术（FABE 的 E），是 [[导购培训SOP]] D1-2 产品知识培训的实操形式。
3. **"让员工爱上货品"是过货的心理前提**：先认同后推荐，比机械背卖点更有效——与 [[销售九部曲]] 的"心态先行"一致。
4. **与商品企划节奏联动**：过货节奏（新品上市→全员过货→考核）应对应 [[季初订货节奏]] 的上新波段，是商品运营在终端的动作接口。
