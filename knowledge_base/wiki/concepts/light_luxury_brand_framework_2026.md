# 轻奢品牌三维跟踪框架（规模-价格-投入）

> **一句话摘要**：轻奢需求呈S型曲线（高价段具备凡勃伦溢价），通过规模（GMV/同店/会员）、价格（件单价/折扣率/售罄率）、投入（营销/渠道/高端门店）三维指标精准捕捉品牌股价拐点，已验证亚瑟士(+10×)、Lululemon(走弱)、拉夫劳伦(+185%)三个完整案例。

## 核心逻辑

轻奢需求非线性，呈S型曲线：
- **高价段**：越贵越具备身份溢价（凡勃伦效应）
- **短期促销放量**可能有效
- **长期持续降价**形成弹性陷阱 → 毛利率与品牌定位双受损

## 三维指标

| 维度 | 核心指标 | 判断逻辑 |
|------|---------|---------|
| **规模** | GMV、同店、门店数、会员数、品牌搜索热度 | 量增→成长性确认 |
| **价格** | 件单价、折扣率、售罄率 | 价增→品牌溢价强化 |
| **投入** | 营销投放、渠道扩张、高端门店布局 | 投入→未来增长储备 |

## 三类验证案例

### 正向拐点：亚瑟士（2019-2026股价+10×）
- 加大高端营销 → 鬼塚虎持续提价 → 量价齐升
- 三维信号：规模↑ + 价格↑ + 投入↑ = 正向飞轮

### 负面警示：Lululemon
- 瑜伽裤均价持续下行 + 营销投入放缓 + 增长依靠低基数
- 三维信号：价格↓ + 投入↓ + 规模（低基数）= 走弱
- → 后续业绩&股价持续走弱

### 正向拐点：拉夫劳伦（2024后+185%）
- 缩减奥莱 + 提高营销占比 + 持续抬升单价
- 亚洲利润率持续上行
- 三维信号：价格↑ + 投入↑ + 规模↑ = 正向

## S型需求曲线与弹性陷阱理论 ⭐ 6月新增

> 来源：同上

### 核心理论
- **S型曲线**：轻奢需求非线性，高价段具备**凡勃伦溢价**（越贵越有身份溢价）
- **弹性陷阱**：短期促销放量有效，但长期持续降价形成弹性陷阱 → 毛利率与品牌定位双受损
- **投资含义**：品牌进入弹性陷阱是卖出信号；品牌出现凡勃伦溢价拐点是买入信号

### 新增验证：Burberry ⭐ 2026-06-30

> 来源：[[2026-06-28_贝尔财经_Burberry_FY2026年报]]

| 指标 | 数值 |
|------|------|
| FY2026 营收 | 24.20亿英镑(-2%) |
| 毛利率 | **67.9%** |
| 大中华区 Q4 增速 | **+10%**（双位数） |
| Z世代消费者 | +18% |
| 运营费用节省 | 8000万英镑 |
| 核心品类(风衣+围巾) | 下半财年双位数增长 |

**三维框架解读**：
- **规模**：全年营收-2%偏弱，但Q4大中华+10%拐点信号 → 规模待确认
- **价格**：聚焦核心品类、提升品牌溢价，毛利率67.9%维持高位 → ✅ 价格↑
- **投入**：200围巾专区、上海170周年大秀、Z世代营销 → ✅ 投入↑
- **判断**：三维信号中价格+投入双正向，规模拐点初现，属于"正向拐点早期"，需跟踪FY2027是否延续

### 风险警示
1. 宏观消费复苏不及预期 → 高端需求走弱
2. 门店扩张低于指引
3. 行业库存高企倒逼降价 → 侵蚀品牌溢价（弹性陷阱触发）
4. 原材料价格大幅波动
5. 国际地缘/汇率冲击海外业务
