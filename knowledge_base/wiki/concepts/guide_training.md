## 十、2026年5月20日01:07更新（第二十六轮采集）

### [2026年连锁零售门店复购考核框架：导购/店长/社群三方协同]（来源：iHR360 / docs.ihr360.com，日期：**2026-05-19**，可信度：**高**）⭐⭐
- **核心转变**：从传统"单点销售"模式转向**"复购协同"模式**
- **五维经营口径统一**（设计考核前必须先统一）：

| 经营模块 | 建议统一口径 | 关注重点 |
| :--- | :--- | :--- |
| **会员复购** | 复购销售额、复购订单数、老会员唤醒后到店与成交 | 区分新客成交与老客回流 |
| **人效** | 班次人效、时段人效、人均有效跟进产出 | 人力是否投在高转化时段 |
| **坪效贡献** | 时段坪效、活动坪效、会员邀约到店带来的增量 | 空间与人力是否匹配 |
| **排班效率** | 高峰班次覆盖率、会员活跃时段覆盖率、任务嵌入率 | 排班是否服务于双目标 |
| **协同归属** | 触达归属、到店承接归属、跨店成交归属、协同提成规则 | 减少抢会员抢业绩 |

- **岗位责任三层指标设计法**：

**导购KPI体系**：
- 【结果类】：复购销售额、复购订单数、老会员回流成交
- 【过程类】：加微率、回访完成率、邀约反馈率、跟进及时率
- 【协同类】：线索承接完成率、跨岗跟进完成率
- 建议周期：日跟进，周复盘，月结算

**店长经营责任制**：
- 角色升级：从"日销负责人"→承担组织/排班/结果复盘的**经营责任人**
- 【结果类】：门店复购达成、班次人效、时段坪效贡献
- 【过程类】：**排班匹配度（关键！）**、会员任务分配完成率、异常纠偏时效
- 【协同类】：社群活动承接率、跨店支援安排完成率
- **重点：店长必须对"班次任务完成率"负责，而非仅当天的销售额**

**社群运营协同机制**：
- 角色定位：负责节奏/内容/转化线索输送（不仅是发券）
- 【结果类】：唤醒后到店量、活动带动复购表现
- 【过程类】：触达率、互动率、分层运营执行率、**线索回传及时率**
- 【协同类】：门店接单率、活动协同完成率

- **动态排班创新**（最大亮点）：
  - 传统做法：按历史客流高峰固定排班
