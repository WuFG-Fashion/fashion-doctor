# 订货会决策框架

> 季初订货的"决策骨架"：以 OTB 为预算硬约束，在核心款/基本款/形象款之间分配权重，并用首单/补单比例平衡压货与断码风险。


## 结论

> **AI 合成洞察（判断 / 推论，非数据复述）**：
>
> 1. **订货会是"用 OTB 天花板在款式间做资源分配"**：OTB 定死总盘，核心/基本/形象款三段配比（50-60/25-30/10-15%）是默认解，超预算只能砍形象款。
> 2. **首单 7 : 补单 3 是压货与断码的折中**：留 30-40% 滚动补单，供应链柔性高可放到 6:4——宁可少订快补，不要多订硬压。
> 3. **决策质量取决于输入质量**：上季分品类售罄率、下季趋势、可用资金、补单窗口四要素齐全，框架才跑得通（见 [[服装订货会精准策划]] 实践）。
> 4. **订货会决策框架是商品企划落地打法的"中段枢纽"**：上游接趋势企划与 OTB，下游接波段上货与清仓兜底（见 [[商品企划落地打法]]）。

## 核心要点

- **OTB 是天花板**：本季总盘由可用资金决定（见 [[动态OTB管理]]），超预算只能砍形象款。
- **三段配比**：核心款 50–60% / 基本款 25–30% / 形象款 10–15%，可按品牌微调。
- **首单 7 : 补单 3**：留 30–40% 做滚动补单，供应链柔性高时（见 [[柔性供应链与商品企划]]）可放到 6:4。
- **节奏闭环**：复盘 → 预算 → 订货会 → 首单 → 波段上货 → 周度监控（见 [[季初订货节奏]]）。
