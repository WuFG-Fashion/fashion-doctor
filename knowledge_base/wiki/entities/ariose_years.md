# 艾诺丝·雅诗 (ARIOSE YEARS)

> **一句话摘要**：杭州爱唯时尚集团旗下中高端时尚女装（2005 创立），2025 销售额约 50 亿元、门店突破 1,800 家、会员超百万，是杭州女装 TOP3 中的"中淑精准商业黑马"；第二曲线 AW PROJECT 以重奢商圈首店试探高净值客群。

## 核心数据

| 维度 | 数据 |
|------|------|
| 母公司 | 杭州爱唯服饰 → 2025-12-17 更名「杭州爱唯时尚集团有限公司」 |
| 主品牌 | 艾诺丝雅诗（2005 创立，中高端时尚女装） |
| 门店 | 2025 底 1,700+ → 2026-03 全国线下突破 **1,800 家** |
| 会员 | 超百万会员用户 |
| 2025 销售额 | 约 **50 亿元**（与江南布衣/伊芙丽/麦檬同量级） |
| 行业梯队 | 杭州女装 TOP3（江南布衣·哲思 / 伊芙丽·商业标杆 / 艾诺丝·中淑黑马） |
| 第二曲线 | AW PROJECT（轻奢设计师，2024.9 推出，对标国际奢牌面料，客群 30-45 岁） |
| 新锐品牌 | RicoVea（2026.3 孵化，成都 IFS 首店，接棒退潮的 CHUU） |
| AW PROJECT 拓店 | 2025 末近 30 家 → 2026 上半年加码重奢：上海港汇恒隆首店首日破 60 万、进驻北京 SKP/深圳万象城 |

> 门店口径不一：另有来源称"2025 年左右突破 2,890 家"，以 1,700-1,800 家为基准待验证。

## 结论

1. **艾诺丝是"中淑精准商业黑马"，但公开数据极度匮乏**：50 亿 / 1,800 店 / 百万会员的体量已逼近江南布衣、伊芙丽，却因非上市、未披露财报而缺乏定量财务；知识库须以"规模定性 + 渠道信号"补足定量缺口，避免与上市竞品做同口径财务对比。
2. **AW PROJECT 是品牌向上突破的胜负手**：以重奢商圈首店（港汇恒隆首日 60 万）试探高净值客群、对标国际奢牌面料，是杭州女装从"商业黑马"向"品牌力"跃迁的关键试验，也是观察"中端女装能否上探轻奢"的样本。
3. **母公司更名"爱唯时尚集团"释放集团化信号**：主品牌 + AW PROJECT + RicoVea（接棒 CHUU 退潮）的多品牌矩阵成型，与太平鸟多品牌集团路径可类比，但体量与资本化（上市）程度差距显著，竞争层级不同。
