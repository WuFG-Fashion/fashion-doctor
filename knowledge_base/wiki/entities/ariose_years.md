# 艾诺丝·雅诗 (ARIOSE YEARS)

> **一句话摘要**：杭州爱唯时尚集团旗下中高端时尚女装（2005 创立），2025 销售额约 50 亿元、门店突破 1,800 家、会员超百万，是杭州女装 TOP3 中的"中淑精准商业黑马"；第二曲线 AW PROJECT 以重奢商圈首店试探高净值客群。

> **门店口径 / 第三方交叉验证（S3 · 2026-08-16）**：自宣 1,800 家（2026-03）获头条独立媒体 corroborate（1,700+ @ 2025 底），主流区间 1,700–1,800 成立；原备注"2,890 家"溯源为搜狗百科 outlier（疑似含加盟意向 / 口径宽），已降权。营收 ~50 亿亦获头条 corroborate。详见 [[2026-08-16_S3_ariose_years_第三方交叉验证]]（自宣数字由第三方媒体 corroborate → 置信度上调为"品牌自宣 + 第三方 corroboration"，仍非审计级）。

## 结论

1. **艾诺丝是"中淑精准商业黑马"，自宣数字已获第三方 corroborate**：50 亿 / 1,800 店 / 百万会员的体量已逼近江南布衣、伊芙丽；虽非上市、无审计财报，但 50 亿营收与 1,700+ 门店获头条等第三方媒体独立 corroborate（见 [[2026-08-16_S3_ariose_years_第三方交叉验证]]），置信度优于纯自宣。知识库仍以"规模定性 + 渠道信号"为主，避免与上市竞品做同口径财务对比。
2. **AW PROJECT 是品牌向上突破的胜负手**：以重奢商圈首店（港汇恒隆首日 60 万）试探高净值客群、对标国际奢牌面料，是杭州女装从"商业黑马"向"品牌力"跃迁的关键试验，也是观察"中端女装能否上探轻奢"的样本。
3. **母公司更名"爱唯时尚集团"释放集团化信号**：主品牌 + AW PROJECT + RicoVea（接棒 CHUU 退潮）的多品牌矩阵成型，与太平鸟多品牌集团路径可类比，但体量与资本化（上市）程度差距显著，竞争层级不同。
