# lululemon

> **一句话摘要**：全球运动休闲龙头，FY2026Q1营收25亿美元(+4%)、净利暴跌38%至1.95亿、中国大陆+30%逆势狂飙、北美连续5季同店下降、全年指引大幅下调。

## 基本信息
- 全称：lululemon athletica inc.
- 上市：纳斯达克 (LULU)
- 总部：加拿大温哥华
- 定位：高端瑜伽/运动休闲服饰

### 战略挑战

1. **北美主场失速**：连续5季度同店下降，创始人代理权争议+负面媒体+竞品Alo/Vuori分流
2. **利润质量恶化**：EPS从2.61→1.69美元(-35%)，营业利润率从18.5%→11.2%
3. **关税冲击**：中国供应链高度依赖，关税侵蚀毛利率2.8pp
4. **中国市场支撑但占比有限**：+30%高速增长但整体体量仍无法弥补北美下滑
5. **产品开发加速**：周期从18-24月→15-16月，目标12-14月

### 四大困境（6月确认）
1. **市场结构严重失衡** — 北美本土疲软，过度依赖中国单一市场
2. **盈利能力持续弱化** — 供应链成本上涨+北美促销常态化侵蚀利润
3. **品类增长动能不足** — 核心瑜伽品类乏力，配饰萎缩，缺乏新爆款
4. **品牌心智优势弱化** — 耐克、阿迪、Alo Yoga等三方合围，赛道壁垒减弱
