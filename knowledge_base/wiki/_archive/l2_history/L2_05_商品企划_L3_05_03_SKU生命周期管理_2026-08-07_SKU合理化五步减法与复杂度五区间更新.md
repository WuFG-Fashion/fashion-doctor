# SKU 合理化五步减法与复杂度五区间（2026-08-07 更新）

> 来源：[[2026-08-07_retailnorthstar_SKU合理化五步减法与复杂度五区间]]

## 一、SKU 单向膨胀的结构性根源

**加法决策成本 << 减法决策成本**：加法责任分散（失败可归因市场），减法责任集中（得罪供应商、品类经理、门店）。结果是未做主动治理的服装品牌 SKU 年均自然增长 **12%–18%**，而销售额增长通常低于此。

## 二、复杂度五区间

| 区间 | 特征 |
|---|---|
| ① 稀缺区 | 客户找不到想要的，连带率低 |
| ② 增长区 | 每加一 SKU 有净增量 |
| ③ **最优平台区** | 边际贡献峰值且平坦（目标区间） |
| ④ **稀释区** | 新 SKU 蚕食老 SKU —— **多数成熟品牌所在** |
| ⑤ 混乱区 | 长尾泛滥、断码严重、售罄率下滑 |

**定量信号**：SPS（单款店均销量）<5 件即表明已进入稀释/混乱区。详见 [[2026-08-07_单款店均效率SPS与款式宽度反推模型]]

## 三、复杂度的五项隐性成本
① 供应链（独立 BOM/采购/质检/包材）② 仓储（库位 + 拣货路径）③ 门店（陈列面积恒定，单款面积被摊薄）④ **人（导购可熟练讲解约 40–60 款，超出后推荐质量下降）** ⑤ 数据（单 SKU 样本变小，预测精度下降）

> 注：店均上柜 120–180 款 vs 导购可熟记 40–60 款 → 导购仅能覆盖约 1/3 在售款，这正是需要重点款（形象+核心）主推机制的原因。

## 四、五步减法流程

| 步骤 | 内容 |
|---|---|
| 1 退出候选池 | 销量后 20% ∩ 售罄率低于品类均值 **15pct** ∩ 毛利率低于品类均值 |
| 2 蚕食检验 | 同价位带有售罄率更高的相似款 → 可被吸收，砍掉不损失销售额 |
| 3 战略豁免 | 齐色齐码补充款 / 形象款 / 新品类试水款（首季不考核） |
| 4 影响量化 | 转移率 **60%–80%**（有替代款）/ **20%–40%**（无替代款） |
| 5 释放再投入 | **60%** 加深核心款 / **30%** 新品类试水 / **10%** 季中翻单弹性 |

## 五、效果基准（一年周期）

| 指标 | 改善 |
|---|---|
| SKU 数量 | -15%~25% |
| 销售额 | 持平 ~ +5% |
| 库存周转 | +0.5~1.0 次/年 |
| 季末售罄率 | +3~8pct |
| 断码率 | -20%~30% |
