# SPS 单款店均效率与款式宽度反推（2026-08-07 更新）

> 来源：[[2026-08-07_单款店均效率SPS与款式宽度反推模型]]

## 一、为什么"总 SKU 数"不是宽度指标

"这季上 800 个 SKU"本身无信息量——铺 100 家店和铺 500 家店是两回事。真正的宽度指标是：

> **SPS（Sales Per Style per Store）= 单款在单店的整季平均销量（件）**

## 二、三层宽度指标

| 指标 | 参考区间 |
|---|---|
| 店均上柜款数（100㎡ 店） | 120–180 款 |
| 店均上柜款数（200㎡ 店） | 200–280 款 |
| SPS 健康值 | ≥8 件 |
| SPS 预警线 | <5 件（款式过宽，必产生尾货与断码） |
| SPS 偏窄信号 | >20 件（顾客选择不足，隐性流失） |
| 坪效拐点 | 上柜款数超区间上限 **+20%** 后坪效下降 |

## 三、分品类 SPS 差异（不可一刀切）

| 品类 | SPS 参考 | 宽深策略 |
|---|---|---|
| 基础款（T恤/衬衫） | 15–30 件 | 窄而深 |
| 核心款（外套/连衣裙） | 8–15 件 | 平衡 |
| 形象款 | 2–5 件 | **不适用预警线** |
| 配饰 | 20–40 件 | 极窄极深 |

> 常见错误：用统一 SPS 预警线考核所有品类 → 形象款被误杀、配饰款宽度失控。

## 四、宽度反推公式

```
目标销售件数 = 目标销售额 ÷ 客单价
店均合理款数 = 目标销售件数 ÷ 门店数 ÷ 目标 SPS
企划总款数 ≈ 店均合理款数 × 1.3~1.5（含淘汰率）
```

示例：1 亿元 / 客单 600 元 / 200 店 / SPS 10 → 店均 83 款 → 企划总款数约 108–125 款
