# 柔性供应链与商品企划趋势（2026更新）

## 供应链范式转移
- 推式(大批量订货)→拉式(数据驱动小单快反)
- 柔性供应链从"竞争优势"→"生存门槛"

## 五步商品企划新范式
1. 趋势研判(AI辅助+社交媒体热点)
2. 小单测试(首单100-500件)
3. 直播测款(直播间为新品首发和爆款测试核心渠道)
4. 数据决策(直播反馈+门店销售决定补单量)
5. 快反追单(爆款7-14天返单，滞销款止损)

## 品类渗透率差异
- 女装：小单快反渗透率最高(生命周期短、SKU复杂度高)
- 男装：较低(基础款集中度高、品牌忠诚度高)
- 童装：较低(品质升级需求为主)

## 四类竞争格局
国际快时尚(一二线/放缓) / 本土多品牌集团(下沉/矩阵) / 运动户外(国潮+专业) / 电商新品牌(社交+直播)
