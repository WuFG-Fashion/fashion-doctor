# L3_06_04 SQL查询优化 — 2026-07-28 更新纪要

> 本轮（ingestC Round 116）补充 Polars 2.0 大规模数据清洗范式跃迁，与 L2_06 数据分析实务直接相关。

## 新增要点

- **Polars 2.0 清洗范式跃迁**：零拷贝内存 + LazyFrame 全链路惰性执行 + 原生并行流式 I/O，TB 级清洗单机亚秒级。
- 实测（CSDN 深度评测 2026-04）：10M 行清洗 8.2s→1.9s（4.3×）；最高比 Pandas 快 **42.6×**；比 Dask 低 **68.7%** 内存；10GB Parquet Spark 8.7s/4.2GB → Polars 3.1s/1.9GB。
- 工程要点：LazyFrame 解耦、Rayon 多线程 + SIMD 向量化清洗、优先 `scan_*`、`scan_*` + CI Schema 校验。
- 类型系统陷阱：PostgreSQL 四舍五入 vs Spark 向零截断（123.46 vs 123.45），跨引擎迁移需显式治理。
