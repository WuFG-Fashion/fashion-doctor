# L3_07_03 跨品牌数据整合 — 2026-08-09 更新纪要

> 本轮（ingestC Round 120）补充语义层（Semantic Layer）作为多品牌"指标计算层"的 2026 最佳实践落地形态——把售罄率/周转/复购等度量定义为持久、受治理、版本化对象，对看板与 ChatBI 统一暴露。

## 新增要点

- **语义层 = 指标计算层底座**：集中定义不可协商的指标，各品牌分布使用，杜绝"两个销售额"；OSI 标准（2026-01）让指标跨工具/跨引擎可互换。
- **给 ChatBI 入口的底座**：Agent 经 dbt MCP server 只读已批准指标，权限继承既有多品牌隔离规则，避免越权泄漏。
- **落地路径**：先小范围试点（单品牌库存质量），把高频口径做成 dbt MetricFlow 度量定义 + 只读视图，再扩至全品牌。
