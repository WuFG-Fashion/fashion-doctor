# B佐证：Lacoste 商品企划与品类拓展（2026-08-28）

> **一句话摘要**：Lacoste FW26 大秀 + Mackintosh 胶囊 + Multi-category 品类拓展（服饰/鞋履/太阳镜/包袋）+ Club Lacoste 概念。
> **来源**：WebSearch 品牌搜索（大秀报道/媒体，2026-08-28）

## 核心要点

1. **FW26 大秀**：the washed-out match（做旧感核心系列）；Mackintosh 合作胶囊（外套工艺跨界）。
2. **Multi-category 品类拓展**：服饰 + 鞋履 + 太阳镜 + 包袋——从"polo 单一心智"走向全品类生活方式品牌。
3. **Club Lacoste 概念**：门店+会员+社群一体化运营（与 L2_03 会员方法论呼应）。
4. **企划逻辑**：核心品类（polo/网球 DNA）保基本盘 + 胶囊联名造话题 + 配饰拓展提客单。
5. 背景：2026 品牌焕新，营收约 €3B（2026-08-27 A2 源）。

## 结论

1. **"核心保基本盘+联名造话题+配饰提客单"是典型的主力/形象款结构**：与 [[2026-08-28_商品企划方法论_OTB与SKU结构2026]] 的"主力 50-60% + 形象 10-20%"完全同构——Lacoste 验证了品类结构黄金比例在高端品牌的操作面。
2. **Multi-category 拓展是客单价提升的结构性手段**：鞋履/太阳镜/包袋为高毛利配饰，与 [[sku_fine_management]] 的品类深度管理衔接，配饰是 SKU 结构的增量池。
3. **Club Lacoste 把商品企划与会员运营打通**：门店体验（商品）→ 会员权益（Club）→ 社群复购，验证 L2_03 与 L2_05 的跨域协同。
4. **品牌实证价值**：Lacoste 作为轮换品牌，为 L2_05 提供"国际高端品牌品类拓展"样板，与太平鸟（本土快反）、Zara（快时尚周转）对照三种企划模式。
