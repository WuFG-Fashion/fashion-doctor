# NO ONE ELSE 中国门店与定位全维度动态

> **一句话摘要**：韩国 PPB STUDIO(chuu 姐妹品牌)旗下 NO ONE ELSE 2021 入华，2025 年中国约 48 家店、客单 400-600 元，以无性别甜辣风吃下快时尚退出的市场份额。

> **最后更新**：2026-08-27

> **置信度**：第三方数据（行业媒体/商场招商盘点，门店数为 2025 统计）

## 核心要点（全维度）
- **门店**：中国约 48 家(2025)，核心商圈；PPB Studio 集团(chuu+NOE)中国共 231 家。
- **定位/价格**：中档无性别潮流，客单 400-600 元，价格带 99-899 元。
- **营销/渠道**：韩流+性价比、京东旗舰店+线下；吃下 Zara/H&M/Gap 退出份额。
- **竞品**：与 [[nerdy]]、[[thisisizi8]] 同为韩潮入华样本，但 NOE 走"规模化直营+代理"更重。

## 结论
1. NO ONE ELSE 以"韩流IP+中价无性别+核心商圈店"规模化落地，是韩潮品牌在华最成功的渠道模型之一，对 [[peacebird|太平鸟]] 年轻线有客群重叠竞争。
2. 与 [[nerdy]]/[[thisisizi8]] 比较：NOE 更重线下规模化，后两者偏买手/社媒轻资产，反映韩潮入华的两种路径。
