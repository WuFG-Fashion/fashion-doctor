## DAY1：商品零售体系（详解）

### 总部零售运营：人（客资）货（商品）对接

- **商品选货策略的共识与公示**：总部核心主推商品策略 / 库存量 / 生命周期 / 商品流转 / 终端零售联动产品研发 / **通情杆**运作体系
- **练货体系：商品搭配，呈现商品美感**
  - 战略目的：提升自信/美感
  - 战术目的：销售、大单
  - 内容：① 商品搭配 ② 人货对接 ③ 商品解读
- **活用商品策略关键节点**：联动库存 / 锁定顾客 / 惊艳搭配 / 生活状态呈现

### 零售终端运营：人（客资）货（商品）对接

- **终端店铺选货体系**：解决库存量大；包容顾客需求；体现聚焦原则；店铺通情杆运作
- **终端店铺练货体系**：集体过款 / 杆挂联动 / 店长质询；**单练、对练、群练**（重在展示商品美感而不在 FAB 话术）
- **终端店铺卖货体系**：
  - 销售训练：商品力（人货对接搭配）、亲和力（三赞三问）、共情力（顾客响应）
  - 商品连单、大单模型
  - 单单复盘 PDCA

### 商品经营体系的价值链

```
顾客使用价值愉悦 ◁ 顾客现场愉悦 ◁ 卖货 ◁ 商品价值呈现 ◁ 练货 ◁ 选货
```

## DAY2：客资增量体系（详解）

> 详细见 [[customer_asset_system]] 概念页

### 客资经营理念：价值关系 > 情感关系

### 新客开发运营体系
- 增量计划：店铺节点 60% / 非店铺节点 35% / 顾客投诉 3-5%
- 核心：精准人货对接

### 老客维护经营体系
- 老客三计划：惊艳计划、衣橱计划、情感计划
- 顾客关怀/建议/生活方式 + 产品关怀/建议/生活方式
- 老客的分类管理和情感温度管理
- 老客的回店计划与频率

### 新老客分析
- 新客老客占比
- 各级数量比
- 各级金额比

### 客资经营体系的价值链

```
成交 ◁ 分类管理 ◁ 情感经营 ◁ 大单计划 ◁ 回店计划 ◁【邀约计划+引流计划】
```
