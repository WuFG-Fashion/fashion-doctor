# Polars 1.42 自适应云I/O与矛盾过滤器消除

> **一句话摘要**：Polars 1.42（2026-06-29 发布）带来自适应云 I/O 并发（TPC-H SF=1000 整体 2x、I/O 查询最高 4x）、6 类矛盾过滤器自动折叠、DataFrame/Expr 级别 is_sorted()。

## 核心要点

1. **自适应云 I/O 并发**：动态调整云存储并发请求数，基于实测带宽和延迟，64 vCPU TPC-H SF=1000 整体 2x 提升、I/O 密集查询最高 4x
2. **矛盾过滤器消除**：识别 6 类矛盾（逻辑否定/反向比较/空成员/不相交范围/非重叠区间/范围外相等），折叠为空结果，零扫描零计算
3. **is_sorted() 扩展**：从 Series 扩展到 DataFrame 和 Expr 级别，可用于 select/filter，支持 descending 和 nulls_last
4. **零 API 变更**：云 I/O 优化自动生效，无需修改任何代码
5. 与 [[polars_vs_pandas_2026|Polars vs Pandas 选型]] 和 [[duckdb_olap_engine_2026|DuckDB OLAP引擎]] 构成完整的 Python 数据处理引擎生态

## 详细内容

### 性能数据

| 特性 | 数据 |
|------|------|
| 基准环境 | TPC-H SF=1000, 64 vCPU |
| 云 I/O 整体提升 | **2x** |
| I/O 密集查询提升 | 最高 **4x** |
| 矛盾过滤生效条件 | 6 类矛盾模式自动识别 |
| is_sorted() 状态 | unstable（实验性） |

### 矛盾过滤器 6 类模式

1. **逻辑否定**：A AND NOT(A)
2. **反向比较**：x > 5 AND x <= 5
3. **空成员**：is_in([])
4. **不相交范围**：a > 5 AND a < 3
5. **非重叠区间**：is_between(4,6) AND is_between(0,2)
6. **范围外相等**：a == 5 AND a > 10

适用于程序化构建的谓词（参数化过滤器），low > high 时自动短路，避免无效扫描和计算。
