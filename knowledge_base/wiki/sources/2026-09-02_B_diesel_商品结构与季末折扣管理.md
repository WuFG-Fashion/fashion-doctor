# Diesel 商品结构与季末折扣管理（B轮·2026-09-02）

> **一句话摘要**：Diesel 商品组合 = 丹宁核心 + 1DR bag hero 款引爆 + 三档价格阶梯（入门配饰→core 丹宁→皮革/鞋履/runway capsules），季末集中 markdown 保护正价售罄、奥莱分区隔离折扣价，非核心品类走授权（L'Oréal 香氛/Marcolin 眼镜/Fossil 手表）。
> **来源**：wiki/raw/articles/2026-09-02_B_diesel_商品结构与季末折扣管理.md（行业媒体拆解 + FW26 大秀 + 授权公告）
> **置信度**：第三方数据（媒体/分析师口径）/ 品牌自宣（FW26 与授权信息）
> **brand_specific**：true（Diesel 品牌特有，双链至 [[diesel]]）

## 核心要点
- **hero 款策略**：1DR bag 单款引爆——承担引流与话题，主力丹宁款承接转化（"话题款 + 主销款"双轨）。
- **价格阶梯**：入门配饰（引流）→ core 丹宁（主销）→ 皮革/鞋履/runway capsules（形象与毛利）三档。
- **季末策略**：集中 markdown（统一大促时点）保护正价期售罄率——"正价期不轻易打折、季末集中出清"。
- **奥莱分区**：折扣商品进奥莱分区，与正价渠道物理隔离，防止价格体系混乱。
- **授权扩品类**：香氛/眼镜/手表授权（L'Oréal/Marcolin/Fossil）——低投入扩品类面。
- **FW26 大秀**：树脂压褶/3D 丹宁 + 50,000 档案物件，维持品牌叙事与溢价（媒体评价销量趋好）。

## 详细内容
| 结构层 | 角色 | 管理动作 |
|---|---|---|
| hero 款（1DR） | 引流/话题 | 单款集中资源 |
| 入门配饰 | 引流/试水 | 低客单拉新 |
| core 丹宁 | 主销/现金流 | 深度保障 |
| 皮革/鞋履/capsules | 形象/毛利 | 少量高溢价 |
| 奥莱分区 | 清货/隔离 | 不与正价混售 |
| 授权品类 | 品类扩展 | 吃授权费+曝光 |

## 结论
- Diesel 的"**季末集中 markdown + 奥莱物理隔离**"与 [[cabbeen|卡宾]] 的"27.9% 平均深度折扣"形成直接对照：集中出清保护正价期利润与品牌调性，而全季折扣侵蚀的是正价售罄率与毛利——这是商品折扣策略的第一性差异。
- "hero 款引爆 + 主力款承接"的双轨结构可迁移：单款承担话题与流量（联名/大秀/病毒内容），主力款吃转化——比"均匀铺款等自然动销"更符合注意力经济。
- 授权扩品类（香氛/眼镜/表）提示多品类品牌不必自建产能——低毛利非核心品类外包，把库存与运营成本转成授权费，同时扩大品牌触点。
- 价格阶梯三档（引流/主销/形象）与 B 轮通用方法论（主力 50-60%/引流 15-25%/形象 10-20%）互证，Diesel 提供国际品牌落地样本。
