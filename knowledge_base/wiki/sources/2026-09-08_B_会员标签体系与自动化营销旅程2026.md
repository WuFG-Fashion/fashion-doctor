# 会员标签体系与自动化营销旅程 2026（B轮·2026-09-08）

> **一句话摘要**：标签是"把人看清楚"，MA 自动化旅程是"到点自动干活"——人群包按生命周期拆分、触发式旅程（新客 D1/D3/D7、弃单 1h/24h、唤醒 D1/D3/D5 逐步加码）、触达后行为回流画布重新判分支；热风案例 500+ 标签带来老客复购 +57%、会员成交 +40%。
> **来源**：raw/articles/2026-09-08_B_会员标签体系与自动化营销旅程2026.md（网易智企 / 慧博科技 / 橙子 CRM / 易神软件 / 新普软件 聚合）
> **置信度**：媒体估算（SCRM/私域服务商案例文，业绩数据为厂商自宣口径，须谨慎引用；热风/衡韵丝绸等为具名客户案例）
> **brand_specific**：false（行业通用方法论，双链至 concept 不链品牌；具名品牌仅作案例引证不建品牌实体链接）

## 核心要点
- **标签五维**：基础属性 / 消费频次 / 商品偏好 / 活跃状态 / 生命周期——热风案例 500+ 标签覆盖 360° 画像；服饰专属补充风格/尺码/价位/上新敏感度。
- **人群包 = 规则的动态集合**：按生命周期拆分（积分到期/当月生日/优惠敏感）各配专属话术与券；**每轮触达后客户行为与属性回流画布、重新决定下一分支**——这是人群包区别于"一次群发"的关键。
- **MA 触发式旅程示例节奏**：新客首单 D1 搭配建议+洗涤指南 → D3 关联推荐 → D7 复购券 + 入社群；弃单 1h 企微提醒、24h 小额定向券；沉默唤醒 D1 见面礼 → D3 爆款推荐 → D5 互动抽奖（逐步加码）；生日 T-7 预告 / T0 礼券 / T+3 返场。
- **验收指标（五率）**：复购率 = 周期内重复购买客户数 / 总活跃客户数；加粉率；互动率（触达后一周 ÷ 送达）；转化率；触达效率（非退订非屏蔽）——每轮人群包上线至少观察两周再做策略调优。
- **前置工程：全渠道归一**：案例 300 多万会员中能统一识别运营的不到四成（六成"影子会员"）——手机号主键 + 设备/地址辅助 + 人工复核兜底，置信度低先挂起不合并。

## 结论
1. **自动化旅程的价值锚点是"回流重判"而非"触达次数"**：人群包每次触达后行为回传、重新分流，才让旅程从线性广播变成自适应运营——没有回流设计的 MA 只是换了个名字的群发。
2. **标签体系是分层运营的弹药库**：RFM 只解决"值多少钱"，风格/尺码/价格带/上新敏感度标签解决"推什么合适"——500+ 标签不是堆数量，是让每一条自动化触达都"像内行推荐"。
3. **先归一、后自动化**：六成"影子会员"意味着不先做全渠道身份合并，一切旅程都打在残缺画像上——归一是自动化的前置工程而非可选项。
4. **对 Fashion Doctor 的落地含义**：本页的旅程模板（D1/D3/D7 节奏）与五率验收口径可直接作为会员运营模块的流程基准；具名品牌业绩（热风 +57% 等）只作文案参照，不得入 kpi 硬基准。
