# 艾诺丝雅诗 AW PROJECT 重奢拓店清单 / 母公司集团化（A1·2026-08-23）

> **一句话摘要**：艾诺丝雅诗第二曲线 AW PROJECT 2026H1 加速重奢商圈拓店——上海港汇恒隆首店首日破 60 万、进驻北京 SKP / 深圳万象城 / 南京德基，以"主品牌供应链复用 + 重奢首店试探高净值客群"验证中端女装上探轻奢路径；母公司杭州爱唯时尚集团多品牌矩阵成型。
> **来源**：[[2026-08-23_A1_ariose_years_AW_PROJECT重奢拓店]]
> **最后更新**：2026-08-23

## 核心要点
- **重奢拓店清单**：AW PROJECT 2026H1 进驻上海港汇恒隆（首店首日破 60 万）、北京 SKP、深圳万象城、南京德基等重奢商场。
- **第二曲线定位**：轻奢设计师线（2024-09 推出），对标国际奢牌面料，客群 30–45 岁高净值女性，承接主品牌 1800+ 店规模红利。
- **母公司集团化**：杭州爱唯服饰 2025-12-17 更名「杭州爱唯时尚集团」，主品牌 + AW PROJECT + RicoVea（接棒退潮 CHUU）多品牌矩阵成型。
- **规模基线**：主品牌 2026-03 全国 1,800+ 店、年销约 50 亿、百万会员（第三方媒体 corroborate，置信度：品牌自宣+第三方 corroboration）。

## 结论
1. **AW PROJECT 是"中端女装上探轻奢"的高风险高回报试验**：重奢首店首日 60 万证明高净值客群存在，但重奢租金/动销能否持续需观察，对 [[peacebird|太平鸟]] 评估"副线向上"路径有近距离样本。
2. **母公司更名释放资本化前奏**：集团化通常先于融资/上市动作，艾诺丝从"区域黑马"向"集团化平台"跃迁，与双核多品牌集团路径可类比但资本化差距显著。
3. **主品牌规模是第二曲线的底气**：1,800+ 店供应链/渠道复用使 AW PROJECT 试错成本低于独立轻奢品牌，印证"主品牌规模 → 副线孵化"的复用逻辑。
