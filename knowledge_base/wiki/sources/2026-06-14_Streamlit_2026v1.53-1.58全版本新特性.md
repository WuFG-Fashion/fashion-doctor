# Streamlit 2026全版本新特性 v1.53→v1.58

> **一句话摘要**：Streamlit 2026年上半年6个版本全面升级——Tornado→Starlette架构迁移、5个全新组件(st.menu_button/st.iframe/st.bottom/st.pagination/Parallel Fragment)、Polars Arrow零拷贝、AI Skills内置、pandas 3.x支持。
> **来源**：Streamlit Official 2026 Release Notes
> **最后更新**：2026-06-14

## 核心要点

1. **架构革命**：v1.53实验性Starlette → v1.57正式默认Starlette/Uvicorn，ASGI兼容
2. **5个全新组件**：st.menu_button(v1.56)、st.iframe(v1.56)、st.bottom(v1.57)、st.pagination(v1.58)、@st.fragment并行(v1.58)
3. **Polars原生**：v1.57 Polars DataFrame直接转Arrow零拷贝，完全绕过Pandas
4. **AI加持**：内置AI代理技能、streamlit skills CLI、`:shimmer[]`动画文本
5. **Widget身份机制过渡**：多数组件有key时仅基于key识别，防止状态重置

## 详细内容

### 版本发射表

| 版本 | 日期 | 核心突破 |
|------|------|---------|
| v1.53 | 2026-01-14 | Starlette实验性/st.App ASGI入口/缓存会话级作用域 |
| v1.54 | 2026-02-04 | Widget key身份机制过渡/experimental彻底移除/主题图表增强 |
| v1.55 | 2026-03-03 | 动态容器on_change/Page visibility/widget bind/st.metric delta_description |
| v1.56 | 2026-03-31 | st.menu_button+st.iframe/dataframe增强/pandas 3.x/st.Page外部URL |
| v1.57 | 2026-04-29 | **Starlette正式默认**/st.bottom/Polars Arrow零拷贝/:shimmer[]/AI技能内置 |
| v1.58 | 2026-05-28 | st.pagination/@st.fragment parallel=true/streamlit skills CLI |

### 对服装零售看板的关键价值

- **Starlette生产部署**：对接企业级ASGI中间件（认证/限流/监控）
- **Polars零拷贝**：超大SKU数据管道直接渲染，避免转换开销
- **@st.fragment并行**：多品牌Dashboard并行加载，首屏提速
- **st.menu_button + st.pagination**：品牌切换+SKU分页增强交互
