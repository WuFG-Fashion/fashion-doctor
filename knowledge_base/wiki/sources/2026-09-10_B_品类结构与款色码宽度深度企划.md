# 品类结构与款色码宽度深度企划（B轮·2026-09-10）

> **一句话摘要**：商品企划的结构层是"**品类占比 → 款宽度 → 色/码深度**"三层递进——品类先保刚需（裤子）与高毛利，宽度用 SPS 反推（100㎡ 店 120–180 款、200㎡ 200–280 款），色码深度用"中性色打底 + 趋势色点缀 + 以销定码"校准；落地成一张采购单就是 **50%–60% 核心中性色 + 25%–30% 趋势色 + 10%–15% Hero 款 + 0–5% 押注**。
> **来源**：raw/articles/2026-09-10_B_品类结构与款色码宽度深度企划.md（2026 春夏服饰趋势洞察 / 买手采购框架 / 门店报表口径 聚合）
> **置信度**：媒体估算（平台趋势报告 + 买手方法论文 + 门店报表口径；平台互动量为平台自披露口径）
> **brand_specific**：false（行业通用方法论，双链至 concept 不链品牌）

## 核心要点
- **结构层的第一问是"品类占比"，不是"选什么款"**：先定上装/下装/外套/内搭的占比，再定款宽度，最后定色/码深度——**只追趋势不做结构，结果是"爆款断码、冷款压库"**。
- **品类结构的健康校验 = 库存分布 vs 销售占比是否匹配**："上装占 80% 库存但只占 50% 销售额"即品类结构失衡；配套红线是库龄 > 60 天占比 **> 20% 需加快清仓**。
- **宽度用 SPS 反推，不靠感觉**（kb_benchmarks.sps_model）：SPS 健康 8 / 警戒 5 / 过窄 20；**100㎡ 店 120–180 款、200㎡ 店 200–280 款**；超限 20% 出现绩效拐点。品类差异化：基础款 15–30 / 核心款 8–15 / 形象款 2–5 / 配饰 20–40。
- **色深度：中性色是基本盘**——30 岁以上客群**中性色销量是彩色 3:1**；建议围绕中性色搭目录，**亮粉/电光蓝只做点缀不进核心深度**；2026 商业色板为"暖而稳"（奶油黄/鼠尾草绿/赤陶/摩卡慕斯）。
- **码深度：以销定码 + 断码损失分析**——M/L 码占总销量 60%+ 时进货按此比例；量化"哪些款因断码导致销售下降"。
- **采购配比框架（把三层落成一张单）**：50%–60% 核心中性色 + 25%–30% 趋势色板 + 10%–15% Hero/statement + 0%–5% Wildcards——**配比做对，售罄率会在流量没涨的情况下先涨**。

## 详细内容

### 1. 第一层：品类占比（需求侧信号 + 健康校验）

**2026 春夏需求侧品类信号**（平台声量口径）：
- 核心品类：**上装、鞋靴、下装**；**鞋靴声量同比 +40%**（增速最快），配饰及包包需求增长；上装与下装同比声量下降。
- **男女装共有的刚需 = 裤子**；女装高热 = 裙子 + 针织衫；男装核心 = 外套 + 休闲鞋。
- 上装：**外套声量领先**（基础保暖品类），**针织衫同比 +20% 以上**（冬春过渡核心单品）。
- 下装：**宽松版型主导**（阔腿裤、喇叭裤居热度中心），**弯刀裤声量增速领跑**。
- 品类分布（2026 上半年女士服装）：连衣裙份额稳定（碎花/纯色/拼接为主）；裤装品类扩大（阔腿/直筒/微喇轮换）；外套以西装、风衣、针织开衫为主，轻薄羽绒进夏季空调房场景。

**门店侧健康校验**：
- **品类库存分布 vs 品类销售占比是否匹配**——不匹配即结构失衡。
- 库龄 > 60 天占比 **> 20% 需加快清仓**。
- 商品复盘看**周转天数**（单品"活"了多久）：连衣裙平均周转 30 天、某款摆 45 天没卖完 → 查陈列位置或尺码完整性。

### 2. 第二层：款宽度（多少个款）

| 店型/面积 | 建议款式数 |
|---|---|
| 100㎡ | 120–180 款 |
| 200㎡ | 200–280 款 |
| 导购可记忆款数 | 40–60 款 |

- **SPS 口径**：SPS 健康值 8、警戒 5、过窄 20；**超限 20% 即出现绩效拐点**。
- **品类 SPS 差异化**：基础款 15–30（靠宽度铺量）/ 核心款 8–15 / 形象款 2–5（靠深度做调性）/ 配饰 20–40。
- **宽度过宽的直接代价**：导购记不住、单款店均效率被摊薄；年 SKU 自然膨胀 **12%–18%**，需主动做减法，减 SKU 目标 **15%–25%**。

### 3. 第三层：色深度与码深度

**色系结构**：
- **中性色是基本盘**：真中性色（燕麦 oat / 象牙 ivory / 浓缩咖啡 espresso / 炭灰 charcoal）——**30 岁以上客群中性色销量是彩色 3:1**；**围绕中性色搭目录，彩色只作点缀**。
- **避免在核心库存押亮色**：亮粉、电光蓝只做点缀款，不进核心深度。
- **2026 商业色板（暖而稳）**：奶油黄（butter yellow）、鼠尾草绿（sage）、赤陶（terracotta）、摩卡慕斯（mocha mousse）。
- 平台侧色彩信号：帕斯蒂尔低饱和风、盐系海滨淡蓝、复古摩登（红 + 奶油 + 深宝蓝 + 大地色）；大地色系占主流（卡其/驼色/燕麦），亮色小面积点缀，渐变回归。
- **材质即溢价**：客户愿为"100% 亚麻"标签**多付 30%–40%**；亚麻混纺（linen-cotton/linen-viscose）动销好，但廉价亚麻"会刮、退货率翻倍"。

**尺码结构**：
- **以销定码**：颜色尺码销售分析报表 → M/L 码占总销量 60%+ 时，进货按此比例配置。
- **断码损失分析**：量化"哪些款因断码导致销售下降、多少潜在销售流失"——断码是"看得见却没抓住"的损失。
- 尺码覆盖面趋势：**从 S–XL 扩展到 XXS–5XL**（性别中性品类尤其）；大码（plus size）仍是**需求最未被满足的品类**——关键是找真正做过大码试身的供应商，而非简单"放码"。

### 4. 采购配比框架（结构三层的落地单）

| 配比 | 类型 | 说明 |
|---|---|---|
| **50%–60%** | 核心中性色 | 最好卖的廓形 × 2–3 个中性色（目录的底盘） |
| **25%–30%** | 趋势色板款 | 奶油黄/赤陶/摩卡等当季色 |
| **10%–15%** | Hero / statement 件 | 那件"驱动社交传播"的连衣裙或外套 |
| **0%–5%** | Wildcards | 直觉押注，用来补完目录 |

> 原则：**宁可"卖断再补单"，也不要压一季库存**。

### 5. 优先级排序逻辑

- **刚需品类（裤子）保宽度 → 高毛利品类保深度 → 形象品类保调性（少量）**。
- 上装/下装/外套/内搭的占比**没有通用答案**，须用**自身品类的销售占比 + 毛利结构**反推，而非照抄行业报告。
- 趋势决定"选什么色/什么廓形"，**结构决定"每个色/每个码备多深"**。

> ℹ️ **基准核对**：①本页引用的 SPS 值（健康 8/警戒 5/过窄 20）、店型款式数（100㎡ 120–180 / 200㎡ 200–280）、品类 SPS（基础 15–30/核心 8–15/形象 2–5/配饰 20–40）、导购可记忆款数（40–60）、减 SKU 目标（15%–25%）、年 SKU 膨胀（12%–18%）**全部取自库内既有基准**（kb_benchmarks.sps_model / sku_rationalization，源自 [[2026-08-07_单款店均效率SPS与款式宽度反推模型]]），本页未新增数值，仅做"三层结构"的编排整合；②"库龄 > 60 天占比 > 20% 需清仓"与 kb_benchmarks.lifecycle_sell_through 的售罄目标（day_30 0.30 / day_45 0.425）为**不同指标**（库龄结构 vs 售罄进度），非矛盾；③中性色 3:1、亚麻溢价 30%–40%、XXS–5XL 覆盖面为买手/平台口径，属趋势与经验值，**不写入 kb_benchmarks**。

## 结论
1. **商品企划的结构层必须按"品类 → 款 → 色 → 码"的顺序决策**：顺序颠倒（先选款再想品类占比）是"爆款断码 + 冷款压库"同时出现的根因——**宽度决定能不能覆盖需求，深度决定能不能接住需求**。
2. **宽度不是越多越好，而是由店型面积与 SPS 反推出来的**：100㎡ 店 120–180 款、200㎡ 200–280 款，超过 20% 就出现绩效拐点；同时导购可记忆款数只有 40–60 款——**超过这个数的款，实质上是在消耗导购的推荐能力**。
3. **色深度的核心是"把中性色当底盘、把彩色当点缀"**：30+ 客群中性色销量 3 倍于彩色，把亮色铺进核心深度是最常见的库存事故；2026 商业色板偏"暖而稳"，与库内中性色基本盘判断一致。
4. **对 Fashion Doctor 的落地含义**：本页三层结构可直接落成"品类结构表 + 款色码深度表"两张分析表——①按品类看"库存占比 vs 销售占比 vs 毛利占比"三角，②按色/码看"销售占比 vs 库存占比"错配；其中"断码损失"与"品类结构失衡"是两个此前未被单独量化过的分析口径，建议纳入商品分析模块。
