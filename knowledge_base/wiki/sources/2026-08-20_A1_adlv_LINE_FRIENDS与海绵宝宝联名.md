# ADLV LINE FRIENDS 与海绵宝宝联名（A1·2026-08-20）

> **一句话摘要**：ADLV 2026 连续拿下 LINE FRIENDS（3 月）与海绵宝宝 SpongeBob（4 月）两大角色 IP 联名，以"萌趣角色 + 无性别街头"巩固韩潮少女盘；中国内地门店约 14 家、深圳大悦城店待开，扩张克制。
> **来源**：[[2026-08-20_adlv_LINE_FRIENDS与海绵宝宝联名]]
> **最后更新**：2026-08-20

## 核心要点
- LINE FRIENDS 联名（2026-03）：布朗熊 / 莎莉是鸡等角色，15 周年特别版，覆盖女款短袖 T 恤、长袖 T 恤、连帽拉链卫衣、基础 LOGO 套装。
- 海绵宝宝特别系列（2026-04-17，尼克国际儿童频道 IP）：以短袖 T 恤线为核心，扩展连帽卫衣、拉链连帽衫、长裤、短裤、牛仔单品；配色黑/白 + 海军蓝/粉/棕，部分扎染与颜料染；含钥匙扣、袜子、帽子配饰。设计上角色图案不大面积直铺正面，调节到自然融入日常。
- 中国内地约 14 家店：上海 MOHO、天津南开大悦城、长春红旗街万达、大连恒隆、沈阳皇城恒隆、大连柏威年等；深圳大悦城店即将开业（商业地产媒体盘点口径）。

## 结论
1. ADLV 用"萌趣角色 IP + 无性别街头"打法，与 [[chuu|CHUU]] 的甜辣韩潮、[[peacebird|太平鸟]] 的联名 IP 爆款逻辑同源，是可对标的中端潮牌样本，但门店规模（~14）远小于 CHUU（300+）。
2. 角色图案"克制植入"显示 ADLV 从"大脸宝宝"单符号向"完整系列"升级，规避"一次性活动商品"陷阱，是其产品力成熟的信号。
3. 中国 ~14 店数据为媒体盘点（非财报），且韩潮近年在中国有退潮风险，引用须标注"媒体估算"口径（门店数置信度低于品牌自宣的联名信息）。
