# 库存多维分析框架（临时收集提炼）

> **一句话摘要**：库存分析不能只看数量或单一周转率，要从「价值—结构—库龄—动销—效益—动作」六步展开，并结合 ABC-XYZ 分类与库存毛利回报率，才能判断钱压在哪、哪些该补、哪些该清。
> **来源**：临时收集/2026-08-23/公众号-库存分析怎么做（李启方）
> **最后更新**：2026-08-28

## 核心要点

- **价值**：`库存金额 = 数量 × 单位成本`；警惕「高金额 + 低周转」。拆到品类/SKU/仓库/供应商看资金占用。
- **结构**：总量正常≠结构健康；看品类结构（金额占比 vs 销售占比 vs 毛利占比）、仓库结构（局部缺货/积压）、渠道结构。
- **库龄**：0-30 正常 / 31-60 关注 / 61-90 预警 / 90+ 高风险 / 180+ 重点清理；必须和处理动作挂钩（>60天查因、>90天冻补、>180天评跌价）。
- **动销**：可销天数 = 库存 ÷ 日均销量；SKU 分高库存高动销/高库低动/低库高动/低库低动/有库无销。
- **ABC-XYZ**：A 类约 10-20% SKU→70-80% 销售利润；结合 X 稳定/Y 波动/Z 随机得 AX…CZ 差异化策略。
- **效益**：`库存毛利回报率 = 毛利额 ÷ 平均库存金额`，比单纯周转更接近经营结果；分高周转高毛利/高周转低毛利/低周转高毛利/低周转低毛利。

## 详细内容

六步框架：① 总览（金额/数量/周转天数/动销率/滞销额/缺货 SKU）② 价值（拆金额）③ 结构（品类/仓库/库龄/渠道）④ 动销（销量/可销天数/售罄率）⑤ 效益（周转+毛利）⑥ 动作（补货/清理/调拨/预警清单 + 责任部门）。

> **置信度**：媒体估算（公众号 FineBI 推广文；库龄分层与 ABC 比例为通用方法论，非审计来源）。
