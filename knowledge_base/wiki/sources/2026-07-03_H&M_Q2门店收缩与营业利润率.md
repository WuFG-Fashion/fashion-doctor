# H&M Q2全球门店收缩至4038家，营业利润率稳固12%

> **一句话摘要**：H&M 2026Q2全球门店缩减至4038家（关停128家），营业利润率12%，线上占比突破30%，亚太为主要收缩区。
> **来源**：全球纺织网 (m.tnc.com.cn)，原始资料见 `raw/articles/2026-07-03_全球纺织网_H&M_Q2门店收缩与营业利润率.md`
> **最后更新**：2026-07-11

## 核心要点

1. Q2关停128家低效门店，**全球门店总量4038家**
2. 营业利润率稳固在**12%**，成本管控见效
3. 线上销售占比突破**30%**
4. 亚太（含中国）为主要收缩区域，COS/&Other Stories拓店节奏全面放缓
5. 夹在ZARA（高端快时尚）与SHEIN（极致性价比）之间，品牌定位模糊

## 详细内容

### 门店变化

| 指标 | 数值 |
|------|------|
| 全球门店总数 | 4,038家 |
| Q2关停门店 | 128家 |
| 线上占比 | >30% |
| 营业利润率 | 12% |

### 区域分化

- **西欧**：本土成熟市场客流基本稳定
- **新兴市场**（巴西/东南亚）：小幅增长
- **亚太（含中国）**：主要收缩区域，主品牌+COS/&Other Stories全线放缓

### 竞争困境

H&M正面临"双向挤压"：
- **上方**：ZARA凭面料质感、精细化门店运营、差异化设计站稳高端快时尚
- **下方**：SHEIN依托极致性价比、超快上新速度、柔性供应链锁定年轻消费群体
- **自身**：品牌定位模糊、设计创新滞后、线上转型节奏缓慢
