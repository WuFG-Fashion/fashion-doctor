# DKNY 母公司 G-III FY2027 Q2 财报实际 + Marc Jacobs 收购完成

> **一句话摘要**：G-III（NASDAQ:GIII）FY2027 Q2（截至 2026-07-31）实际营收 $554.1M（-10%，略逊一致预期 $570M），non-GAAP EPS $0.26 超预期且**上调全年指引**；毛利率扩张 440bp 至 45.2%；**2026-09-01 完成 Marc Jacobs 运营业务收购**（目标长期年营收 $1B，FY2027 小幅摊薄）。
> **来源**：SEC 8-K EX-99.1（2026-09-02 财报原文）/ MarketReview / GuruFocus / Zacks / TipRanks
> **最后更新**：2026-09-03

> **置信度**：财报（SEC 8-K 业绩发布原文；GAAP/Non-GAAP 数值为公司披露口径，未经审计）
> **brand_specific**：true（品牌特有财务数据 → 双链 [[dkny]]）

## 核心要点
- **Q2 实际 vs 预告（09-02 前页）**：营收 $554.1M（-9.6%/-10%，上年 $613.3M），**低于一致预期 $570.4M 与管理层指引 $570M**（miss 约 3%）；non-GAAP EPS $0.26（上年 $0.25），**高于一致预期 $0.23 并顶格超出管理层指引上沿 $0.25**。
- **毛利率大幅扩张**：45.2%（+440bp，上年 40.8%），驱动为提价 + 自有高毛利品牌占比提升；毛利 $250.4M 与上年 $250.5M 几乎持平（营收降 $59M 但毛利未降）。
- **GAAP 利润含一次性项**：净利 $20.2M / diluted EPS $0.46（上年 $10.9M/$0.25），内含 $9.3M 估值备抵释放税益 + $3.1M 关税退税利息收入；剔除后 adj 净利 $11.5M / EPS $0.26。
- **费用与营业利润剪刀差**：SG&A $231.4M（+2%，占销售 41.8% vs 37% 费用去杠杆）；营业利润降至 $10.8M（上年 $16.3M）；adj EBITDA $20.2M（-13.1%）。毛利率改善未完全传导至营业利润。
- **资产负债表强化**：现金 $529.2M（上年 $301.8M）；库存 $555M（-13%）；总债务仅 $7.8M；股东权益 $1.82B；净现金约 $521.4M；本季股东回报 $12.2M（回购 $7.9M + 股息 $4.3M）。
- **Marc Jacobs 收购完成（2026-09-01 交割，早于财报一日）**：IPCo 持有 Marc Jacobs IP，G-III 收购运营业务并获多区域/多品类长期独家授权；目标长期年营收 $1B；预计 FY2027 小幅摊薄（交割后 12 个月内摊薄、此后增厚）。
- **FY2027 指引上调**：净销售 ~$2.71B（已含 CK/Tommy 流失约 $460M；上年 $2.96B，维持）；GAAP 净利 $181-185M / EPS $4.10-4.20（自 $171-175M / $3.85-3.95 上调）；non-GAAP 净利 $97-101M / EPS $2.20-2.30（自 $95-99M / $2.15-2.25 上调）；adj EBITDA 降至 $174-178M（自 $178-182M）；税率假设 25.2%（原 30%）；指引不含 Marc Jacobs。
- **Q3 FY27 展望**：净销售 ~$870M（上年 $988.6M）；净利 $59-64M / EPS $1.35-1.45。
- **组合与股价**：自有 10 品牌（现含 Marc Jacobs/DKNY/Donna Karan/Karl Lagerfeld/Sonia Rykiel/Vilebrequin）+ 授权 20+；go-forward 组合（去 CK/Tommy）高个位数增长；股价约 $32.15（市值 $1.37B），TipRanks 共识 Hold / PT $38，GuruFocus GF Score 75/100、较 GF Value $26.46 高估约 21.5%。

## 详细内容
### 预告→实际的兑现度（上轮待办核验）
09-02 前页预告的一致预期为 EPS $0.23、营收 $570.4M。实际结果为 **EPS 层面全面超越（GAAP $0.46 / non-GAAP $0.26 均 beat）**，但 **营收层面 miss（$554.1M < $570M）**——印证「beat 来自毛利率扩张与税项/利息，而非销售增长」的判断。管理层因此**上调全年 GAAP/Non-GAAP EPS 指引**但**下调 adj EBITDA 区间**（费用去杠杆所致），属「利润口径上修 + 现金口径谨慎」的组合。

### Marc Jacobs 交易结构（G-III 组合层跃迁）
交割日（09-01）与财报发布（09-02）相邻，显示交易与再融资/现金储备安排同步。结构为 IPCo（IP 持有）与 G-III（运营 + 长期独家授权）分持，G-III 以 $529M 现金储备支撑整合、总债务仅 $7.8M 提供加杠杆空间。管理层把 Marc Jacobs 定位为 CK/Tommy 授权流失后的增长接力棒（目标 $1B 长期年营收，约相当于流失规模的 2 倍以上）。

### 对 DKNY 的意义
DKNY 与 Marc Jacobs 同属 G-III 自有品牌核心，未来将在集团资源（设计/供应链/渠道管理/资金）上并行竞争。Q2 后 G-III 现金充裕（净现金 $521M）但 FY2027 需消化 MJ 摊薄 + CK/Tommy 授权滚落，DKNY 中国直营扩张（上海淮海路首店 2026-05-16）的资金弹性取决于集团组合优先级排序。

## 结论
1. **预告→实际核验闭环：「beat 来自毛利扩张与一次性项，而非增长」**——non-GAAP EPS $0.26 顶格超出指引、全年指引上调，但营收 miss、营业利润与 adj EBITDA 双降。判断 G-III 健康度须看 go-forward 组合高个位数增长 + 毛利率 45.2%（置信度：财报）。
2. **Marc Jacobs 收购 = G-III「授权商 → 自有品牌集团」的质变节点**：以 CK/Tommy 授权流失为代价换自有品牌池扩张，与 [[karl_lagerfeld]]（G-III 授权组合）共享母公司资源。DKNY 中国扩张的资源约束短期缓解（现金 $529M），但 MJ 整合期集团重心或倾斜，单品牌门店仍黑箱（置信度：媒体估算，交易长期影响为管理层展望）。
3. **对双核/品牌墙参照**：品牌墙授权代理品牌（[[品牌墙概念与代理模式]]）若走「收回直营/自有化」路径，G-III 是完整样本——自有化带来毛利率跃升（+440bp），但短期必付 SG&A 去杠杆与利润波动代价；授权组合模式可平抑单品牌周期（置信度：财报推断）。
4. **低净利 + 高分红 + 强现金的组合仍在延续**：G-III 承压期维持股息 + 加码回购，以股东回报稳估值，压缩单品牌（含 DKNY）再投入弹性——与 09-02 前页判断一致，已获实际数据确认（置信度：财报）。
