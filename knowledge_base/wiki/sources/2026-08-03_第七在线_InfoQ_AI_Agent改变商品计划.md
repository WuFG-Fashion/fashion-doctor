# AI Agent 正在改变商品计划：从事后复盘到提前决策（第七在线 / InfoQ）

> 一句话摘要：AI Agent 不替商品团队做决定，而是把商品计划从"一次性作业"推向"持续推演"，实现 7×24 监控、动态推演与提前决策，让决策窗口从"事后"拉到"事前"。

> 来源：第七在线，InfoQ 写作社区 xie.infoq.cn/article/337699ac36cdbac74de07122a，2026-07-10
> 最后更新：2026-08-03

## 核心要点

1. **五变化**：①持续推演（计划变"活页"）②主动预警+根因诊断 ③经验可验证可校准 ④统一经营模型（部门协同）⑤事前沙盘推演（替代事后复盘）。
2. **内核**：持续监控 + 动态推演 + 提前决策；"库存是结果，决策才是源头"。
3. **四大前提（差一个即落不了地）**：数据打通（POS/ERP/财务 T+1 同口径）、规则建模（首单上下限/可销周数安全线/周转警戒线）、权限机制（Agent 不替人拍板）、业务闭环（预警→判断→执行→反馈回流）。

## 关键数据（案例值）

| 案例 | 指标变化 |
|------|----------|
| 卫衣华东增速>30% | 可销周数 4周→1.6周；调拨后恢复 3.2周；**+28万销售 / 1.2万调拨成本 / +2.3pp 售罄** |
| 华北11店某SKU | 可销周数降至 **1.2周**（安全线 2周）；根因首单30%（计划35%）；**追加 250件** |
| 经验校准（首单40%→45%） | 方向正确概率 **72%**；华东转化 −15% / 周转 +12天 |
