# MR&MRS ITALY 2025-2026 中国渠道复兴（2026-08-31 A3）

> **一句话摘要**：MR&MRS ITALY（慕漫翊）在 2023 以中文名「慕漫翊」+ 天猫国际回归中国后，2025-12 落地上海静安嘉里中心冬季限时快闪店，2026 进一步在合肥银泰中心开设专门店，渠道从「快闪试探」走向「常态专门店」，延续高端派克大衣的小众奢侈模型。

> **最后更新**：2026-08-31

## 核心要点
- **2023 回归路径**：2023 年以中文名「慕漫翊」回归中国市场，成立关联公司慕漫翊(北京)贸易有限公司，并正式入驻天猫国际开启新品全球首发。
- **2025-12 上海快闪**：2025 年 12 月 21 日，MR&MRS ITALY 冬日限时快闪店登陆**上海静安嘉里中心**北区一层；主打男女同款皮草派克服（Luna 短款 / Venere 长款）、羽绒服（Valentina / Diamante 系列）与 Grazia 飞行员夹克，近十种皮草内胆配色。
- **2026 合肥专门店**：2026 年品牌在**合肥银泰中心**开设专门店，标志渠道从「冬季快闪试探」升级为「常态专门店」节奏。
- **品类位次**：买购网 Maigoo《派克服十大品牌 2026》将 MR&MRS ITALY 列为第 **3** 位（前有 CanadaGoose、OZLANA），运营主体标注为慕漫翊(北京)贸易有限公司——与 2026-08-19 A3 轮录得的「第 3 位 / 人气指数 6678 约为 CanadaGoose 37%」一致，本次为时序复验确认。

## 详细内容（全维度）
### 门店 / 渠道 / 线下事件
- 2023：回归中国，中文名「慕漫翊」，天猫国际入驻。
- 2025-12-21：上海静安嘉里中心（北区一层）冬日限时快闪店。
- 2026：合肥银泰中心专门店（常态门店，非快闪）。
- 历史渠道过山车：2017 大中华区 4 家直营（香港 IFC / 海港城、北京国贸、上海恒隆）→ 7 家 → 2020 中国 13 家 → 疫情退出 → 2023 回归（详见 [[mr_mrs]] 实体页 S3 渠道信号补全）。

### 产品 / 营销
- 标志性产品：手工皮草内衬派克大衣（parka），100% 意大利制造；2025 冬季系列强化「男女同款 + 中性叛逆」语言，皮草内胆配色扩展至慕绿 / 漫粉 / 青花瓷 / 丹霞 / 星辉等近十色。
- 爆红资产：韩剧《来自星星的你》全智贤同款军绿派克，仍是亚洲认知锚点。

### 行业 / 竞品
- 中国高端御寒外套呈「1 个头部（CanadaGoose）+ 并列第二梯队（OZLANA / MR&MRS ITALY）」结构；MR&MRS ITALY 以「影视同款 + 意式皮草工艺」切入，与 [[peacebird|太平鸟]] 的联名 IP 打法、[[cabbeen|卡宾]] 的设计师溢价路线形成「外牌 vs 国牌」高端对照。
