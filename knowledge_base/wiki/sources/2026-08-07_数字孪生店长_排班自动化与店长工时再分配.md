# AI 数字孪生店长 — 排班自动化与店长工时再分配

> **一句话摘要**：店长工时中约 40% 为可自动化事项（排班 15% + 日报 12% 占大头），AI 数字孪生店长将排班耗时从 3 小时/周压到 20 分钟/周（-89%），带教时间占比由 25% 提升至 35%–40%，人效提升 8%–12%。

## 核心数据

| 指标 | 数值 |
|---|---|
| 店长可自动化工时占比 | ~40% |
| 排班耗时 | 3 小时/周 → 20 分钟/周（-89%） |
| 带教时间占比 | 25% → 35%–40% |
| 人效（人均销售额）提升 | 8%–12% |
| 高峰时段人力覆盖率 | 65%–70% → 85%+ |
| 客流曲线训练所需历史数据 | 8–12 周 |

## 店长工时结构

| 事项 | 占比 | 可自动化 |
|---|---|---|
| 排班与考勤 | 15% | 高 |
| 数据统计与日报 | 12% | 高 |
| 巡店检查 | 10% | 中（AI 视觉） |
| 库存盘点/调拨 | 8% | 中 |
| 带教与沟通 | 25% | 否（核心价值） |
| 顾客接待与异常 | 20% | 否 |
| 其他行政 | 10% | 中 |

## 与已有知识的衔接

- **闭环了 [[2026-08-07_帷幄_鞋服导购四象限评估与五项行为指标]] 留下的问题**：帷幄指出"潜力型导购（高能力低产出）根因是排班与客流错配"，本源恰好给出解法——智能排班使高峰时段人力覆盖率从 65%–70% 提升至 85%+，直接消解该错配。**两源构成"诊断—处方"的完整链路。**
- **对 [[导购培训闭环体系]] 的补充**：闭环体系依赖店长承担"带教"角色，但店长带教时间此前仅占 25%；排班/日报自动化把带教时间释放到 35%–40%，是闭环得以跑通的**前置资源条件**。
- **对 [[服装门店经营AI化2026]] 的补充**：既有页面偏重"AI 面向顾客侧"（导购辅助、试穿、诊断），本源补入"AI 面向管理侧"（排班、日报、巡店），构成门店 AI 化的另一半。

## 与既有基准的核对

- 本源"人效提升 8%–12%"为新增指标，`kb_benchmarks.json` 中无对应项，**无矛盾**；建议新增 `store_ops.labor_efficiency_boost = 0.08~0.12`。
- 本源"店长带教时间 25%→35%–40%"为新增口径，无冲突。

## 落地前提（三条硬约束）
1. 8–12 周客流历史数据
2. POS / 会员 / 考勤三系统打通
3. "AI 出班表、人改班表"的人机协作模式，非全自动
