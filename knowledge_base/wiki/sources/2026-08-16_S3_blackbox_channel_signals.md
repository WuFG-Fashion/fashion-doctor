# S3·6黑箱品牌渠道信号补全

> **一句话摘要**：针对 S轮遗留的 6 个"门店数黑箱"品牌（awoken_space / dkny / ellesse / koyo / mr_mrs / nerdy），做定向第三方检索补全渠道信号——nerdy 经历"爆发→2024代理危机→大撤退"、mr_mrs 经历"进入→扩张→疫情退出→2023回归"过山车、koyo 50+ 一线商场获多源 corroborate；awoken_space 副线仍黑箱（仅同体系 AWOKEN TIME 集合店可间接推断）。

## 各品牌渠道信号

### 1. AWOKEN SPACE（中国本土潮流副线）— 仍黑箱
- 副线独立门店数：**未披露**（公开资料极少）。
- 同体系 **AWOKEN TIME 潮流集合店**：武汉已 4 家（武商梦时代 / 经开永旺 / 龙湖江宸天街 / 武商MALL），南昌 / 襄阳有店，单店超 800㎡（赢商网 2024）。
- 商标：AWOKEN SPACE 第25类 2023-03 注册（阿里云商标）。
- 信号：SPACE 副线独立数据黑箱，渠道信号仅能从同体系 TIME 集合店间接推断（武汉集群 + 场景店模式）。

### 2. DKNY（G-III 授权 / 美国都市品牌）
- DKNY Jeans 内地：约 **44 家**（全球十六大牛仔品牌 doc，2007 上海首店）。
- DKNY 全系中国：约 **20 家**（含香港 / 上海，wikiwand 较旧口径）。
- 渠道：天猫 2017 即在售（电商先行）；2026-05 上海淮海中路首店 ~245㎡（实体已记）；母公司 G-III FY2026 销售 -7% 承压。
- 信号：中国门店 modest（~20–44 依产品线），电商 + 首店试探，典型授权代理模式。

### 3. ellesse（Pentland / 百丽时尚）
- 中国运营：**百丽时尚（Belle）** 旗下服饰品牌之一（新浪 2024）。
- 渠道：天猫 / 京东有售，**线下门店较少**（第三方评测）；定位"被低估的中端"。
- 全球：Pentland 区域授权，中国是 key partner（WWD）。
- 信号：中国电商为主、线下少，百丽时尚运营，门店数黑箱。

### 4. KOYO JEANS（广州高龙 / 香港设计师）
- 中国网点：**入驻国内一线商场 50+ 家**（猎聘 / 好猎头 / 赶集 多源 corroborate）。
- HKDI 宽泛口径："业务扩展至中国大陆 over 100 cities"。
- 门店含香港海港城、广州太古汇、成都 IFS、长沙 IFS 等。
- 信号：50+ 一线商场获多源 corroborate，渠道信号明确（高端商场密集），门店数仍黑箱。

### 5. MR&MRS ITALY（意大利皮草夫妇）— 过山车
- 中国门店轨迹：**2017 大中华区 4 家直营**（香港 IFC / 海港城、北京国贸、上海恒隆）→ 7 家 → **2020 中国 13 家** → 疫情陆续退出 → **2023 携新系列回归中国**，成立关联公司 **慕漫翊(北京)贸易**，中文名"慕漫翊"。
- 当前（2026）回归后门店数未清晰披露（黑箱），由慕漫翊(北京)贸易运营。
- 信号：经历"进入→扩张→疫情退出→2023回归"完整周期，渠道信号 = 弘毅资本加持 + 慕漫翊运营。

### 6. NERDY（韩国 / MODEUS / 杭州弗娜瑞）— 爆发→危机→大撤退
- 2020 入华、线上火；**2022-08 中国超 60 家门店**（搜狗百科）；2023 实体门店超 60 家、预估 2024 达 120 家（潮新闻 2023-12）。
- **2024-08 代理权危机**：韩国品牌方解除杭州呢滴（原总代理）合约，称其供货假冒；杭州呢滴反控强制高价采买库存。
- **2024-12 天猫旗舰店关店**（最后发货 2024-12-31），OUTLET 店仍可售；**2025 杭州线下仅剩武林银泰 1 处**（43nx.cn）。
- 信号：韩潮代理模式脆弱性的极端样本，渠道信号 2024–2025 剧烈恶化（60+ 店 → 杭州仅 1 家）。

## 交叉验证结论
1. **渠道信号可得性分化**：koyo（50+ 商场多源 corroborate）、nerdy/mr_mrs（轨迹清晰）信号强；awoken_space 副线仍真黑箱。
2. **代理/授权模式是黑箱根因**：nerdy（杭州呢滴代理危机）、mr_mrs（弘毅+慕漫翊更替）、dkny/ellesse（G-III/百丽授权）均因代理结构导致单品牌门店数不透明。
3. **韩潮代理模式脆弱性实证**：nerdy 从 60+ 店到杭州仅 1 家，是 S轮"韩潮退潮/授权代理结构性脆弱"风险的最强单案例，建议回流 [[brand_risk_signals_2026]]。
