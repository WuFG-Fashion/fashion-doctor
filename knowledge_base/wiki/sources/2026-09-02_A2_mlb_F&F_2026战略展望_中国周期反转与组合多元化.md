# F&F 2026 战略展望——中国 MLB 周期反转、库存矫正与品牌组合多元化

> **一句话摘要**：第三方深度分析揭示 F&F（KOSPI 091970）当前核心命题：中国 MLB 正从"2019-2022 三年浪潮"进入周期回摆（宏观降温 + 街头风见顶 + 分销库存雪崩三因叠加），F&F 以"库存矫正 + 扩直营 + 收紧促销"公开对冲，基准情形是稳定在更低但可持续的 run rate 并重定位为一线城市高端玩法；组合层通过 Duvetica 全资收购、Sergio Tacchini 亚洲授权、HYBE 持股构建"后 MLB"第二增长曲线。

## 核心要点

- **中国 MLB 周期定性（新增·战略层）**：2019 年入华（天猫旗舰店）后 2019-2022 三年浪潮（营收利润倍增），当前三因叠加回摆：①宏观（中国可选消费结构性疲软/地产/青年失业）②街头风周期反转（oversized logo 与棒球帽潮流见顶，转向 minimal/quiet-luxury/technical outdoor/heritage Americana）③**分销库存雪崩**（批发渠道上行期过度订货 → 折扣雪崩 → 价格体系受损 → 多季度发货低于 sell-out）（置信度：媒体估算）。
- **F&F 矫正动作（新增）**：公开推进 **normalizing distributor days（库存天数正常化）＋ 扩大直营店 + 收紧促销**，修复价格体系（置信度：媒体估算）。
- **基准情形判断（新增）**：中国 MLB **不会"再次爆发"**，更可能**稳定在更低但可持续的 run rate**，品牌重新定位为 **tier-1 一线城市高端玩法**而非大众街头现象（置信度：媒体估算）。
- **品牌组合多元化（新增）**：Discovery Expedition（韩国户外现金牛，中国为苦战——Arc'teryx/TNF/Columbia/本土 Pelliot·Toread 拥挤）｜**Duvetica（F&F 首个全资奢侈 IP**，意大利高端羽绒，类比 Moncler 之下第二梯队，需多年重建）｜**Sergio Tacchini（亚洲授权，heritage tennis 风，潜在"下一个 MLB"）**｜Stretch Angels（配饰/年轻女性）｜**HYBE 持股（K-pop 联名与粉丝营销）**（置信度：媒体估算）。
- **MLB 中国渠道颗粒（第三方）**：截至 2025-02，MLB 中国大陆覆盖 **263 城、1185 家直营门店**（上海 61 家直营+旗舰）；棒球帽"平均每 6.3 秒售出一顶"、占品牌销量约 **25%**；2026-08 林一任 MLB 潮流品牌青春代言人（置信度：第三方数据）。
- **MLB Kids 产品侧（新增·弱）**：韩国市场 MLB Kids 公开 2026 秋冬系列（活力健康→街头风格，T恤/卫衣/风衣+鞋帽），与韩国童装品牌普遍"提前布局换季羽绒服"应对缩短换季期同步（置信度：媒体估算）。

## 结论

1. **中国 MLB 的叙事从"增长故事"切换为"周期管理故事"**：Daylongs 把三连跌归因于宏观 + 街头周期 + 分销库存三因共振——其中**分销库存雪崩是品牌可干预项**（正常化库存天数/扩直营/收紧促销），而宏观与潮流周期不可控。对 Fashion Doctor 的直接启示：**品牌墙/代理模式品牌若在批发渠道过度放量，sell-through 走弱时折扣雪崩会反噬价格体系**——这与 [[karl_lagerfeld]] 奥莱加速是同一风险的不同面（主动去库存 vs 被动崩价）。
2. **"授权模式"的风险敞口被 Daylongs 量化**：MLB 是"租来的 IP"（F&F 无所有权），组合层 Duvetica 全资收购正是 F&F 对冲授权依赖的动作——"从租 IP 到买 IP"是 [[品牌墙概念与代理模式]] 中品牌生命周期的高级阶段，值得作为代理公司（原 MODING 操盘集合）的长期演进参照。
3. **Sergio Tacchini 是下轮重点观察对象**：heritage tennis 风 + 亚洲授权 + "下一个 MLB"潜力，若其营收在分部披露中单独出现，即进入加速期——与 [[lacoste]]（网球基因品牌）形成同赛道对照。
4. **对双核启示**：MLB 中国 1,185 直营店（2025-02）的规模对应"一线城市高端化"再定位，与 [[peacebird|太平鸟]] 直营提质、[[cabbeen|卡宾]] 代销化转型互为参照——渠道广度之后拼的是**单店产出与价格纪律**。
