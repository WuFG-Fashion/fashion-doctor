# Levi's 印度 500 店里程碑与日本双联名（Shinzone / JOURNAL STANDARD relume）

## 核心要点
- **印度 500 店里程碑 + 扩面战略**：Levi's India 已突破第 500 家门店，印度位列其全球前六大市场；但增长杠杆已从"开店数"转向**关键城市扩面**（Mumbai / Bengaluru / Delhi + Chandigarh / Pune / Ahmedabad / Chennai）。ICON 大店格式贡献约 **1/5（~20%）** 印度 DTC 营收。
- **超牛仔品类宽化**：女装以**高双位数**增长、增速超男装；印度市场"每买 1 件下装对应 >1 件上装"（全球为 1:3）；Red Loop 高端休闲线占男装约 **15%**、高双位数增长——印证"从牛仔裤品牌→丹宁生活方式品牌"的全球定位转型。
- **本土化供应链**：>95% 印度在售产品本地制造，10 人设计团队、约 **85% 为 India-for-India 原创设计**，支撑高响应速度。
- **日本双联名（2026 夏）**：① Shinzone「Re-edit 90's」2026-08-14 线上预售 / 08-28 日本 Levi's 与 Shinzone 直营店发售（第二本 lookbook，截至 08-12 未宣发美/国际）；② JOURNAL STANDARD relume 硬丹宁胶囊（TYPE 1/TYPE 2 Trucker + 1947 501 Selvedge），2026-08-07 预售/发售，日本市场。

## 详细内容
（综合 ETRetail / RetailNewsAsia / The Hindu BusinessLine / DFU Publications 2026-08 报道；Hiren Gor, MD-SAMEA 访谈口径）

- **门店与渠道**：集团 FY25 全球营收 **$6.3B**，设 **$10B** 目标；印度为最关键贡献市场之一。FY24 印度销售 **₹1,668.7 crore**，利润 **₹159.4 crore（-13.4%）**。截至 5 月季度（Q2 FY2026）：集团净营收 **$1.6B +8% YoY**，亚洲 **+10%**（与 2026-08-30 入库 Q2 FY2026 口径一致）。
- **品类结构**：女装高双位数增长、上装 "每下装对应 >1 上装"（全球 1:3）；Red Loop 占男装约 15%、高双位数增长——"denim lifestyle" 扩品类落地。
- **供应链**：>95% 印度在售本地制造，10 人设计团队、约 85% India-for-India 原创设计；印度同时"为全球生产"，承接供应链多元化。
- **日本联名**：Shinzone「Re-edit 90's」为第二本 lookbook，2026-08-14 预售、08-28 日本双渠道发售；JOURNAL STANDARD relume 复刻档案硬丹宁（TYPE 1/TYPE 2 Trucker + 1947 501 Selvedge），2026-08-07 预售/发售，均限日本市场。

## 结论
1. **印度是 Levi's 全球 $10B 野心的核心增量市场**，但其增长杠杆已从"铺店"转为"扩面 + 品类宽化（女装 / 上装 / Red Loop）"——对中国市场的启示：门店数不是护城河，**单店产出与品类广度**才是。
2. **超牛仔化（denim lifestyle）是 Levi's 全球统一战略**，日本以"档案复刻联名（Shinzone / JOURNAL STANDARD relume）"承接高端 / 收藏需求，与中国市场的明星 / 文化联名打法形成对照。
3. **本土化供应链（>95% 本地制造）是印度高响应的根基**，与 [[服装行业竞争格局]] 中"近岸 / 本地化产能对冲关税与时效"判断一致，也是其敢于在新兴市场做深度产品本地化的前提。
