# AWOKEN TIME 白猿宇宙 IP / 武汉多店清单 / 外拓（A1·2026-08-23）

## 核心要点
- **白猿宇宙 IP**：自有原创 IP「白猿宇宙」，武商梦时代设 8.7 米白猿装置作为地标打卡点，用空间叙事替代单纯卖货。
- **武汉多店清单**：梦时代（8.7 米白猿）/ 武商MALL 国广店（800㎡ 旗舰）/ 江宸天街 / 经开永旺 / 江夏永旺，单城集群密度高。
- **外拓城市**：襄阳武商 / 宜昌国贸 / 南昌武商已落店；上海泗泾招商花园城（2026 四季度）已签约。
- **模式**：服装+时尚咖啡区+潮玩/生活用品，场景打卡+KOL 驱动到店，对标新一代国潮集合店。

1. **AWOKEN TIME 用"自有 IP + 场景店"做区域深耕**：白猿宇宙 8.7 米装置是低成本高传播的地标，单城多店密度摊薄租金/营销，对 [[peacebird|太平鸟]]「门店体验化」方向有近距离参照。
