# 服装SKU进销存管理优化

> **一句话摘要**：简道云发布的服装SKU进销存优化方法论——通过ABC分类管理使热销SKU占比从20%提升至65%，库存周转从3次/年提升至5次/年，缺货率降低25%。

> **原始文件**：`wiki/raw/articles/2026-06-06_简道云_服装SKU进销存管理优化.md`

## 核心要点

1. **ABC分类使热销SKU占比20%→65%**，库存周转率+67%（3→5次/年）
2. **合理安全库存使缺货率-25%**，配合安全库存公式实现科学补货
3. **库存准确率提升至98%**，订单处理时间缩短40%
4. **8维度补货数据决策**：30/60/90天销量、周转天数、在途库存、同期对比等
5. **四阶段推进路径**：数据统一→流程梳理→系统上线→数据复盘

## 关键优化数据

| 指标 | 优化前 | 优化后 | 幅度 |
|------|--------|--------|------|
| 热销SKU占比 | 20% | **65%** | +225% |
| 库存周转率 | 3次/年 | **5次/年** | +67% |
| 库存成本 | - | - | **-15%** |
| 库存准确率 | - | **98%** | - |
| 缺货率 | - | - | **-25%** |
| 订单处理时间 | - | - | **-40%** |

## 核心方法论

### 安全库存公式
```
安全库存量 = 最大日销量 × 最大补货时间 - 平均日销量 × 平均补货时间
补货点 = 安全库存 + 预计在途消耗
```

### 滞销SKU识别
- 连续30天无销售
- 连续60天销量低于阈值
- 库存周转天数显著高于同类

### 调拨优于采购
某门店缺货时，优先系统识别其他门店/仓库富余库存进行调拨
