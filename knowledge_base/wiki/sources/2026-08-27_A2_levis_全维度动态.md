# LEVI'S 2026 全维度动态（Q1/Q2 财报/中国复苏/联名营销）

> **一句话摘要**：Levi Strauss & Co.（NYSE: LEVI，CEO Michelle Gass）2026 加速"DTC 优先 + 丹宁生活方式"转型，Q1 营收 $1.74B（+14.1%）、Q2 $1.56B（+8%/有机+6%）、DTC 占比首破 51%；中国市场在 Burberry 前高管 Anita Fung 操盘下回暖，成都太古里/武汉旗舰 + 马年限定 + Rosé 联名驱动。
> **来源**：Levi's 投资者关系 Q2 新闻稿 / Nasdaq 业绩会纪要 / 今日头条 / Inside Retail
> **置信度**：财报（NYSE 披露）
> **brand_specific**：true
> **最后更新**：2026-08-27

## 核心要点

- **Q1 CY2026**：净营收 $1.74B（+14.1%，超预期 $1.65B），adj EPS $0.42（+14.4%）；门店 1,232 家（同比 +31）；DTC 占比首破 50%；中国"从平淡到积极"反弹。
- **Q2（截至 2026-05-31）**：净营收 $1.56B（+8% 报告 / +6% 有机），经营利润率 7.8%（+35bps），adj EBIT 利润率 9.0%（+70bps），adj EPS $0.28（+27%）；**DTC 占 51%**，电商 +19%，Asia +12%（有机）；连续第 17 个季度同店增长。
- **全年指引上调**：FY2026 报告营收 +7.0–7.5%、有机 +5.5–6.0%，adj EPS $1.46–1.52；股息 +14% 至 $0.16/股。
- **品类**：女装 +11%、上衣 +5–7%、Beyond Yoga +16%、白丹宁女装 +70%；"头部到脚"生活方式扩张贡献约 1/3 增量。
- **中国复苏**：2026-03 任命 Anita Fung（前 Burberry / Alexander McQueen）为大中华区 MD；收缩 51 家低效特许经营店后转攻旗舰店（成都太古里、武汉旗舰）；2026 马年限定系列；Rosé（BLACKPINK）× Levi's「Behind Every Original」台北/成都快闪。
- **全球营销**：Super Bowl（2026-02）「Behind Every Original」全球战役（影片 Backstory，导演 Kim Gehrig，主演 Rosé / SGA / Questlove）；2026 FIFA 世界杯（美/墨/英/法足协授权，Levi's Stadium Logo 被遮成病毒营销）；大使 Belinda、Alia Bhatt。

## 结论

1. Levi's 2026 的超额增长来自**"DTC 优先 + 女装/上衣扩张 + 高端化（Blue Tab）"**三杠杆，与 [[服装行业竞争格局]] 中"直营化 + 品类拓宽"趋势一致；DTC 占比破 51% 标志其已从丹宁裤商转型为生活方式品牌。
2. 中国"关低效店 → 请奢品高管 → 攻旗舰 + 文化联名"的打法，对 [[peacebird|太平鸟]]/[[cabbeen|卡宾]] 有参照价值：以组织升级（引入高端零售人才）驱动品牌势能，比单纯铺店更可持续。
3. 与 [[mlb]]（IP 授权高增）不同，Levi's 靠自有品牌产品力 + 营销大投放；二者共同印证"2026 全球服装主线是 DTC 与品牌资产重估"。财报口径清晰，可直接纳入竞品财务基准。
