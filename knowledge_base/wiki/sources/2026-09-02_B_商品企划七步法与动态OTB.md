# 商品企划七步法与动态 OTB（B轮·2026-09-02）

> **一句话摘要**：商品企划 = MFP→OTB→品类→波段→SKU→配补货→复盘七步链路；首单 ≤60-70% 留 30-40% 灵活采购给快反，类目库存 120 天门控防止现金被库存占用。
> **来源**：wiki/raw/articles/2026-09-02_B_商品企划七步法与动态OTB.md（GSBF + 中国鞋服商品计划指南 + Eightx）
> **置信度**：第三方数据（行业方法论）/ 媒体估算（可调参数）
> **brand_specific**：false（通用方法论，双链至 concept 不链品牌）

## 核心要点
- **七步链路**：MFP（年度商品财务计划）→ OTB（采购预算）→ 品类结构 → 波段 → SKU 规划 → 配补货 → 售罄复盘；上一步输出是下一步输入。
- **品类分配**：40/30/15/15（主/次/机会/形象）或款型口径"主力 50-60% / 引流 15-25% / 形象 10-20%"。
- **assortment 平衡**：depth（深度保主销）vs breadth（广度覆盖需求），按品类角色取舍防 SKU 摊薄。
- **现金门控 OTB**：类目库存 ≤120 天；首单 25-30% 总量控制 + 30-40% 灵活采购（快反/追单）；避免 130% 现金被库存占用。
- **OTB 公式**：OTB = 预期销售 - 期初库存 + 目标期末库存。

## 详细内容
| 环节 | 要点 | 风险提示 |
|---|---|---|
| MFP | 年度销售/折扣/毛利预算 | 无 MFP 则 OTB 无锚 |
| OTB | 首单 60-70% + 30-40% 灵活预算 | 首单过高 → 错判即库存 |
| 品类 | 40/30/15/15 或主力/引流/形象 | 平均用力 → 无重点 |
| 波段 | 分波投放（见波段源） | 一次性铺货 → 无节奏 |
| SKU | depth/breadth 平衡 | 铺 SKU → 摊薄单款深度 |
| 配补货 | 快反窗口追单 | 缺补货机制 → 断码 |

## 结论
- 商品企划的本质是"**把不确定性留给预算而非库存**"：首单 60-70% + 30-40% 灵活采购，把错判成本从"压库存"转成"追单机会成本"，对快时尚/设计师品牌都适用。
- 品类角色分权（主力保售罄、引流保客流、形象保品牌）防止平均用力——对照 [[cabbeen|卡宾]] 2026 春夏售罄率 48.4% vs 2025 系列 73.8% 的分化，可推断其货盘结构在主力款命中上出了问题。
- 现金门控（120 天库存上限）是中小品牌的生命线：库存周转天数超过现金周期即资金链风险，OTB 审批应先过"现金占用"关卡。
