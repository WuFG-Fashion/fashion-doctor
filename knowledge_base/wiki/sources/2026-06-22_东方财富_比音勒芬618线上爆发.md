# 比音勒芬2026年618线上全面爆发

> **一句话摘要**：比音勒芬2026年618全线上渠道同比翻倍以上，抖音+337%/天猫+126%/京东首小时20倍+，线上占比仅10%增长弹性极大，618超预期将支撑Q2营收延续高增。
> **来源**：东方财富网 (https://caifuhao.eastmoney.com/news/20260619144836780946150)
> **最后更新**：2026-06-22

## 核心要点

1. 全线上渠道同比翻倍以上，天猫/抖音/京东三大平台均100%+增长
2. 抖音销售额同比+337%，男装类目增速全平台第一
3. 线上营收占比仅10%（海澜之家21%/波司登35%），渗透率远低于同行，增长弹性极大
4. 5.16首届T恤节全渠道单日破1亿，线上贡献约6000万元
5. 客单价稳定千元以上，高端男装线上转化表现突出

### 增长驱动力

1. **管理层加码线上**：2026年全面加大抖音直播、天猫运营、京东会员运营投入
2. **产品适配线上**：推出线上专属凉感、轻量化户外款，平衡线下价格体系
3. **渠道红利**：线上收入占比仅10%，远低于海澜之家(21%)、波司登(35%)
4. **多品牌协同**：主品牌冲量 + 肯迪文百年庆典同步线上联动

### 业绩影响

- 券商一致预判：618超预期将支撑2026Q2营收延续高增（Q1营收同比+18.36%）
- 线上渠道有望持续放量，全年电商收入增速维持高位
- 打开第二增长曲线

### 风险提示

- 线上增速基数低（2025年线上占比仅10%），高增速可持续性待验证
- 线下价格体系与线上平衡是关键挑战
