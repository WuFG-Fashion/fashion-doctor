# 季前商品计划波段OTB与SKU款深决策

> **一句话摘要**：商品计划六层拆解链路——销售目标→渠道→品类→波段→OTB→SKU款深，波段是OTB管理基本单位，首单70-80%/快反15-25%。
> **来源**：百家号 2026-06-29
> **最后更新**：2026-07-09

## 核心要点

1. 正确拆解链路：销售目标→渠道→品类→波段→OTB→SKU款深（六层不可跳过）
2. 波段是OTB管理的基本单位，不是过渡层
3. SKU是OTB计算后的输出结果，不是计划起点
4. 首单OTB(期货)70-80% + 快反OTB池15-25%
5. SKU款深三维框架：品类结构+价格带结构+款式结构(引流/核心/利润/形象)

## 详细内容

### 六层拆解链路
```
销售目标 → 渠道目标 → 品类目标 → 波段目标 → 波段内OTB预算 → SKU数量与款深
```

示例（10亿元年度目标→春季2.5亿→女装2亿→连衣裙3500万→春一波2000万→OTB→SKU）

### OTB三大铁律
1. 波段OTB额度必须在下单截止日前完成授权（不等于订货会开始日）
2. OTB决策必须在订货会启动前至少2-3周完成
3. 系统提前14天预警OTB未授权风险

### 上市倒推模型
```
上市时间 → 交期(10周) → 物流 → 仓库 → 下单截止日 → OTB授权完成时间
```

### SKU款深四型
| 类型 | 深度 | 定位 |
|------|------|------|
| 引流款 | 浅 | 快速测试市场 |
| 核心款 | 最深 | 主力销售转化 |
| 利润款 | 中等 | 贡献毛利 |
| 形象款 | 最浅 | 制造稀缺感 |

### 常见致命错误
- SKU当计划起点 → 应按OTB约束倒推
- 品类OTB直接跳到供应商OTB（跳过波段）→ 无法追踪波段预算消耗
- OTB走审批时交期窗口已关闭 → 货晚30天=全季失败
