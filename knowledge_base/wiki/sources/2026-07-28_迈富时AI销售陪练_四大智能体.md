# 迈富时 AI 销售陪练：四大智能体赋能服装导购（Marketingforce，2026）

> **一句话摘要**：迈富时为某2000+门店头部服装品牌部署AI销售陪练，以四大智能体（角色模拟/金牌话术收集/产品专业问答/攻防模拟）降低新人学习成本、提升成交率与人均成交金额。
> **来源**：marketingforce.com/about/newsshow/1821.html（迈富时/珍岛，2026 CDIE 杰出AI创新技术服务商）
> **最后更新**：2026-07-28

## 核心要点

1. 场景：头部服装品牌 **2000+门店导购**，头部vs尾部成交差数倍，门店流动率高，新人靠自我摸索
2. 四大智能体：AI角色模拟Agent / AI金牌话术收集Agent / AI产品专业问答Agent（面料洗护尺码即时查）/ AI攻防模拟Agent（犹豫客户抛价格质量难题）
3. 效果：新人学习成本明显降低，进店成交率与人均成交金额有效提升
4. 多智能体协同（Agentforce中台）从"单点工具"到"AI原生组织"

## 详细内容

### 四大智能体职能
| 智能体 | 职能 |
|--------|------|
| AI角色模拟 | 模拟不同客户类型与场景 |
| AI金牌话术收集 | 萃取高频成交话术反馈导购 |
| AI产品专业问答 | 面料/洗护/尺码知识即时查询 |
| AI攻防模拟 | 扮演犹豫客户训练精准应对 |
