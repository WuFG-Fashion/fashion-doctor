# 高端男装RFM沉默会员筛选 + AI导购唤醒（有赞）

> 一句话摘要：30年/400店高端男装品牌靠"RFM筛20-30%高价值沉默会员 + AI生成优先联系名单与话术 + 前15天只做服务"组合，唤醒老客贡献76%的老客收入增长（整体+45%），导购任务执行率40%→95%。

> 来源：有赞生意专家（youzan.com/blog/articles/77244），2026-05-28；采集 2026-08-05（Round B / L2_03 会员与VIP运营）

## 核心要点

1. **高客单男装三重劣势**：复购周期长（西装穿两三年）、离店即失联、导购管不过来（一人几百会员全靠人记）。
2. **RFM筛沉默会员**：圈"高金额但近期无动静"与"频次稳定但突然断掉"两类，合计约占沉默会员 **20%–30%**，贡献后续激活收入绝大部分；其余暂不投入。
3. **AI替导购三件事**：自动生成每日优先联系名单（基于浏览行为+购买周期+RFM）、按画像生成差异化话术、基于历史偏好做场景化搭配推荐（非单品群发）。
4. **铁律——前15天只做服务**：新加企微/重新激活会员前15天不发促销，做售后回访/穿着建议/保养提醒/换季搭配咨询。
