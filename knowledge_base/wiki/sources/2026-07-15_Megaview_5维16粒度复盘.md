# Megaview AI陪练 — 5维16粒度复盘机制

> **一句话摘要**：Megaview Agent Team架构（Customer Agent + Coach Agent），200+场景/100+客户画像，5大维度16个粒度量化评分，知识留存72%/新人上岗6月→2月。

> **来源**：wiki/raw/articles/2026-07-15_Megaview_AI陪练复盘机制5维16粒度深度.md
> **最后更新**：2026-07-15

## 核心要点

1. Agent Team多智能体协作：Customer Agent（模拟客户）+ Coach Agent（AI教练）
2. 5大维度16个粒度评分：表达能力/需求挖掘/异议处理/成交推进/合规表达
3. 知识留存率72%（vs传统20%），新人上岗6个月→2个月
4. 场景引擎覆盖早市rush/家庭客群/促销对抗/会员回访四种逻辑
5. 传统角色扮演仅覆盖35%实际客情，AI可实现动态压力模拟

## 详细内容

### 5维16粒度评分体系

| 维度 | 细分指标 |
|------|----------|
| 表达能力 | 语速/流利度/逻辑结构/情绪管理 |
| 需求挖掘 | 场景探询/痛点确认/决策因素排序/SPIN暗示性问题 |
| 异议处理 | 认同-重构-确认节奏/竞品对比/价格异议 |
| 成交推进 | closing时机/封闭提问/方案自然过渡 |
| 合规表达 | 风险点识别/政策准确度 |

### 训练效果对比

| KPI | 传统培训 | AI陪练 | 提升 |
|------|----------|--------|------|
| 知识留存率 | ~20% | 72% | +3.6x |
| 新人上岗周期 | 6个月 | 2个月 | -67% |
| 主管陪练时间 | 全职 | -50% | 释放人力 |
| 需求挖掘完整性 | 基线 | +34% | — |
| 成交周期 | 基线 | -22% | — |
| 沉默应对流失 | 基线 | -40% | 反应时间4.7s→1.2s |

### 场景引擎能力

- 四种对话逻辑：早市rush/家庭客群/促销对抗/会员回访
- 传统角色扮演仅覆盖35%客情
- AI可模拟"带竞品报价单""多人打断"等复杂场景
- 非营业时间/碎片化时段高频对练

### 知识沉淀闭环

销冠经典对话→拆解为学习模块→反哺AI客户行为模式→训练场景持续进化。高绩效经验不再随人员离职流失。
