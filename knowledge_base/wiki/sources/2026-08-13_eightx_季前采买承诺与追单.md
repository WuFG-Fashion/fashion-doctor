# 季前采买前置承诺vs预留追单的2026实操

> **一句话摘要**：按 SKU 属性三分位承诺（基础款 75–85%/核心款 60–75%/时尚款 40–60%），A/B/C rank 深买 A 类，OTB 70/30 且储备金不低于品类 10–15%。
> **来源**：https://eightx.co/blog/preseason-inventory-buying
> **最后更新**：2026-08-13

## 核心要点

- 三分位前置承诺比例：Replenishable basics 75–85%、Seasonal core 60–75%、High-fashion 40–60%。
- A/B/C rank：按销量与毛利排序，仅 A 类深买，C 类丢弃/代发，B 类浅买。
- OTB = 计划销售 + 计划 markdown + 计划期末库存 − 期初库存 − 在途；先零售后转成本。
- 70/30 政策 + 储备金纪律：季末前不低于品类 10–15%，按周售罄分 2–4 波释放。

## 详细内容

| 分位 | 前置承诺 | OTB 储备 |
|------|----------|----------|
| 可补基础款 | 75–85% | 15–25% |
| 季节核心款 | 60–75% | 25–40% |
| 时尚/实验款 | 40–60% | 40–60% |

OTB 实例（Q4 夹克，零售口径）：销售 $1,000,000 + markdown $100,000 + 期末 $150,000 − 期初 $300,000 = $950,000；50% 毛利下成本约 $475,000；70/30 拆 $665K 承诺 / $285K 追单。
