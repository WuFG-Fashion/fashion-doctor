# Python 数据分析与可视化完整工作流 2026

> **一句话摘要**：CRISP-DM 七步工作流 + Pandas/Polars/DuckDB 三件套选型矩阵 + EDA 三大分析 + 可视化全家桶，针对服装零售场景映射每个步骤。

> **来源**：CSDN（https://blog.csdn.net/likuoelie/article/details/161007752）
> **最后更新**：2026-06-12

## 核心要点

1. **CRISP-DM 七步**：定义问题→数据获取→清洗→EDA→特征工程→建模→沟通，每步映射服装零售场景
2. **三件套选型**：Pandas(10万行以下)/Polars(百万-千万行)/DuckDB(亿级)，按数据规模选择
3. **EDA 三类**：单变量(直方图/箱线图)+多变量(热力图/散点图)+时间序列(趋势/季节性)
4. **可视化栈**：Matplotlib→Seaborn→Plotly Express(交互)→Altair+Great Tables→ydata-profiling(自动化)
5. **服装零售图表推荐**：Treemap(品类占比)/Sankey(转化路径)/热力图(库存周转)/散点图(价格-销量)

## 详细内容

### 七步工作流 × 服装零售

| 步骤 | 零售示例 |
|------|---------|
| 定义问题 | 提升季度销售额？哪些品类库存慢？ |
| 数据获取 | 销售/用户行为/库存/广告 |
| 数据清洗 | 退货负值/缺失尺码/重复订单 |
| EDA | 品类/季节/渠道趋势分析 |
| 特征工程 | 利润率/环比/客单价 |
| 建模 | 销量预测/区域热销 |
| 沟通 | 周报/仪表盘 |

### 选型矩阵（按数据规模）

| 规模 | 工具 | 场景 |
|------|------|------|
| <10万行 | Pandas | 单店日销/周报 |
| 百万-千万行 | Polars | 全渠道月销/RFM |
| 亿级行 | DuckDB | 供应链/复杂SQL |

### 可视化工具推荐

| 需求 | 图表 | 工具 |
|------|------|------|
| 品类占比 | Treemap | Plotly |
| 月度趋势 | 折线图 | Seaborn/Plotly |
| 转化路径 | Sankey | Plotly |
| 区域分布 | 地图热力图 | Folium |
| 价格-销量 | scatter+color | Plotly Express |
| 库存周转 | 热力图 | Seaborn |

### 学习路线
1. 1-2周：NumPy+Pandas+Matplotlib → 品牌CSV分析
2. 2-4周：EDA+Plotly+Kaggle → Superstore Sales
3. 持续：Polars+Streamlit → 实时销售仪表盘
