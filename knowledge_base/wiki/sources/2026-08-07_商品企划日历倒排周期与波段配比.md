# 商品企划日历 — 倒排开发周期、双轨配比与波段节奏

> **一句话摘要**：企划失控多因"只有终点没有里程碑"；标准期货制从定调到上市约 9 个月（T-9 定调 / T-6 面料确认 / T-5 一轮样衣评审淘汰 30–40% / T-3.5 订货会 / T-3 大货下单 / T 上市 / T+2周 翻单决策）；快反可压缩至 30–45 天但通常仅覆盖 20%–40% 款式；一季 3–5 波段，首波占 30%–35%，超过 45% 会导致季中断新品。

## 倒排关键节点（T = 上市日）

| 节点 | 时间 | 交付物 |
|---|---|---|
| 趋势与企划定调 | T-9 月 | 主题/色彩/OTB 总额 |
| 品类结构与宽深初稿 | T-8 月 | 各品类款数、SPS 目标 |
| 设计开发启动 | T-7.5 月 | 初版款式表 |
| 面辅料确认 | T-6 月 | 大货可行性、成本 |
| 样衣评审一轮 | T-5 月 | **淘汰率 30%–40%** |
| 样衣二轮 + 定价 | T-4 月 | 最终款式表 |
| 订货会 | T-3.5 月 | 首单量、区域配货 |
| 大货下单 | T-3 月 | 生产排期 |
| 首批入仓 | T-1 月 | 分货 |
| 门店铺货 | T-0.5 月 | 陈列方案 |
| **上市** | T | 首销监控 |
| 首销复盘 | T+2 周 | **翻单决策** |
| 二波段 | T+4~6 周 | — |

## 期货 / 快反双轨配比

| 模式 | 占比 | 适用 | 提前期 |
|---|---|---|---|
| 期货 | 60%–80% | 基础款、核心款、特殊面料 | 6–9 月 |
| 快反 | 20%–40% | 应季翻单、潮流试水 | 30–45 天 |

- 女装 / 潮流品牌快反占比可到 **40%–50%**
- 男装 / 商务装通常 **15%–25%**

## 波段节奏（一季 3–5 波）

| 波段 | 时点 | 占比 | 职能 |
|---|---|---|---|
| 首波 | 季初 | 30%–35% | 定调、测款 |
| 第二波 | +4~6 周 | 25%–30% | 主力放量、翻单跟进 |
| 第三波 | 季中 | 20%–25% | 补充调整 |
| 第四/五波 | 季末 | 15%–20% | 清尾、过渡季 |

> **常见错误**：首波占比 >45% → 季中无新品 → 客流下滑 + 被迫提前打折。

## 三个健康检查

| 检查项 | 健康值 |
|---|---|
| 节点达成率 | ≥85% |
| 样衣一轮淘汰率 | 30%–40% |
| 上市准时率（偏差 ≤7 天） | ≥90% |

## 与已有知识的衔接

- **给 [[2026-08-07_单款店均效率SPS与款式宽度反推模型]] 装上时间轴**：SPS 反推得到的"店均款数"应在 **T-8 月**的"品类结构与宽深初稿"节点确定，而非订货会临场决定。本源明确了宽深决策的**时间落点**。
- **给 [[2026-08-07_retailnorthstar_SKU合理化五步减法与复杂度五区间]] 装上执行窗口**：五步减法中的"退出候选池"需在 **T-5 月一轮样衣评审**时执行（淘汰率 30%–40% 正是减法的主战场），而非等到季末看数据——**季末才砍已经晚了一整季**。
- **对 [[柔性供应链与商品企划]] 的量化补充**：既有页面论述小单快反的价值，本源给出快反的**合理占比区间**（整体 20%–40%，女装可至 40%–50%，男装 15%–25%），避免"全面快反"的误判。
- **与 [[2026-07-09_季前商品计划波段OTB]] 的口径对齐**：两源均采用 3–5 波段划分，本源补入各波段的**占比基准**（30-35 / 25-30 / 20-25 / 15-20）。

## 与既有基准的核对

- `kb_benchmarks.json` 中无企划日历相关项，**无矛盾**。建议新增：
  - `gtm_calendar.total_lead_time_months = 9`
  - `gtm_calendar.quick_response_days = 30~45`
  - `gtm_calendar.qr_share_overall = 0.2~0.4`, `qr_share_womenswear = 0.4~0.5`, `qr_share_menswear = 0.15~0.25`
  - `wave.first_wave_share = 0.30~0.35`, `first_wave_warning = 0.45`
  - `gtm_calendar.sample_rejection_rate = 0.3~0.4`
  - `gtm_calendar.milestone_ontime_rate = 0.85`, `launch_ontime_rate = 0.90`
