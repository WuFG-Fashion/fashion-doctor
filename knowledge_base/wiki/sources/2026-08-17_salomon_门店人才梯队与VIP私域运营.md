# Salomon门店人才梯队与VIP私域运营

> **一句话摘要**：Salomon 用"高潜零售人才 8 个月沉浸式培养（70% 晋升率）+ 奢侈品精细化待客 + VIP 私域深度运营"作为高端户外门店打法。
> **来源**：Salomon 官方 LinkedIn（Retail Talent Class 2026）+ 招聘 JD（薪资为媒体估算）
> **最后更新**：2026-08-17
> **置信度**：品牌自宣（官方人才计划帖）；薪资数字内联标注媒体估算
> **brand_specific**：true（Salomon 特有，双链到 [[salomon]]）

## 核心要点
- Retail Talent Program：识别高潜、8 个月沉浸式、70% 晋升更高职位。
- 上海核心店经理职责含 VIP 会员体系 + 私域深度运营 + 奢侈品待客逻辑。
- 门店薪资（媒体估算）：店员 1.2-1.8 万 ×13 薪，店经理 2-3 万 ×13 薪。

## 详细内容

### 人才梯队（官方）
- 每年识别高潜零售员工，8 个月沉浸式：进阶零售专业 + 拉伸任务 + 资深导师 + 国际流动。
- **70% 高潜晋升到更高职位**（总部或门店）；Annecy 总部集训。
- 培训岗：需求分析 / 服务&产品培训 / 神秘客跟进 / 现场教练（on-site coaching）。

### 门店运营（招聘 JD）
| 职责 | 内容 |
|------|------|
| 生意经营 | 业绩/毛利/人效/坪效；拆解月度周度指标 |
| VIP 私域 | 新客挖掘、老客维系、分层精细化；新品预览/限定款发售/会员沙龙 |
| 体验标准 | 全球统一 VM 视觉 + 奢侈品精细化待客逻辑 |
| 团队 | 招聘/排班/绩效辅导；标准化带教体系 |

### 薪资参照（媒体估算）
- 店员（长春）：1.2-1.8 万 ×13 薪
- 上海核心店经理：2-3 万 ×13 薪
- 均含五险一金、绩效奖金

## 结论
1. **人才培养即护城河**：70% 晋升率 + 内部导师传承，把"高端服务素养"沉淀为组织能力而非依赖个别明星店员，与 [[导购培训闭环体系]] 闭环逻辑一致。
2. **VIP 私域是高端户外门店的利润锚**：Salomon 把"奢侈品待客"适配"都市户外生活方式"，用会员沙龙/限定款维系高单价与联名成交，是 [[导购能力评估与赋能体系2026]] 在高端品牌的落地样本。
