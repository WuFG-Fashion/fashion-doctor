# 三款极简审美图表可视化 Skill 工具清单（临时收集提炼）

> **一句话摘要**：三款开源图表可视化 Skill——lieflat-charts（编辑感数据图表三风格）、Archscribe（手绘技术图/架构图）、diagram-design（27 类专业图表 + 品牌风格自动匹配）——供零售数据看板与汇报图表选型参考。
> **来源**：临时收集/2026-08-23/公众号-3个极简审美的图表可视化Skill（原文为 AI Skill 工具清单）
> **最后更新**：2026-09-04

## 核心要点

1. **lieflat-charts（larashero3-dotcom/lieflat-charts）**：以统一字体/留白/线条/动效把数据图表做成"编辑感"视觉内容，含三种风格——**Lupi（编辑叙事型）**：细线/点阵/逐条记录/大留白，适合论文、长文、年报等需慢读的数据故事；**Glance（快速判断型）**：粗柱/大数字/色块/清晰排序，几秒内看懂高低变化，适合周报、汇报、dashboard；**Basics（基础编辑型）**：保留柱/折/环形图熟悉轮廓 + 可数刻度/发丝线/编辑排版，适合结构简单或数据量少场景。
2. **lieflat-charts-custom（komakizhu 变异版）**：保留 Mono/Porcelain/Palm/Wire 模式，新增高对比莫兰迪、克莱因蓝·橙、勃艮第·深青绿、梅子紫·酸橙四套预设 + 对应模板/对比度校验/PNG 预览。
3. **Archscribe（lazypay/Archscribe）**：生成高级感**手绘技术图**——手绘字体、可编辑 Excalidraw 源文件、静态 PNG 预览、动态 GIF；适合文章讲解、系统架构图、流程图及 DailyDoseOfDS 风格技术草图（深色霓虹 + 浅色纸面两套观感）。
4. **diagram-design（cathrynlavery/diagram-design）**：**27 种专业图表类型**（架构图/流程图/时序图/ER 图 + 四象限/维恩/金字塔等表达型），每类含简约浅色/简约深色/全编辑三种变体，输出干净 HTML+SVG；支持**品牌风格自动匹配**——抓取网站首页提取背景色/正文色/强调色/字体栈写入样式指南，后续图表自动沿用。

## 详细内容

工具定位：三款 Skill 覆盖"数据图表→技术图→架构/业务图"三种可视化产出场景，均面向 AI 辅助生成（提示词 Skill 形式），可嵌入 dashboard 制作、汇报材料、知识库插图等工作流。对服装零售数据分析的可落点：看板图表风格统一（Glance 风格适合经营日报）、商品企划/复盘长文的叙事化图表（Lupi）、系统架构与数据链路图（Archscribe/diagram-design）。库内已有相关实践可承接：[[viz_best_practices]]（图表选择与配色）、[[retail_bi_visualization_2026]]（BI 工具选型）、[[streamlit_dashboard_2026]]（自建看板）。

## 结论

1. **图表产出应"先定阅读场景再选风格"**：同一组数据，给周报/经营看板（决策者 3 秒扫读）应走 Glance 粗柱大数字，给复盘长文/年报（细读叙事）应走 Lupi 编辑感——风格选型本质是"读者阅读耐心"的函数，与图表类型同等重要。
2. **品牌风格自动匹配是零售多品牌看板的一致性杠杆**：diagram-design 的"抓取首页→生成样式指南→图表自动沿用"模式，可直接类比到东尚多品牌 dashboard 的视觉治理（每品牌一套色板/字体栈，图表随品牌切换而统一换肤），比人工逐图调色更可维护。
3. **工具清单类信息价值在于"可被检索、按需取用"**：三款工具入库后作为 AI 辅助可视化备选池，需真实试用后才能给"替代 Streamlit/Plotly 组合"的判断——本轮仅登记清单，不承诺适配结论。
