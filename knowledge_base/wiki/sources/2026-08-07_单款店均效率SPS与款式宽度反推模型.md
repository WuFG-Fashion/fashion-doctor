# 单款店均效率 SPS 与款式宽度反推模型

> **一句话摘要**：用 SPS（单款店均销量）替代"总 SKU 数"作为宽度决策指标——健康 ≥8 件、<5 件预警、>20 件偏窄；100㎡ 店合理上柜 120–180 款、200㎡ 店 200–280 款，超上限 20% 后坪效不升反降；企划阶段可用「目标件数 ÷ 门店数 ÷ 目标SPS」反推店均款数。

## 核心指标

| 指标 | 定义 | 参考区间 |
|---|---|---|
| 店均上柜款数（100㎡） | 单店同期在售款数 | 120–180 款 |
| 店均上柜款数（200㎡） | 同上 | 200–280 款 |
| SPS 健康值 | 单款单店整季销量 | ≥8 件 |
| SPS 预警线 | — | <5 件 |
| SPS 偏窄信号 | — | >20 件 |
| 坪效拐点 | 上柜款数超区间上限 | +20% 后坪效下降 |

## 分品类 SPS 差异

| 品类 | SPS 参考 | 宽深策略 |
|---|---|---|
| 基础款（T恤/衬衫） | 15–30 件 | 窄而深 |
| 核心款（外套/连衣裙） | 8–15 件 | 平衡 |
| 形象款 | 2–5 件 | 不适用预警线 |
| 配饰 | 20–40 件 | 极窄极深 |

> **关键提醒**：用统一 SPS 预警线考核所有品类会误杀形象款、放任配饰款宽度失控。

## 宽度反推公式

```
目标销售件数 = 目标销售额 ÷ 客单价
店均合理款数 = 目标销售件数 ÷ 门店数 ÷ 目标 SPS
企划总款数 ≈ 店均合理款数 × 1.3~1.5（含淘汰率）
```

示例：1 亿元 / 客单 600 元 / 200 店 / SPS 10 → 店均 83 款 → 企划总款数约 108–125 款

## 与已有知识的衔接

- **与 [[2026-08-07_retailnorthstar_SKU合理化五步减法与复杂度五区间]] 形成"诊断—决策"配对**：复杂度五区间告诉你"是否处在稀释区"（定性），SPS 告诉你"具体宽了多少、该砍到几款"（定量）。SPS<5 件正是"进入稀释/混乱区"的**可测量信号**。
- **与 [[2026-08-05_wecx_女装商品结构金字塔四层占比]] 的交叉校验**：金字塔给各层占比，本源给各层的 SPS 参考（形象款 2–5 件 vs 核心款 8–15 件），说明**形象款占比 5-10% 是合理的，因其本就不承担走量职能**，两源逻辑自洽。
- **对 [[动态OTB管理]] 的前置补充**：OTB 解决"买多少钱"，SPS 反推解决"买多少款"。二者共同确定 OTB 的宽深拆分，是 [[2026-07-13_PANTEL_OTB六步法_李宁改革]] 中"宽深决策"步骤的可计算化。

## 与既有基准的核对

- 本页 SPS 指标在 `kb_benchmarks.json` 中**无对应项**，无矛盾。建议新增：
  - `assortment.sps_healthy = 8`, `sps_warning = 5`, `sps_too_narrow = 20`
  - `assortment.styles_per_store_100sqm = 120~180`, `styles_per_store_200sqm = 200~280`
  - `assortment.plan_to_store_ratio = 1.3~1.5`
- 与 [[2026-08-07_retailnorthstar_SKU合理化五步减法与复杂度五区间]] 的"导购可熟练讲解 40–60 款"存在**口径关系而非矛盾**：店均上柜 120–180 款 > 导购可熟记 40–60 款，说明**导购只能覆盖约 1/3 的在售款**，这正是需要重点款机制（形象款+核心款主推）的原因，两组数据互相解释。
