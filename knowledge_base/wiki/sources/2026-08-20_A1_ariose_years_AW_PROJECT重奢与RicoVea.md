# 艾诺丝雅诗 AW PROJECT 重奢拓展与 RicoVea 新锐（A1·2026-08-20）

> **一句话摘要**：艾诺丝雅诗母集团以"主品牌 1,800 店 + AW PROJECT 重奢上探（港汇恒隆首日 60 万、进 SKP/万象城/德基）+ RicoVea 新锐接棒退潮 CHUU"三梯队推进，2026 加速向百亿女装冲刺。
> **来源**：[[2026-08-20_ariose_years_AW_PROJECT重奢与RicoVea]]
> **最后更新**：2026-08-20

## 核心要点
- AW PROJECT（第二增长曲线）：2025 末近 30 家 → 2026 上半年加码重奢商圈，上海港汇恒隆首店开业首日破 60 万，进驻北京 SKP、深圳万象城、南京德基；对标国际奢牌面料（意大利羊绒、日本三菱科技面料），客群 30–45 岁高净值精英女性。
- RicoVea 新锐设计师品牌：2026-03 孵化，成都 IFS 首店，二季度超 10 家新店，接棒退潮的 [[chuu|CHUU]]；7 月常州万象城首店，解构设计、松弛穿搭。
- 母公司杭州爱唯服饰 2025-12-17 更名「杭州爱唯时尚集团有限公司」；主品牌 2026-03 门店突破 1,800 家、2025 销售约 50 亿（第三方媒体 corroborate）。
- 蒙阴旗舰店 2026-03-08 女神节开业（区域布局）。

## 结论
1. 艾诺丝以"中端主品牌 + 轻奢 AW PROJECT + 新锐 RicoVea"三层梯队覆盖 25–45 岁女性全价格带，是杭州女装"区域龙头集团化"的标杆，对 [[peacebird|太平鸟]] 多品牌集团路径可类比但资本化差距大。
2. AW PROJECT 重奢首店首日 60 万验证"中端女装上探轻奢"可行，是观察"商业黑马能否跃迁品牌力"的关键样本；RicoVea 接棒 CHUU 退潮，说明韩潮红利消退正被本土新锐填补。
3. 数据仍非审计级（媒体估算 + 自宣 corroborate），引用须标注口径；但 50 亿 / 1,800 店已获第三方独立媒体 corroborate，置信度优于纯自宣。
