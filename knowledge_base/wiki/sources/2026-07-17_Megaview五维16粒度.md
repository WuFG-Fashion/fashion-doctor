# Megaview AI模拟客户复盘 5维16粒度能力地图

> **一句话摘要**：Megaview通过Agent Team多智能体协作+5维16粒度评分体系，将导购能力从"主观评语"升级为可量化的行为评估，知识留存率72%，线下培训成本降50%。

> **来源**：Megaview 销研院，2026-05-08

## 核心要点

1. **5维16粒度评分**：表达能力/需求挖掘/异议处理/成交推进/合规表达，每个维度细分具体行为指标
2. **Agent Team多智能体**：多Agent分别扮演客户/教练/评估角色，12类客户画像
3. **"错题本"精准复训**：系统识别失误→推送微课→次日AI刻意验证
4. **知识留存72%**（传统20%），新人上岗6月→2月

## 关键数据

| 指标 | 数值 |
|------|------|
| 评分维度 | 5大维度16个粒度 |
| 客户画像数 | 12类 |
| 场景探询得分提升 | 62→89分 |
| 知识留存率 | 传统20% → AI陪练72% |
| 医学新人上岗 | 6个月→2个月 |
| 线下培训成本降 | 约50% |
| 需求挖掘成交转化率 | +23pp |

## 详细内容

### 5维16粒度评分体系

| 大维度 | 细分行为指标 | 量化方式 |
|--------|------------|---------|
| 表达能力 | 开场/产品介绍/流畅度 | 对话行为标记 |
| 需求挖掘 | 场景探询/痛点确认/决策因素排序 | SPIN/FABE检测 |
| 异议处理 | 价格异议/竞品对比/功能质疑 | 应对策略匹配 |
| 成交推进 | 促成时机/连带推荐/逼单技巧 | 推进节点标记 |
| 合规表达 | 虚假承诺/夸大宣传 | 关键词检测 |

### 复盘机制

系统自动标注每个对话环节——"第3轮对话主动询问使用频率"计为有效探询；"客户提及竞品后未追问对比维度"标记为漏点。能力雷达图让管理者第一次看到训练数据完整图景。
