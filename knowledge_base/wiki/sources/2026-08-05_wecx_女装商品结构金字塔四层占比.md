# 女装商品结构金字塔与四层占比（wecx）

> 一句话摘要：健康商品结构应呈金字塔——形象款5-10%（定调性）/核心款50-60%（主利润与风格基石）/基础款20-25%（稳销量提连带）/引流款10-15%（吸新客测反应）；并以"小批量快反应测款迭代"替代期货制，用点击→收藏→加购→转化四项数据快速识别潜力爆款。

> 来源：wecx（wecx.com/viewnews_194313.html）；采集 2026-08-05（Round B / L2_05 商品企划）

## 核心要点

1. **四层结构占比**：形象款5-10% / 核心款50-60% / 基础款20-25% / 引流款10-15%。
2. **开发节奏**：打破期货制，拥抱"小批量、快反应、测款迭代"；规划首批上市款/后续追单款/节日营销专属款三类波段。
3. **数据驱动测款**：上新初期点击→收藏→加购→转化四项数据识别潜力爆款，控制库存风险。
4. **视觉与内容企划**：LOOKBOOK/场景穿搭/短视频，把单品转化为解决方案（一衣多穿/面料工艺解读/UGC）。

## 关键数据（商品结构占比）

| 类型 | 占比 | 核心作用 |
|------|------|---------|
| 形象款 | 5%–10% | 定义品牌调性、制造话题 |
| 核心款 | 50%–60% | 主销售额与利润、风格基石 |
| 基础款 | 20%–25% | 提高连带率、稳定销量 |
| 引流款 | 10%–15% | 吸引新客、测试市场反应 |
