# State of Apparel Merchandising Planning 2026（RetailNorthstar，2026）

> **一句话摘要**：RetailNorthstar 2026研究显示，高效商品企划采用单一计划模型（OTB/assortment/buy同源）+ 尺码曲线基于sold% + 48小时季中可见性；规模阈值>200-250 SKU后管理复杂度非线性上升，$10M品牌季运营缺口$380K-750K。
> **来源**：retailnorthstar.ai/resources/research/state-of-apparel-planning-2024（RetailNorthstar 研究，2026）
> **最后更新**：2026-07-28

## 核心要点

1. 单一计划模型：OTB/assortment/buy quantities 同模型，数据同源（非需对账链接文件）
2. 尺码曲线基于 **sold%（卖出占比）** 而非 bought%（买入占比）→ 持续提高售罄率
3. 季中可见性：**48小时内** 有售罄数据，足以在销售窗口内行动
4. 规模阈值：50-150 SKU可纪律管理；**>200-250 active SKUs** 对账负担超团队承受
5. 中端市场缺口：企业平台实施12-24月/ERP不解决季前规划；apparel-native工具周级实施
6. 运营缺口：$10M品牌/季 **$380K-$750K**，修复可提毛利 **4-8pp**

## 详细内容

### 规模阈值与平台触发
- 小错误累积（对账误差/错过季中信号/季前截止压力）+ 团队成长（2人→3人协同成本超连接系统）
- 缺口在"精细表格"与"企业平台"之间，由OTB+assortment+buy一体中端工具填补

### 运营缺口量化（$10M品牌/季）
| 缺口 | 成本 |
|------|------|
| 无OTB框架 | $150K-$300K超买 |
| 错误尺码曲线 | $80K-$150K尺码残次 |
| 无追单能力 | $100K-$200K赢家漏单 |
| 手动分配 | $50K-$100K错配 |
| **合计** | **$380K-$750K**；修复提毛利4-8pp |
