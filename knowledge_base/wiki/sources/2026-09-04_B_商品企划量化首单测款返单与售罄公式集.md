# 商品企划量化：首单测款返单与售罄公式集（B轮·2026-09-04）

> **一句话摘要**：首单 ≤预估销量 40%（新供应商 25-30%）→ 第 7/14 天双节点测款 → 四分类分流（爆款返单 2 倍/潜力 +50%）→ 高峰每 7 天滚动补单（返单量 = 可售天数 × 日均 × 1.2），把小单快反从口号变成可执行参数。
> **来源**：raw/articles/2026-09-04_B_商品企划量化首单测款返单与售罄公式集.md（帆软E数通 / 搜狐出海案例 / 东纺云 / Modanomics / Maker's Row / Prediko 聚合）
> **置信度**：媒体估算（行业实操文）/ 第三方数据（SHEIN/ZARA 公开口径）
> **brand_specific**：false（行业通用方法论，双链至 concept 不链品牌）

## 核心要点
- **首单纪律**：新款首单 ≤ 预估销量 40%（首单≠备货总量，产能要够但第一批进仓克制）；首次合作供应商压到 25-30%（防质量问题）。产业信号：头部电商平台春季新品首单 <500 件占比突破 65%。
- **测款双节点**：第 7 天看点击率+收藏加购（点击 < 同行均值一半 = 视觉问题；加购高转化低 = 价格偏高）；第 14 天看转化+复购，拉不起来就停止投流。
- **四分类分流**：爆款（14 天转化 ≥4% 且加购 ≥12%）→ 立即返单 2 倍；潜力款 → 追加首单 50%；平庸款维持；放弃款列清库、不再投流。
- **返单节奏公式**：高峰按"小单快返"每 7 天滚动，返单量 = 当前可售天数 × 日均销量 × 1.2（在途库存始终可控）。
- **售罄率口径与基准**：分母 = 累计收货件数（非在售/在途）；累计口径看季末复盘、周度口径看季中决策。>90% 考虑补单、80-90% 强、60-80% 健康、40-60% 需干预；季末目标 80%+。

> ℹ️ **基准核对（售罄率档位）**：厂商口径有差异——本页（Modanomics）60-80% 健康 vs 酷盾 2026 诊断阈值 >75% 优秀/<55% 危险，与 [[sell_through_examination_standard_2026]] / kb_benchmarks lifecycle_sell_through（季末 0.8、热销 ≥0.8、正常 0.5-0.8）同属"季末 80% 目标 + 60-80% 健康"区间，量级一致非硬矛盾；须区分"周度交易口径"与"累计季末口径"。

> ℹ️ **基准核对（首单比例双口径）**：本页"首单 ≤ 预估销量 40%（新供应商 25-30%）"是**单款测款首单**占该款预估销量的比例；[[2026-09-02_B_商品企划七步法与动态OTB]] 中"首单 60-70% + 30-40% 灵活"是**期货订单占 OTB 预算**的结构比例（另述"首单 25-30% 总量控制"）。两者维度不同（销量预测 vs 采购预算），量级规则同向（首单克制），非硬矛盾。

## 详细内容

### 1. 换季 SKU 快速调整（帆软 E 数通 2026-08）
- 渠道调拨：A 渠道售罄 70% vs B 渠道 30% → 优先 B→A 调拨而非给 B 补新货。
- 退货回流目标 48h：质检 2h + 重新包装贴标 4h + 系统入库 1h + 重新上架即时；退货滞留一天就损失一天再售机会。

### 2. 快反全链路案例（女装出海，2026-08）
- 首单统一 100 件/款 → AI 内容线批量出穿搭视频测款（完播率+加购率双高才返单）。
- 返单协议：爆款确认后 7 天出货、10 天海运加急到仓（行业传统 30-45 天）。
- 6 个月结果：月销稳定 $15 万+、退货率 22%（行业均值 30-40%）、爆款确认周期 3 周→10 天、库存周转 45 天（行业 90 天+）。

### 3. 行业标杆参数
- SHEIN（2025）：营收 $418 亿、库存周转 36 天、滞销库存低个位数；供应商账期 3-6 个月→30 天、优质工厂 7 天回款。
- 海澜之家×京东"深海数据模型"：爆款预警比对历史成长曲线 → 首单 500-1000 件动态补单 → 百万/千万单品，存货周转效率 +3 倍；海澜云服一件起订 7 日交付、生产周期 15→4 天。
- ZARA：新品开发到上市 10-20 天、首期每款只产平均需求 50%、剩余按销售追单；滞销率约 10%（行业 17-20%）。
- 柔性工厂要求：产线"细胞化/模块化"改造（多技能工人、快速换款）；快返核心瓶颈在面料非缝纫；48-72 小时瞬时潮流击穿传统期货模式。

### 4. 商品"项目卡"方法论（女装风衣复盘）
- 一页项目卡五要素：目标人群 / 场景 / 价格带（主力区间上沿，留折扣空间）/ 关键指标（首周售罄率、两周退货率、断码率、连带率）/ 止损阈值（两周未跑通核心尺码曲线即收缩补货）。
- 教训：配比不能用审美定（直播间雾蓝高收藏低转化 vs 门店灰黑稳成交）；"视觉正确 ≠ 穿着正确"——体感才是成交。

### 5. 售罄率与商品分析公式集（Modanomics / Prediko / 酷盾）
- 公式：售罄率 = 售出件数 ÷ 累计收货件数；Units Remaining = 收货 − 售出。
- 诊断阈值（酷盾 2026）：售罄率 >75% 优秀 / <55% 危险（启动折扣调拨）；折扣率 >85% 健康 / <70% 侵蚀毛利；动销率 >60% 正常 / <40% 结构失衡；畅滞销比参考 1:1.5。
- 尺码配比：试衣到成交转化 40-60%；优衣库强化 SKU 效益评估后当季售罄 78%→86%（公开口径）。
- Maker's Row：新款上市前 8-10 周按周盯售罄；第 2 周仅 10% 售罄的款季末难回健康正价；预置 markdown 触发器（第 6 周 <25% → 首次降价）去情感决策。
- Denver 针织案例：2 个 hero 款占第 6 周 65% 售罄、3 个弱款 <20% → 下季砍弱款 hero 翻倍，季毛利预估 +18%。
- 爆款基因分析：定义爆款（销售速率 > 品类均值 2 倍 且 上市 4 周售罄 >40%）→ 提取近 2-3 季属性共性（70% 基础色系/60% 中高价格带）→ 输入下季选款。

## 结论
- **首单比例不是拍脑袋是三道闸**：预估销量的 40%（老供应商）/ 25-30%（新供应商）/ <500 件（平台快反）三个锚点，让"测款"真正低成本；首单过高 = 错判即库存。
- **测款必须有时点纪律**：第 7 天和第 14 天是黄金决策窗——过早信号噪声大、过晚库存风险积累；四分类表（爆/潜/平/弃）把"感觉"变成可执行动作表。
- **售罄率分母口径不统一是全行业数据打架主因**：数量口径看货走得快不快、金额口径看钱回来多少；Fashion Doctor 做跨品牌比较前必须统一口径并在表头标注。
