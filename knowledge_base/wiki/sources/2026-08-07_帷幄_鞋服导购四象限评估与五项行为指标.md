# 帷幄 — 鞋服导购四象限评估与五项可量化行为指标

> **一句话摘要**：以「能力（行为过程）× 产出（人效/连带）」双维度将导购分为明星/潜力/经验/低效四类，其中"高能力低产出"的潜力型占门店不达标人员的 20%–30%，问题在排班与客流错配而非能力；配套五项可量化行为指标后连带率提升 8%–15%、接待转化率提升 10%–20%。

## 核心数据

| 指标 | 数值 | 说明 |
|---|---|---|
| 潜力型（高能力低产出）占不达标人员比 | 20%–30% | 根因是排班/客流错配 |
| 需求提问数（行业中位） | 2–3 个 | 优秀者 5 个以上 |
| 连带率提升 | 8%–15% | 引入周度行为看板后 |
| 接待转化率提升 | 10%–20% | 同上 |
| 低效人员改善期 | 30–60 天 | 未达标则调岗 |

## 四象限人员分类

| 类别 | 能力 | 产出 | 管理动作 |
|---|---|---|---|
| 明星导购 | 高 | 高 | 话术沉淀为组织资产 + 带教 |
| 潜力导购 | 高 | 低 | **排查外部约束（排班/客流/货品），不是加训** |
| 经验导购 | 低 | 高 | 靠老客吃饭，补新客能力，防流失 |
| 低效人员 | 低 | 低 | 30–60 天改善期 |

## 五项可量化行为指标

1. 开场破冰率（进店 30 秒内）
2. 需求提问数（开放式问题数）
3. 连带推荐率
4. 异议处理完成率
5. 临门推进率

## 与已有知识的衔接

- **对"明星导购识别"方法的补充**（现散见于 [[AI导购陪练]] 与 [[导购培训闭环体系]]）：既有做法偏重"用结果指标筛人"，本源补入"能力×产出"双轴，使得**高能力低产出**这一被漏掉的群体可被识别，避免误判为能力不足。
- **对 [[导购培训闭环体系]] 的补充**：闭环的"评"环节此前以 14 维评估为主，本源提供了 5 项**门店现场可观测**的轻量指标，可作为周度高频层，与月度 14 维评估形成双频。
- **与 [[AI导购陪练]] 的呼应**：Megaview 主动推进率 23%→61% 的训练结果，对应本源的"临门推进率"指标，两者口径一致，可直接串联训练→上岗行为验证的链路。
