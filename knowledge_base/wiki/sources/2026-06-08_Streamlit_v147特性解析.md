# Streamlit v1.47.0 深度特性解析

> **一句话摘要**：Streamlit v1.47以主题增强和组件灵活性提升为主，新增大量width/height参数、chart颜色配置、st.chat_input Session State支持。

> **来源**：Streamlit官方文档 v1.47.0 Cheat Sheet
> **最后更新**：2026-06-08

## 核心升级

### 主题配置增强
- `theme.baseFontWeight` / `theme.codeFontWeight` - 字体粗细
- `theme.chartCategoricalColors` / `chartSequentialColors` - 图表默认配色
- `theme.dataframeHeaderBackgroundColor` - DataFrame表头背景色
- `theme.headingFontSizes` / `headingFontWeights` - 标题样式
- `theme.linkUnderline` - 链接下划线控制

### API变更
- `st.chat_input` 支持Session State设置未提交值
- `st.html`/`st.feedback`/`st.pills`/`st.segmented_control`/`st.multiselect` 新增width参数
- `st.metric`/`st.text_area` 新增height参数
- `st.code`/`st.form` 支持 `height="stretch"`
- 缓存函数新增 `show_time` 参数显示耗时

### 多页面管理
```python
pg = st.navigation(
    st.Page("page1.py", title="Home", url_path="home", default=True),
    st.Page("page2.py", title="Settings", url_path="settings")
)
pg.run()
```
