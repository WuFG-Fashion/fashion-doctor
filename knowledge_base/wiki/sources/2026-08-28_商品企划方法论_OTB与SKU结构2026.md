# 商品企划方法论：OTB 与 SKU 结构（2026-08-28）

> **一句话摘要**：OTB 公式与商品计划八步法的 2026 完整骨架，叠加品类结构黄金比例（主力 50-60%）与 8x 现金门槛。
> **来源**：WebSearch 汇总（商品企划行业方法论，2026-08-28）
> **最后更新**：2026-08-28

## 核心要点

1. **OTB 公式**：期初库存 + 采购预算 − 销售预测 − 期末目标库存 = 可支配采购额，按品类/波段/门店三维分解。
2. **商品计划八步法**：目标分解 → 历史售罄复盘 → OTB 预算 → 品类结构 → 波段上新 → SKU 宽深配比 → 价格带 → 配补调。
3. **品类结构黄金比例**：主力 50-60% / 引流 15-25% / 形象 10-20%；TOP20% SKU 贡献 60-80% 销售。
4. **8x 现金门槛**：库存 ≤ 月销 ×8 视为资金健康（行业经验值）。
5. OTB 偏差 ≤15% 健康（与 kb seasonal_deviation 0.15 一致）；AI 人机协作 OTB 准确率 85%（kb ai_collaboration_accuracy 0.85 同源）。

## 详细内容

### OTB 公式与八步法

| 步骤 | 内容 |
|------|------|
| 1-2 | 销售目标分解（店/品类/周）+ 历史售罄复盘 |
| 3-4 | OTB 预算编制 + 品类结构规划 |
| 5-6 | 波段上新计划 + SKU 宽深配比 |
| 7-8 | 价格带管理 + 配补调执行 |

## 结论

1. **品类结构黄金比例提供 SKU 级决策标尺**：主力/引流/形象 50-60/15-25/10-20 可直接落到 [[sku_fine_management]] 的 SKU 分层，防止"形象款过多拖累售罄"。
2. **8x 现金门槛是商品企划与财务的接口**：库存资金健康线为 OTB 预算提供硬约束，与 [[动态OTB管理]] 的现金流视角一致。
3. **八步法与 OTB 偏差 ≤15% 是闭环校验**：偏差超 15% 触发波段复盘与调拨，衔接 kb otb/manual_accuracy 0.725 → ai_collaboration 0.85 的升级路径。
4. **数据可信度提示**：方法论为行业汇编（媒体估算级），但 OTB 阈值与 kb_benchmarks 互证，可信度较高。
