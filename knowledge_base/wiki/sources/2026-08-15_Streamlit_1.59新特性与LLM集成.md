# Streamlit_1.59新特性与LLM集成

> **一句话摘要**：Streamlit 1.59.0（2026-07-06）带来 ButtonColumn、st.mermaid_chart、App.run() 直启、st.fragment 写外部容器、persist_state 等，强化表内交互与 LLM 集成。

> **置信度**：官方公告

## 核心要点

1. ButtonColumn（st.dataframe/data_editor 表内可点击按钮）+ 列统计子菜单。
2. st.skeleton（加载占位）、st.mermaid_chart（原生 Mermaid 图，亦走 st.markdown）。
3. App.run() 入口：直接 `python app.py` / `uv run app.py`，告别 `streamlit run`。
4. st.fragment 可写外部容器（局部刷新不整页 rerun）；persist_state 跨 rerun 保留控件状态。
5. st.chat_input 粘贴文件 + submit_mode；st.write_stream 支持 OpenAI Responses API 流；Snowpark 连接已移除。

## 详细内容

| 特性 | 价值 |
|------|------|
| ButtonColumn / MarkdownColumn | 表内操作与富文本，减少跳转 |
| st.mermaid_chart | 看板内联架构/流程图，替代外链图 |
| App.run() | 简化容器 ENTRYPOINT 与 FastAPI/Starlette 嵌入 |
| st.fragment(parallel) + 写外部容器 | 局部刷新，缓解整页 rerun 性能 |
| persist_state | 控件状态跨 rerun 保留 |

1.58（2026-05）已引入 @st.fragment parallel=True、st.pagination、streamlit skills CLI；1.55（2026-03）引入动态容器 on_change、bind 参数（控件↔URL）。

## 对本项目直接映射

- st.mermaid_chart 可在看板内联系统架构/数据流图（呼应 [[streamlit_dashboard_2026]] 的图示需求）。
- App.run() 简化 V3 启动脚本；persist_state + st.fragment 局部刷新是缓解「session 不丢 / 底部固定 / 横向滑动」三角矛盾的可行手段之一（见 [[streamlit_production_dashboard]]）。
- 与 [[python_dashboard_ecosystem_2026]] 中 Streamlit 赛道领先位一致：表内交互 + LLM 集成 + 轻启动持续强化。
