## 1. 基于核心顾客大企划增量方案（534107127，2022-03-31）

### 业务定位
- 韦孚咨询是围绕**商品和顾客精准对接为导向**提升设计研发和经营运营咨询公司
- 涉及**总部和终端**（设计和经营）
- 国内 90% 女装上市公司我们都在合作，**50% 女装上市公司我们在深度顾问辅导**
- 服务品牌：地素、艾诺丝雅诗、迪赛尼斯、歌力思、赢家等

### 服务理念
- 体验式教学 + 教练式跟进的培养模式
- **学员最终的能力和行为改变**是衡量培训质量的唯一标准
- 服务理念：出色的方案设计能力 + 出色的方案实施能力
- 服务模式：专一项目、专一小组、推动实施
- 质量审核：四级质量审核体系 + 完善项目后续服务体系

### 帮助企业解决（4 大类）
1. 公司共识品牌核心顾客，基于公司定位顾客完成迭代
2. 聚焦核心品类如何导客户数据精准落地
3. 高产店打造背后总部产品 marketing 方案落地（品宣、品推、品销）
4. 打通产销线扩大核心顾客销售规模

## 2. 韦孚国际 美学零售新模式（201128282，2017-10-30）

### 公司介绍
- 韦孚由多位业内资深的培训专家联合创建
- 致力于**服饰品牌终端管理、零售店铺运营、店长督导教练辅导、店铺运营体系及培训督导体系搭建**
- **经销商系统管理、店铺复制、订货会营销、零售管理咨询、企业学院体系搭建、美学营销、陈列布局设计、促销活动设计**等

### 服务理念
- 体验式教学和教练式跟进的培养模式
- 学员最终的能力和行为改变是衡量培训质量的唯一标准
- 服务理念：出色的方案设计能力 + 出色的方案实施能力
- 服务模式：专一项目、专一小组、推动实施
- 质量审核：四级质量审核体系

### 韦孚优势（4 大类）
1. **丰富的授课经验**：为全国知名品牌实施了大量课程
2. **拥有完整成熟的零售流通业课程**：覆盖零售行业从终端店员到区域经理各层级
3. **拥有各行业的案例素材库**：通过录音、录像等方式收集、整理最新的终端管理、终端销售案例
4. **拥有实战性强的课程开发实力**：已建立一整套标准的课程开发流程

- 长期服务品牌 100+ 家中 10+ 上市公司
