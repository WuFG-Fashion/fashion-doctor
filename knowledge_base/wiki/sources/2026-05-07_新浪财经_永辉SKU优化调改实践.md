# 永辉SKU优化调改实践

> **一句话摘要**：永辉超市SKU从16000+精简至8000-10000，目标3年打造100个亿元单品，提出用户-模型-心智-效率四基石战略框架
> **来源**：新浪财经/FBIF2026，演讲者佘咸平(永辉CPO)，2026-05-07
> **最后更新**：2026-06-21

## 核心要点
1. SKU精简：16000+→8000-10000，淘汰56%供应商，单品效率大幅提升（自有品牌30x/定制7x）
2. 品类结构大调整：生鲜+3R从30%→55%，全面退出服装线（仅保留袜子/男内衣）
3. 三阶段心智：爆品心智→品类心智→品牌心智，目标3年100个亿元单品
4. 四基石框架：用户(聚焦中产新中产)→模型(可复制>明星店)→心智(长期平价)→效率(零供协同)
5. 零供关系升级：三不原则(不收渠道费/不拖欠货款/不恶意二选一)，200+战略伙伴

## 详细内容

### SKU精简数据
| 指标 | 调改前 | 调改后/目标 |
|------|--------|-----------|
| SKU数 | 16000+ | 8000-10000 |
| 供应商 | (基数) | -56%淘汰 |
| 自有品牌占比 | <5% | 目标20-30% |
| 同采率 | <30% | 目标80%+ |
| 自有品牌单品产出 | 1x | 30x |
| 定制产品单品产出 | 1x | 7x |

### 品类结构变化
| 品类 | 调改前 | 调改后 |
|------|--------|--------|
| 生鲜+3R | 30% | 55% |
| 标品 | 70% | 45% |
| 服装 | 全线 | 仅保留袜子(男)+内衣(男基础款) |
| 锅碗瓢盆 | 10组货架 | 1-2组 |

### 爆品打造方法论
| 案例 | 策略 | 结果 |
|------|------|------|
| 永辉橙汁 | 与胖东来共用产线 | 月销48万件+ |
| 肉酱意面 | 欧丽薇兰定制/9.9元 | 月销30万件+ |
| 三文鱼 | 48家→2家供应商集中 | 门店减半，2月销=2024全年 |
| 伊利低温奶 | 2款核心产品全渠道 | 加速增长，关系从"谈费用"→"共建过程" |
| 鸡蛋 | 不参与价格战/强化"12天内"品质 | 销量成倍增长 |

### 四基石框架
1. **用户**: 核心画像(35岁/家庭年收入20万+/70%女性)，从"全客层"→聚焦"中产新中产"
2. **模型**: 标准门店面积/SKU/毛利/盈利→可复制>明星门店
3. **心智**: 爆品→品类→品牌三阶段递进
4. **效率**: 三不原则+战略伙伴+透明供应链

### 对服装零售的启示
- SKU精简逻辑通用：聚焦核心品类，淘汰尾部低效SKU
- 爆品方法论可迁移：单品集中→品类矩阵→品牌信任
- 零供关系：从"费用谈判"→"过程共建"值得服装行业借鉴
- 用户聚焦：明确服务谁比服务所有人更重要
