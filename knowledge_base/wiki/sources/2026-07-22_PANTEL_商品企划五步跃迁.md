# PANTEL商品企划五步跃迁

> **一句话摘要**：潘俊（PANTEL）提出中国服装品牌从经验到战略的商品企划五步法——品类角色→价格带→波段→OTB→店群，净利率可提升3-5pp。

> **来源**：今日头条 PANTEL时尚，2026-07-06

## 核心要点
1. 中国服装库存周转185-220天 vs Zara/优衣库70-90天，差距在企划源头
2. 品类角色体系：20%SKU贡献60%销售额，每类角色不同KPI
3. 波段3+3+3+3模型：首单70%→40%，售罄+8-12pp
4. OTB滚动决策：每周追单±20%/每月品类纠偏±10%/每季结构复盘
5. 店群分级：按渠道角色×客群×气候带，非城市级别

## 关键数据

| 指标 | 传统 | 五步法 | 改善 |
|------|------|--------|------|
| 首单占比 | 70% | 40% | -43% |
| 售罄率 | 基准 | +8-12pp | - |
| 折扣深度 | 基准 | -5-10pp | - |
| 净利率 | 基准 | +3-5pp | - |
