# 2026-09-04 A3 PVH 2026Q2 财报落地（官方实绩）：TH 持平 / EMEA 减值 $439M / 指引重申

> **一句话摘要**：PVH 于美东 2026-09-02 盘后发布 2026 财年 Q2（13 周截至 2026-08-02）实绩——集团营收 $20.97 亿（-3%，符合指引区间上沿）、non-GAAP EPS $3.70（+46.8%，超 Zacks 共识 $3.08 达 20.1%）；Tommy Hilfiger 品牌收入 **$11.32 亿、同比基本持平**（含收回北美授权女装品类约 +3pp 提振）；Q2 含 EMEA 报告单元 **$4.39 亿税前非现金商誉减值**；全年 non-GAAP 指引（EPS $11.80-12.10 / OP margin ~8.8%）**重申不变**。本页为 09-02 前瞻源（媒体估算级）的官方实绩落地页，并裁定 08-19/08-26 媒体链 Q2 数字失真问题。
> **置信度**：财报（PVH 官方 8-K / 10-Q + 电话会口径）
> **brand_specific**：true（PVH/Tommy Hilfiger 品牌特有财务数据）

## 核心要点
- **集团 Q2 实绩**：营收 **$2,097M（-3%）**，报告口径落在指引（-3%~-4%）上沿、恒定汇率口径超指引（-4%~-5%）；non-GAAP 营业利润率 **11.1%**（超指引 ~9.5%）；**GAAP EPS -$2.23** / non-GAAP EPS **$3.70**（上年 $2.52，+46.8%）（置信度：财报）。
- **Tommy Hilfiger 品牌**：收入 **$1,132M（约持平，上年 $1,136M）**，含收回北美授权女装品类批发约 **+3pp** 提振；剔除该过渡后 **约 -3%**。DTC 受益双位数针织增长（毛衣双位数/衬衫与 Polo 中个位数），亚麻品类全球 +30%+（置信度：财报）。
- **关税退税主导利润弹性**：Q2 收到 **$107M 关税退税**，贡献毛利率约 **+510bp**（毛利率 63.0%，+530bp）与 EPS 约 **+$1.80**；剔除退税后 non-GAAP 营业利润率约 6%（同比 +20bp）——**退税而非经营改善是利润超预期主因**（置信度：财报）。
- **EMEA 商誉减值 $439M**：中东冲突长期化 + 欧洲宏观疲软触发 EMEA 报告单元商誉减值（非现金、税前），是 GAAP 亏损主因；管理层未下调全年指引 = "风险折价已一次出清但基本面未恶化"（置信度：财报）。
- **区域/渠道结构**：EMEA $986.3M（-6%，批发弱）；美洲 $680.1M（-1%）；APAC $343.7M（+3% 报告/+1% 恒定，DTC 驱动）；授权 -13% 至 $86.9M（北美授权过渡计划内）。DTC $1,056M 持平（店 -1%/电商 +4%）；批发 -6% $954M 全区域下滑（置信度：财报）。
- **全年指引重申**：FY2026 non-GAAP 营收约持平（恒定汇率略降）、营业利润率 ~8.8%、**EPS $11.80-12.10**（上年 $11.40），含约 $0.40 有利汇率——**否证 08-21/08-28 媒体链"指引 6.44-6.54"失真记录**（置信度：财报）。
- **运营投入继续**：年内完成 120+ 店翻新/迁址、130+ 新店；Q3 营销投放同比加码；新识别集中采购/费用管控年化 **$45M** 成本节约；CEO 确认 Alexis Rollier（前丝芙兰全球 CFO/COO）到任新 CFO（置信度：财报）。
- **中国信号**：APAC DTC 恒定汇率低个位数增长、中国电商中个位数（恒定汇率）；中国商务部调查仍在进行（合规风险未解除）（置信度：财报/媒体）。

## 结论
1. **PVH Q2 是"退税型 beat"而非"经营型 beat"**：剔除 $107M 退税（+510bp 毛利/+$1.80 EPS）后营业利润率仅约 6%，叠加 EMEA $439M 商誉减值一次出清——利润弹性高度依赖一次性项，对 [[cabbeen|卡宾]]/[[peacebird|太平鸟]] 的"利润率改善质量"审计是警示样本：**须区分经营改善与一次性/退税/政府补助贡献**（置信度：财报）。
2. **Tommy Hilfiger 品牌处于"存量防守"阶段**：收入持平、剔除授权收回过渡后 -3%，增长靠 DTC 品类聚焦（毛衣/亚麻 +30%）与 Kelce/Cadillac F1/Liverpool 营销承接，印证 08-15 源"成熟美式品牌存量天花板"判断——对双核的参照是：主品牌稳态期必须靠子品牌/新品类（太平鸟的乐町/PB、卡宾的 2AM/都市）提供增量（置信度：财报）。
3. **指引重申 + 新 CFO 到任 = 治理延续信号**：全年 EPS $11.80-12.10 与 08-28 源"分析师重定价 vs 公司口径稳"叙事一致（该源"6.44-6.54"为失真值，以本页为准）；Rollier（丝芙兰 8 年 CFO/COO）到任标志 PVH+ 计划进入"利润效率"深化期（置信度：财报）。
4. **中国调查是悬顶风险**：APAC 增长但中国电商仅中个位数 + 商务部调查进行中——PVH 在华敞口（TH 中国直营收回后）的合规不确定性持续，纳入 [[brand_risk_signals_2026]] 地缘风险池跟踪（置信度：媒体估算）。
