# 2026现代Python数据栈 — dlt/Dagster/Marimo/Polars/uv

> **一句话摘要**: 2026年高绩效团队标配: dlt摄取→Postgres+DuckDB存储→Polars转换→Dagster编排→Marimo笔记本→Streamlit看板→uv+Ruff工具链，数据/AI/ML基础设施三线融合。

> **来源**: [SaaS Curate](https://www.saascurate.com/posts/the-modern-python-data-stack-teams-are-actually-using-in-2026) + [Datafold](https://www.datafold.com/blog/the-modern-data-stack-open-source-edition/) + [htdocs.dev](https://htdocs.dev/posts/the-modern-python-data-stack-in-2026)
> **日期**: 2026-07

## 核心要点

1. **摄取层**: dlt(Python原生/类型感知/幂等) + Airbyte(350+连接器) 取代手写脚本
2. **存储层**: Postgres一统天下(pgvector+pg_duckdb+Citus)，MongoDB退潮
3. **转换层**: Polars取代Pandas(生产ETL)，dbt主导SQL转换，Ibis跨后端兴起
4. **编排层**: Dagster(15.8K Stars/资产中心) + Prefect 取代 Airflow
5. **笔记本**: Marimo(响应式/可复现) 取代 Jupyter，Positron 数据优先IDE
6. **工具链**: uv(包管理) + Ruff(lint) + ty(类型检查) 替代 pip/black/mypy
7. **看板**: Streamlit(内部工具) + Evidence(SQL驱动) 替代 Tableau/Looker
