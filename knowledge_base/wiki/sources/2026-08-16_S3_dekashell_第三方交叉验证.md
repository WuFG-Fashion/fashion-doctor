# S3·迪卡轩DEKASHELL 第三方交叉验证

> **一句话摘要**：对实体页自宣数字（遍布 30 省、超 600 家门店、非上市无财报）做第三方交叉验证——全智 / 猎聘等招聘平台 corroborate 600+ 门店，品牌手册（自身）称 800 余家、校园宣讲转述 1,000+，自宣 600+ 站得住、无显著夸大；母公司实为杭州旭弘实业（2007 公司成立 / 2013 推品牌）。

## 核心要点（第三方数据汇总）

| 来源 | 门店数 | 备注 |
|------|--------|------|
| 自宣（实体页） | 超 600 家 | 遍布 30 省 |
| 全智（企业库 / 第三方） | 超 600 家 | 2007 创立、30 省 |
| 猎聘（招聘平台 / 第三方） | 超 600 家 | 杭州旭弘实业简介 |
| DEKASHELL 品牌手册（自身） | 800 余家 | 一二线 + 深耕三四五线，万象城 / 赛格等 |
| 江西服装学院宣讲（第三方转述） | 终端超 1,000 家 | "三年冲进杭州女装第一阵营" |

- 价格定位（品牌手册）：春 200–1,500 / 夏 200–1,200 / 秋 450–2,000 / 冬 450–4,000，均价 580–1,150；对标 MAJE / Edition / DAZZLE / MO&Co / EIFINI / PEACEBIRD。
- 母公司与时间线校正：实体页原写"2007 创立"指**杭州旭弘实业有限公司**（2007 成立），DEKASHELL 品牌实际 **2013 年**推出；"杭州轻淑"为品类描述，正确公司主体为杭州旭弘实业。

## 交叉验证结论

1. **门店 600+ 可信、区间 600–800 合理**：第三方招聘平台（全智 / 猎聘）一致 corroborate 600+，与自宣吻合；品牌手册（自身）800 余家、宣讲转述 1,000+ 为上限口径，整体无显著夸大。
2. **置信度定级**：自宣 600+ 由多个独立第三方 corroborate → 从"纯品牌自宣"上调为"品牌自宣 + 第三方 corroboration"，但非上市、无审计财报，仍为黑箱样本（仅规模可观）。
3. **母公司 / 时间线校正**：应为"杭州旭弘实业（2007 成立）旗下 DEKASHELL（2013 推）"，避免将 2007 误读为品牌创立年。
4. **对比艾诺丝**：迪卡轩数据可得性更弱（无营收披露、仅门店数 corroborate），属"规模可观但财务全黑箱"；艾诺丝已有营收量级第三方 corroborate，信息质量略高。
