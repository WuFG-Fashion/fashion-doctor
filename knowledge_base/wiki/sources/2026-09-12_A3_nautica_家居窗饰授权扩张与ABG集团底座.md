# 2026-09-12 A3 Nautica：家居窗饰品类授权扩张 + ABG 集团底座量化

> **一句话摘要**：Nautica 于 **2026-09-08** 新增**家居窗饰品类授权**——由 **SelectBlinds**（2023 年被 Hunter Douglas 收购的线上定制窗饰商）推出 **Nautica Home** 系列（卷帘/罗马帘/窗帘，仅 SelectBlinds.com 独家）；同步经 ABG 官方 PR 取得**集团底座量化**（ABG 年系统零售额 **超 $380 亿** / **1,700+ 授权商** / **150 国** / **50+ 品牌**）与 Nautica 自身"**70+ 品类**"口径——本页把 Nautica 从"服装品牌"重新定位为"**ABG 体系下的多品类品牌资产**"，并给出授权方/被授权方/运营方三层结构的最新样本。
> **来源**：PR Newswire（SelectBlinds 官方新闻稿，2026-09-08）+ Authentic Brands Group 官方新闻中心（巴西电商 PR）+ FashionNetwork 转载
> **最后更新**：2026-09-12

> **置信度**：官方公告（两则均为授权方/品牌方官方新闻稿）

## 核心要点

- **新增家居窗饰品类（新事件）**：**SelectBlinds × Nautica** 推出 **Nautica Home** 窗饰系列（Roller Shades / Roman Shades / Drapery），设计元素为条纹、航海母题、植物纹、编织肌理与素色——**仅 SelectBlinds.com 独家销售**；SelectBlinds 商品副总裁 **Ashley Damico** 具名表态"把 Nautica 标志性的海岸风带进家居"（置信度：官方公告）。
- **被授权方背景（关键结构信息）**：SelectBlinds 总部亚利桑那州 Chandler，**2023 年被 Hunter Douglas 收购**——即 Nautica 家居窗饰的对手方是**窗饰行业龙头旗下电商平台**，而非小型品牌商（置信度：官方公告）。
- **Nautica 品类数口径（新量化）**：官方 boilerplate 记 Nautica **"70+ 品类"**（服装/配饰/家居，覆盖男/女/童）——库内此前无"品类数"这一维度（置信度：官方公告）。
- **ABG 集团底座（新量化，可作品牌墙对照标尺）**：ABG 自述 **1,700+ 授权商与战略伙伴 / 覆盖 150 国 / 年系统零售额超 $380 亿 / 50+ 品牌 / 近 10 亿社媒粉丝**；组合名单含 Reebok、Champion、GUESS、Brooks Brothers、Ted Baker、Quiksilver、Spyder、Billabong、Sperry、Hunter 等（置信度：官方公告）。
- **巴西电商二次确认**：ABG 官方 PR 与 FashionNetwork 独立报道均确认巴西官方电商（nauticabr.com）由 **TRM** 运营、**首期仅男装**，并复述"**近 1,300 家独立门店与店中店 / 30+ 国**"口径（与 09-11 源一致，corroborate）（置信度：官方公告）。

## 详细内容

### 1. Nautica 授权结构全景（截至 2026-09）

| 层级 | 主体 | 职责 | 覆盖 |
|------|------|------|------|
| **品牌所有者** | Authentic Brands Group（ABG） | 持有 Nautica 品牌资产、对外授权、区域战略 | 全球 |
| **品类授权商（服装）** | 联亚集团（上海联亚商业有限公司） | 大中华区批发+零售运营 | 中国 70 直营 + 54 伙伴店 |
| **品类授权商（内衣袜）** | **Altomax** | 男/女/童内衣袜开发-生产-分销 | **巴西**（2026 年内签署） |
| **区域运营方（电商/批发）** | **TRM**（1968 年成立，巴西服装公司） | 巴西批发、零售、电商运营 | **巴西**（nauticabr.com，首期男装） |
| **品类授权商（香水）** | **Interparfums** | 香水创作/开发/生产/分销 | 全球，**2030-01 全面接管**，首年预估 > $70M |
| **品类授权商（家居窗饰）** | **SelectBlinds**（Hunter Douglas 旗下） | 定制窗饰设计-生产-电商直营 | **美国，SelectBlinds.com 独家** |

- 结构读法：**同一个品牌在同一个市场（巴西）同时跑三条线**（TRM 电商 + Altomax 内衣袜 + 既有零售），而**不同品类在不同市场用不同对手方**（窗饰在美国交给窗饰龙头，香水全球交给香水集团）——品牌方只出**品牌资产与叙事**，不承担品类运营的资本开支。
- 这解释了 Nautica 为何"服装零售规模有限但品牌声量持续"：**它的收入结构里，服装只是众多品类中的一条**。

### 2. ABG 集团底座（品牌墙对照标尺）

| 指标 | 数值 |
|------|------|
| 年系统零售额（systemwide retail sales） | **超 $380 亿** |
| 授权商与战略伙伴 | **1,700+** |
| 覆盖国家 | **150** |
| 旗下品牌 | **50+** |
| 社媒粉丝 | **近 10 亿** |

- 用途：这是**"品牌资产管理方"这一层的规模标尺**。国内品牌墙上的多个国际品牌（Nautica / DKNY / Karl Lagerfeld / Lacoste 等）背后的所有方层级规模差异极大——**判断一个品牌墙品牌"能不能持续"要看它背后所有方的品类授权网络规模**，而不是看该品牌自身在中国的门店数。

## 结论

1. **Nautica 本轮增量的价值不在"又多一个联名"，而在"授权结构的第三层被看清"**：此前库内只知 ABG 是所有者、联亚是运营方；本页补上**品类授权商层**（Altomax 内衣袜 / Interparfums 香水 / SelectBlinds 窗饰）——**同一品牌可按品类切给不同对手方，且对手方多为该品类头部（窗饰给 Hunter Douglas 系、香水给 Interparfums）**。这是"卖资产"模式的完整形态，与国内品牌"自己开店卖货"是两种生意。
2. **"70+ 品类 / 1,700 授权商 / $380 亿系统零售额"这组数字的真正用途是当尺子**：它让"品牌墙"上的国际品牌可以被按**背后所有方的授权网络规模**排序——网络越大，单一市场（如中国）的门店波动对品牌存续越不构成威胁。反之，**若一个品牌背后没有这样的授权网络，它的中国区关店就是真收缩**。
3. **窗饰这个品类选择本身值得注意**：它不进服装渠道、不依赖时尚周期、客单由"定制尺寸"决定——**是典型的"抗周期家居品类"**。品牌方把品类延伸到窗饰，等于给品牌资产增加了一条与服装零售景气度**不相关**的现金流。对国内品牌的可迁移启示是：**品牌延伸优先选"不与主业共享景气周期"的品类**，而不是延伸到自己也受同一周期影响的邻近服装品类。
4. **口径纪律**：本页"1,300 家独立门店与店中店 / 30+ 国"是 **ABG 官方 boilerplate**（含 shop-in-shops），与库内 09-05 记录的"75 国 / 244 家品牌专卖店"（爱企查口径）**统计口径不同、不可直比**。引用 Nautica 门店规模必须带限定词。
