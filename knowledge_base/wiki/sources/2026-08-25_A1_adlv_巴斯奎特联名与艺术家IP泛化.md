# ADLV × Basquiat 巴斯奎特 26SS 联名与艺术家 IP 泛化（A1·2026-08-25）

> **一句话摘要**：ADLV 2026-06-19 官宣 Basquiat 巴斯奎特 26SS 联名，把"角色 IP"打法升级为"艺术家 IP"；但同年 GAP/ONLY/优衣库 UT/MAC 同步押注同一画家，稀缺性被泛联名化稀释。

## 核心要点
- ADLV 于 **2026-06-19 官宣 Basquiat 巴斯奎特联名 26SS 系列**——首次从"卡通角色 IP"（LINE FRIENDS / 海绵宝宝）跨到"当代艺术家 IP"。
- 首尔**圣水洞 showroom 成中国游客打卡点**；"骨折专区"（折扣区）一百出头可入手，形成"代购/旅购"型跨境获客。
- **同一画家被全品类抢注**：GAP（4 月 T 恤，百元档）、ONLY（2026 夏季主打）、优衣库 UT（百元档常规在售）、宝丽来（7 月）、MAC（8 月 7 日日本首发）、Trends Hobby（8 月车模）。
- 背景锚点：2026-05-15 苏富比，巴斯奎特 1983 年《博物馆安全（百老汇崩溃）》成交 5,271.75 万美元（约 3.58 亿元人民币）——拍卖热度外溢为消费品联名潮。

## 结论
1. **ADLV 的 IP 曲线在升级但护城河在变浅**：从"熊孩子印花"到卡通角色（LINE FRIENDS/海绵宝宝）再到艺术家（Basquiat），单价与调性可以往上走；但巴斯奎特 2026 年已被 GAP/ONLY/优衣库 UT 同时使用，**授权 IP 的排他性缺失使联名从"差异化"退化为"入场券"**——这与 [[adlv]] 库内"一个爆款符号撑起品牌"的生命周期风险叠加。
2. **"骨折专区 + 韩国 showroom 打卡"是被低估的跨境获客通道**：ADLV 中国内地仅约 14 店（媒体估算），但通过首尔门店的游客流量 + 折扣区百元价格带，实际触达远超门店数暗示的规模；这条通道不进财报、不进门店数，评估韩潮品牌在华真实渗透时须单列，避免仅看门店数低估其存在感。参见 [[服装价格带管理与价格真空区]]。
3. **对 Fashion Doctor 的可操作含义**：做联名 ROI 评估时，**IP 独占性应作为独立打分维度**——同一 IP 当年被 3 个以上非竞争品类品牌使用时，溢价能力应下调；泛化的艺术家 IP 只能贡献流量，不能贡献品牌资产。
4. 数据风险：ADLV 联名与价格均为媒体/官宣口径（非财报），无销量披露，不可推断该系列实际贡献。
