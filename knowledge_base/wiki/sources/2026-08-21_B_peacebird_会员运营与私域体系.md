# 太平鸟会员运营与私域体系佐证

> **一句话摘要**：太平鸟 2026Q1 累计注册会员超 2600 万、高价值活跃会员 580 万，会员贡献营收 68%、复购率 41%、客单高出散客 56%——是"全域会员运营+私域引流"方法论的双核品牌实证。
> **来源**：wiki/raw/articles/2026-08-21_B_peacebird_会员运营与私域体系.md
> **最后更新**：2026-08-21
> **置信度**：品牌自宣（营销拆解文章口径，非财报数据；营收数字与财报不符处以财报为准）

## 核心要点
- 会员规模：累计注册会员超 2600 万、高价值活跃会员超 580 万（2026Q1）。
- 会员价值：贡献总营收 68%；复购率 41%（非会员 3 倍）；客单高出散客 56%；私域复购营收 +35%。
- 私域动作：企微+社群+小程序（穿搭顾问/新品优先购/专属折扣/生日权益）；门店到店客流引流企微转化率 27%。
- 会员成长值体系：购买/分享/评价/回收入积分，高活跃用户提前 48h 新品内测；Z 世代会员年消费频次 4.7 次、客单 1128 元、LTV 为非会员 3.2 倍。
- 门店角色转型：从销售终端→品牌体验中心+内容拍摄基地+私域流量入口。

### 2. 私域运营体系
- 渠道：企业微信 + 社群 + 会员小程序。
- 权益：专属穿搭顾问、新品优先购、专属折扣、生日权益、穿搭定制服务。
- 分层：精细化分层运营新客、老客、高价值会员。
- 全域闭环：线上下单线下提货、线下试穿线上复购。

### 3. 会员成长值体系（外套品类案例）
- 行为入积分：购买/分享/评价/回收；高活跃用户提前 48 小时参与新品内测。
- Z 世代会员：年均消费频次 4.7 次、客单价 1128 元、LTV 为非会员 3.2 倍。
- 外套品类 CAC 187 元（较 2021 -34.5%）、ROI 1:5.8。

### 4. ⚠️ 数据口径警示
- 营销软文称"2025 营收 87.16 亿 +6.21% / 2026Q1 营收 23.89 亿"，与财报口径（2025FY 63.34 亿 -6.88% / 2026Q1 16.56 亿）严重不符，判为口径混乱或数据错位。**营收数据一律以财报为准**，本页会员运营指标仅作方向性佐证。

## 结论
1. **太平鸟是"会员贡献 68% 营收"的头部样本**：会员复购率 41% 远高于行业整体优秀值 28%，但低于 VIP 分层口径 35-45% 上限——印证知识库"整体 vs 分层口径必须区分"的结论。
2. **私域引流的落点在门店**：27% 到店客流→企微转化率说明门店导购是私域第一触点——对 [[peacebird]] 组织架构调整（2026 门店精简）是"提质而非减量"的注脚。
3. **会员成长值（行为入积分）与通用方法论完全吻合**：购买/分享/评价/回收入积分 + 新品内测特权 = 权限型奖励的实证，验证 [[2026-08-21_忠诚度计划设计方法论_模型ROI兑换率]] 的"权限 > 折扣"结论。
4. **对 Fashion Doctor 的落地意义**：太平鸟 41% 复购率可作为双核运营对标基准之一，与卡宾会员 410 万（[[2026-08-21_A1_cabbeen_中期报告售罄率与会员数据]]）形成双核对照。
