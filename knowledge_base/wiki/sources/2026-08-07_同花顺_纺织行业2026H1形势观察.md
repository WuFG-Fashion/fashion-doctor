# 纺织行业2026H1形势观察（上游利润+26%）

> **一句话摘要**：2026前5月纺织规上利润+26%、利润率3.1%，呈现"纺织品韧性强、成衣承压分化"格局，兴发化纤出口+10.2%、愉悦家纺+18.2%领跑。
> **来源**：同花顺《承压转型向纵深推进，纺织行业稳中寻机步履坚实》（2026-07-24）
> **最后更新**：2026-08-07

## 核心要点
- 前5月纺织规上：工业增加值 **+3%** / 营收 **-0.2%** / 利润 **+26%** / 利润率 **3.1%**
- 化学纤维出厂价 **-0.2%**；棉纺织营收 **+1.2%**；面料出口 **-0.5%**；产业用纺织品 **+1.7%**
- H1纺织品服装出口 **1459.6亿美元**(+1.4%)：纺织品 **730亿(+3.5%)** 韧性较强，服装 **729.6亿(-0.7%)** 承压
- 兴发化纤前5月出口 **+10.2%**；愉悦家纺出口创汇 **+18.2%**（欧洲/非洲强劲）
- 行业分化：高端功能性/绿色认证产品订单充足，同质化常规产品需求疲软

## 详细内容

### 上游纺织经营全景（前5月）
| 维度 | 数据 |
|------|------|
| 规上工业增加值 | +3% |
| 营业收入 | -0.2% |
| 利润总额 | +26% |
| 营业收入利润率 | 3.1% |
| 棉纺织营收 | +1.2% |
| 产业用纺织品营收 | +1.7% |
| 面料出口 | -0.5% |

### 出口结构
- 纺织品出口730亿美元(+3.5%) vs 服装出口729.6亿美元(-0.7%)——"纺织品韧性较强、成衣承压分化"
- 根源：全球供应链重构，成衣加工订单持续向越南、孟加拉转移
- 破局：绿色/功能纤维（兴发再生纤维、功能纤维）适配欧美碳关税，议价力提升；RCEP/东南亚/中东对冲欧美下滑
