# 低绩效导购辅导与绩效面谈机制（B轮·2026-09-10）

> **一句话摘要**：低绩效导购的正确处理不是"换人"而是"**30–90 天结构化的 PIP（绩效改善计划）**"——用数据而非印象指出差距、共同定 SMART 目标、公司同步承诺支持（培训/带教/每周检查）、期满客观评估三档结论；**替换一名零售员工的成本是其年薪的 50%–200%**，辅导的性价比远高于招聘。
> **来源**：10_web/articles/2026-09-10_B_低绩效导购辅导与绩效面谈机制.md（MBA 智库五步法 / Stella 零售 PIP 指南 / PIP Templates / Asana 模板 聚合）
> **置信度**：媒体估算（HR 咨询与模板站方法论文；其中 SHRM 替换成本为第三方数据·转引）
> **brand_specific**：false（行业通用方法论，双链至 concept 不链品牌）

## 核心要点
- **PIP 不是"劝退的前奏"**，而是一个严肃的、有明确目标的改进机会；执行到位时它是"救人 + 留痕"的双重工具（若确实回不去，也是法律与运营层面的保护）。
- **PIP 时长（零售）：30–90 天**，取决于待解决问题与公司政策。
- **替换成本量化**：一名零售员工的替换成本 = 其**年薪的 50%–200%**（SHRM 转引，含招聘、培训、生产力损失）——这是"值得花时间做 PIP"的经济依据。
- **差距必须用数据不用印象**：反面案例是"需要改善态度"这类无效表述；正面是"过去一个月每周 3 个以上班次迟到 10–15 分钟""超过 60% 班次未达成日连带目标""30 天内 2 次以上服务投诉"。
- **SMART 目标示例**：❌"提高准时率" → ✅"未来 30 天所有排班准时或提前到岗，最多 1 次例外"；❌"更重视销售" → ✅"未来 45 天至少 70% 的班次达成日连带目标"。
- **PIP 是双向的**：必须写明公司承诺提供什么（专项培训、资深同事带教、管理者每周复盘、排班调整）——这既是伦理要求也是法律要求。
- **绩效问题常常是工作量问题而非态度问题**：员工倦怠常源于大量重复低技能任务（反复答同样问题、边迎宾边补货、午高峰接电话）——**这种情形不该用 PIP，该加人/减负**。

## 详细内容

### 1. 五步法（执行主干）

| 步骤 | 关键动作 | 禁忌 |
|---|---|---|
| ① 坦诚沟通，明确差距 | 正式一对一；**用具体事例和数据**指出差距；倾听员工解释，**共同确认问题根源** | 用主观评价（"态度不好"） |
| ② 共同制定 SMART 目标 | S 具体/M 可衡量/A 有挑战可实现/R 与岗位与公司目标相关/T 明确期限（30–90 天） | 目标模糊、无期限 |
| ③ 明确支持与资源 | 能力：专项培训 + 资深同事带教 + 管理者每周复盘；意愿：重连工作价值 + 短期小目标 + 及时正向反馈；资源：确保完成目标所需一切 | 只提要求不提支持 |
| ④ 定期检查与反馈 | PIP 期间**每周一次正式检查**，回顾进展、解决新问题、**记录在案**；反馈持续、具体、双向 | 只到期末才算账 |
| ⑤ 评估结果并决策 | 按预设 SMART 目标**客观评估**：成功 → 肯定并纳入常规管理但继续观察；部分改进 → 延长 PIP 或**调岗**；无改进 → 启动淘汰流程 | 长期容忍低绩效（会导致优秀人才流失） |

### 2. 零售场景的"可观察、可衡量"差距示例

- 过去一个月内，**每周 3 个及以上班次迟到 10–15 分钟**；
- **超过 60% 的班次未达成日连带/加售目标**；
- **30 天内收到 2 次以上**关于服务不主动的客户投诉。

> 起草 PIP 前先调记录：考勤表、销售报表、客户反馈日志、既往书面警告——**数据越多，对话越少变成"各说各话"**。

### 3. PIP 文档必备五要素

1. **公司期望陈述**（标准化岗位期望——注意：员工不应在 PIP 时才第一次看到它）；
2. **绩效概览**（实际表现 vs 角色期望，附客观事实）；
3. **行动计划**（可衡量的 SMART 步骤）；
4. **后续追踪排程**（含里程碑时间轴与检查会议，**提前排定**，双方都不"突然被通知"）；
5. **后果说明**（PIP 无效时会发生什么，含可能的升级或终止）。

### 4. 两个容易被忽略的判断

- **绩效问题 vs 工作量问题**：员工倦怠/表现下滑的一个被低估原因是大量重复低技能任务——**当团队被摊薄，绩效自然下滑，这不该用 PIP 处理，而该加人/减负**。
- **评估者特质偏见**：避免把"我对成功的个人主观看法"当标准——设具体清晰的评估标准，并做**多评估者审查**收集绩效数据。

### 5. 合法合规与团队影响

- **过程合法合规**：严格按公司制度与劳动法律法规执行，**保留所有沟通记录与评估证据**，避免法律风险。
- **决策果断**：所有努力无效时果断让不合适的人离开，是对双方负责；长期容忍低绩效会伤害高绩效员工士气。
- **管理团队情绪**：处理低绩效员工时注意对团队其他成员的影响——透明、公平的流程本身就是团队信号。

> ℹ️ **基准核对**：①本页 PIP 时长 30–90 天与 kb_benchmarks.guide_kpi.post_training_performance_min=0.10（培训后绩效最低提升）为**不同维度**（过程周期 vs 结果增幅），非矛盾；②"替换成本 = 年薪 50%–200%"为 SHRM 转引第三方数据，标注在正文（不升格为页面级 confidence，因来源为二手转引）；③本页与库内 [[2026-09-06_B_星级导购认证与职级晋升体系]] 构成"正向晋升 / 反向改进"的一对：星级体系定"如何升级"，PIP 定"如何不降级"——**两者共用同一套可观测行为指标**（业绩达成率、服务满意度、培训参与），口径可复用。

## 结论
1. **低绩效处理的第一性问题是"归因"**：先分清是能力问题、意愿问题还是工作量问题——**只有前两者才该走 PIP**，把工作量问题当态度问题处理，会同时失去这个人和团队的信任。
2. **PIP 的质量取决于"可观察化"程度**：把"态度差"翻译成"每周 3 次迟到 10 分钟以上""60% 班次未达连带目标"，是让面谈从"各说各话"变成"对表"的唯一办法；这与 [[2026-09-06_B_星级导购认证与职级晋升体系]] 的"行为维度须可观察化"是同一原则的正反两面。
3. **支持条款不是走过场**：PIP 里的"公司承诺"（培训/带教/每周检查/排班调整）既是员工改得动的必要条件，也是后续若需终止时的合规护城河——**跳过这一节的 PIP 在管理上无效、在法律上危险**。
4. **对 Fashion Doctor 的落地含义**：建议把 PIP 做成门店可调用的标准表单（含 SMART 目标模板 + 周检查记录 + 期满评估三档结论），与导购能力四象限（[[2026-08-07_帷幄_鞋服导购四象限评估与五项行为指标]] 的"待提升/风险"象限）打通——**象限筛出人，PIP 处理人**，避免"评完就没下文"。
