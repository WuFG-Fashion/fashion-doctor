# Streamlit 2026版本架构演进（v1.53→v1.57）

> **一句话摘要**：Streamlit 2026年5个版本完成Tornado→Starlette/Uvicorn架构迁移，新增st.bottom/st.menu_button/st.iframe等核心组件，并实现Polars零拷贝Arrow直传，是Streamlit历史上最大的架构升级。

> **来源**：Streamlit官方Release Notes
> **最后更新**：2026-06-10

## 核心要点

1. **架构革命**：v1.57默认使用Starlette/Uvicorn替代Tornado，获得ASGI兼容+现代Python异步生态
2. **Polars原生支持**：v1.57实现Polars DataFrame直接转Arrow，完全绕过pandas，性能和类型保真度双提升
3. **新组件三件套**：st.bottom（底部固定容器）、st.menu_button（下拉按钮）、st.iframe（嵌入外部内容）
4. **API现代化**：st.App程序化配置、st.App.secrets替代secrets.toml、st.logout身份登出
5. **废弃清理**：4个experimental API + 3个chart参数在2026年内完成移除

## 版本演进时间线

| 版本 | 日期 | 关键变更 |
|------|------|---------|
| v1.53.0 | 2026-01-14 | Starlette实验性引入、st.App/ASGI入口、st.logout、会话级缓存 |

## 重大架构变更详述

### Tornado → Starlette/Uvicorn

**影响**：Streamlit从同步Web框架迁移到ASGI异步框架
- ASGI兼容：可与FastAPI/Starlette等现代Python Web框架集成
- 性能提升：利用Uvicorn的高并发事件循环
- 高级配置：通过`st.App`暴露底层服务器配置
- 自定义路由：支持HTTP中间件、生命周期钩子

**对现有项目的影响**：
- 如果使用`_get_websocket_headers()` → 改用`st.context.headers`
- 如果使用Tornado特定功能 → 需评估迁移
- 新部署默认使用Starlette，无需额外配置

### Polars Arrow零拷贝

```python
# v1.57前：Polars → Pandas → Streamlit（两次转换，性能损失）
df = pl_df.to_pandas()
st.dataframe(df)

# v1.57后：Polars → Arrow → Streamlit（零拷贝，性能提升）
st.dataframe(pl_df)  # 直接传Polars DataFrame
```

## 关键API变更对照

| 旧API（已废弃） | 新API | 废弃版本 |
|------|------|------|
| `st.experimental_get_query_params()` | `st.query_params` | v1.54 |
| `st.experimental_set_query_params()` | `st.query_params` | v1.54 |
| `st.experimental_user` | `st.user` | v1.54 |
| `_get_websocket_headers()` | `st.context.headers` | v1.57 |
| `st.plotly_chart(use_container_width=True)` | 用width参数替代 | v1.57 |

## 与服装零售系统的关联

对于已使用Streamlit构建多品牌看板（如[[peacebird]]和Cabbeen看板），v1.57升级建议：
- **st.bottom**：可用于固定品牌选择器或全局筛选条件
- **Polars Arrow直传**：大数据量销售明细表渲染性能显著提升
- **Starlette架构**：与现有Python后端（FastAPI等）集成更自然
- **st.menu_button**：品牌切换/设置菜单的更好实现方式
