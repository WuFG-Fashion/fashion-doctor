# 中山大学×阿里巴巴 iTryOn——互动式视频虚拟试衣

> **一句话摘要**：ICML 2026论文首次定义"互动式视频虚拟试衣（Interactive VVT）"任务，iTryOn框架实现61%互动成功率（ISR），让AI导购能像真人主播一样拉链、揪衣角、卷袖子。
> **来源**：腾讯新闻 / ICML 2026 PMLR Vol.306
> **最后更新**：2026-07-04

## 核心要点

1. 首次填补"人与衣服主动互动"的VVT空白——现有技术只能走秀，不能拉拉链
2. 三层创新架构：3D手部先验 + A-RoPE时间语义对齐 + AC loss稀疏事件加权
3. **ISR 61%** vs 最佳竞品48.38%，2B参数击败14B竞品
4. VVT-Interact数据集：5292个样本，6类互动动作，Qwen-VL-32B自动标注
5. 产业意义：直播电商万亿市场，AI导购替代真人主播的里程碑

## 详细内容

### 三层技术架构

| 层级 | 组件 | 解决的问题 |
|------|------|------------|
| 空间指引 | 3D手部先验（HaMeR模型） | 2D骨骼深度信息丢失导致"手在干什么"无法判断 |
| 语义指引 | A-RoPE（放大系数k=4） | 动作描述与视频帧的时间对齐失败 |
| 训练优化 | AC loss（λ=0.5） | 互动帧仅占1-5%，学习信号被普通帧压倒 |

### 关键设计决策
- 不用深度图而用纯手部3D网格：深度图包含衣袖信息会"信息泄露"，导致换装残留原服装轮廓
- 形态学平滑（开运算→闭运算）：消除逐帧标注的孤立噪声

### 核心指标

| 指标 | iTryOn | 最佳竞品 | 提升幅度 |
|------|--------|---------|---------|
| ISR (互动成功率) | **61%** | CatV?TON 48.38% | +26% |
| 配对VFID | **22.46** | CatV?TON 26.99 | -16.8% |
| SSIM | **0.78** | - | - |
| FVD | **380.56** | MagicTryOn 431.79 | -11.9% |

- 非互动场景同样领先：VFID 8.43（2B参数）vs MagicTryOn 12.20（14B参数）
- 基础模型Wan2.1-VACE天然适配VVT任务（预训练目标吻合）

### VVT-Interact 数据集
- 5292个视频-服装配对（5160训练/132测试）
- 6类互动：调整领口、调整下摆、卷/放袖子、穿/脱、揪拉、其他（拉拉链等）
- 标注流程：Qwen-VL-32B → 全局描述 + 逐帧二值标签 → 形态学平滑 → 时间戳动作描述

### 已知局限
1. 不懂服装语义：对无拉链T恤做"拉拉链"产生哑剧效果
2. ISR只衡量语义成功，不能量化物理准确性（面料拉伸幅度、褶皱分布等）
