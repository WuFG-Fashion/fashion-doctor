# retailnorthstar — SKU 合理化五步减法与复杂度五区间模型

> **一句话摘要**：SKU 单向膨胀源于"加法决策成本远低于减法"（未治理品牌 SKU 年均自增 12%–18%）；用复杂度五区间定位后，多数成熟品牌处在"稀释区"；执行五步减法（退出候选池→蚕食检验→战略豁免→影响量化→释放再投入）后，SKU 降 15%–25% 而销售额持平至 +5%，售罄率提升 3–8pct、断码率降 20%–30%。

## 核心数据

| 指标 | 数值 |
|---|---|
| 未治理品牌 SKU 年均自然增长 | 12%–18% |
| 导购可熟练讲解款式数上限 | 40–60 款 |
| 有替代款时的销售转移率 | 60%–80% |
| 无替代款时的销售转移率 | 20%–40% |
| SKU 合理化后 SKU 降幅 | 15%–25% |
| 销售额变化 | 持平 ~ +5% |
| 库存周转提升 | +0.5–1.0 次/年 |
| 季末售罄率提升 | +3–8pct |
| 断码率下降 | 20%–30% |

## 复杂度五区间

| 区间 | 特征 |
|---|---|
| ① 稀缺区 | 客户找不到想要的，连带率低 |
| ② 增长区 | 每加一 SKU 有净增量 |
| ③ **最优平台区** | 边际贡献峰值且平坦（目标） |
| ④ 稀释区 | 新 SKU 蚕食老 SKU，**多数成熟品牌在此** |
| ⑤ 混乱区 | 长尾泛滥、断码、售罄率下滑 |

## 五步减法流程

1. **退出候选池** = 销量后 20% ∩ 售罄率低于品类均值 15pct ∩ 毛利率低于品类均值
2. **蚕食检验** — 同价位带存在售罄率更高的相似款 → 可吸收
3. **战略豁免** — 齐色齐码补充款 / 形象款 / 新品类试水款
4. **影响量化** — 转移率 60%–80%（有替代）或 20%–40%（无替代）
5. **释放再投入** — 60% 加深核心款 / 30% 新品类 / 10% 季中翻单弹性

## 与已有知识的衔接

- **补齐 [[sku_fine_management]] 缺失的"减法"半边**：既有页面以 ABC 分类、三色 N 码等**分类与配置**方法为主，缺少"如何系统性砍 SKU"的决策流程。本源的五步法与蚕食检验补上了这一环。
- **与 [[2026-08-05_wecx_女装商品结构金字塔四层占比]] 互补**：金字塔回答"各层占多少"（形象 5-10%/核心 50-60%/基础 20-25%/引流 10-15%），本源回答"总量该是多少、超了怎么砍"。**结构比例 + 总量治理 = 完整的宽度决策。**
- **与 [[动态OTB管理]] 的接口**：第五步"释放再投入 60/30/10"直接对接 OTB 额度再分配，其中 10% 的季中翻单弹性与季中滚动 OTB 的预留逻辑一致。
- **对 [[2026-08-01_retailnorthstar_分品类售罄率基准]] 的延伸**：同源方法论，前者给品类售罄率标尺，本源给出"用售罄率低于品类均值 15pct"作为退出候选的**具体阈值**，两者可直接串联为一套可执行规则。

## 与既有基准的核对

- 本源"季末售罄率提升 3–8pct"是**相对改善量**，与 `kb_benchmarks.json / lifecycle_sell_through.end_season_target = 0.8`、`season_end_sell_through.excellent = 0.7` 为不同维度（绝对目标 vs 改善幅度），**无矛盾**。
- 建议新增基准：`sku_rationalization.annual_sku_creep = 0.12~0.18`、`sku_rationalization.reduction_target = 0.15~0.25`、`sku_rationalization.transfer_rate_with_substitute = 0.6~0.8`、`merchandise.guide_memorizable_styles = 40~60`。
