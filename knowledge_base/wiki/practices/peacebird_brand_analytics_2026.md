# 太平鸟品牌级数据分析实践（渠道结构/门店绩效/存货周转/盈利质量穿透）

> **一句话摘要**：双核 [[peacebird|太平鸟]]（603877.SH）的**品牌级数据分析实践页**——把 2026H1 财报颗粒（营收 28.78 亿/扣非 5071 万/门店 2861/存货降 17.3%）编译成渠道结构 BI、门店绩效、存货周转与盈利质量穿透四大分析模板，是 [[brand_level_data_analysis_gap_matrix|品牌级缺口矩阵]] peacebird 行（🟡 部分覆盖 → ✅ 完整闭环）的交付；与 [[cabbeen_brand_analytics_2026|卡宾]] / [[crocs_financial_benchmark_template_2026|Crocs]] 构成"双核+第三财报品牌"同构样板。
> **来源**：太平鸟 2026 半年报 + 库内既有 A/B/C 轮源页（置信度标注见各节）
> **最后更新**：2026-09-06

## 核心要点

1. **太平鸟是 focus_brands 中"财报披露最全 + 数字化披露最全"双料标杆**：作为 A 股上市公司，营收/毛利/门店/渠道/费用全线披露，且数字化叙事（1.8 亿/50+ 项目/TOC/全域 CRM）比品牌墙任何品牌都完整——品牌级分析页的边际产出最高，可直接支撑 [[multi_brand_unified_analytics|多品牌统一分析架构]] 的"渠道-门店-盈利质量"三大模块样例。
2. **分析主矛盾 = "收缩提质 vs 规模失速"**：2026H1 营收 -0.72% 但扣非 +269.9%、归母 +30.89%，净关店 137 家——品牌级分析的价值是把"扣非转正是否靠关店、盈利是否含非经常"从叙事变成可验证指标（非经常 5100 万占净利半壁是必查项）。
3. **财报未披露售罄率，须用"存货-周转-库销"代理链**：与 [[cabbeen_brand_analytics_2026|卡宾]] 直接披露售罄率 73.8% 不同，太平鸟披露的是存货（14.35 亿 -17.3%）、期货准交率（96%）、追单周期（30 天内）——分析模板需显式声明代理口径，避免与卡宾页售罄率 SQL 直接套用。
4. **费用刚性是利润拐点的最大反向变量**：销售费用率 2022-25 由 36.8% 升至 41.6%（09-04 源），2026Q2 三费率 52.92%——"关店省下的钱被费用刚性吃掉多少"是太平鸟单店模型的必算题。

## 详细内容

### 1. 渠道结构分析（先立口径表再出 BI）

太平鸟 2026H1 渠道颗粒（置信度：财报，半年报口径）：

| 渠道 | 2026H1 营收 | 同比 | 占比 | 解读 |
|------|-----------|------|------|------|
| 直营 | 14.42 亿 | **+2.73%** | ~50% | 增长引擎：Q1 直营 +7.9% → H1 +2.73% 回落，Q2 承压 |
| 线上 | 7.71 亿 | **+3.06%** | ~27% | 增长引擎：线上毛利率 54.93%(Q1) 连续两年每年 +5pp |
| 加盟 | 6.40 亿 | **-10.32%** | ~22% | 拖累项：净关加盟 83 家 + TOC 模式切换期 |

> **口径注意**：直营 +2.73%/线上 +3.06% 均为 H1 累计口径；"直营 Q1 +7.9%"（券商/媒体口径）为单季——混用会得出"直营加速还是减速"的矛盾结论。做太平鸟渠道增速报表前必须声明"累计 vs 单季"。

BI 看板建议（[[retail_bi_visualization_2026|零售 BI 可视化]] 视角）：
- **高管层一张卡**：渠道营收增速拆直营(+2.73%)/线上(+3.06%)/加盟(-10.32%) + 品牌拆男装/女装/MINI/LEDIN（H1：男装 11.96 亿 +1.38%、女装 10.84 亿 +2.26%、MINI 3.90 亿、LEDIN 1.81 亿）——一眼看清"增收靠直营线上、失速在加盟与女装/童装收缩之间"。
- **商品层**：男装 vs 女装 × 直营/加盟的毛利率差异矩阵（财报口径直营毛利率 > 加盟；线上毛利率 H1 提升 +4.33pp）。

### 2. 门店绩效分析（2861 店的关店账）

- 门店：期末 **2861 家**，较年初 2998 净减 **137**（直营 -54/加盟 -83）；轨迹 3373(2024末)→2998(2025末)→2861(2026H1)（置信度：财报）。
- **关店账 SQL 模板**：净关店 137 家的营收影响 = Σ(被关店上年营收) − 余店同店增长。财报直营 +2.73% 隐含"关低效店 > 同店下滑"才成立——用门店级 POS 验证：保留店店均营收增速 是否 > 关店前店均。

```sql
-- 关店提质验证（{brand}_store_monthly：店-月-营收）
WITH store_ret AS (          -- 保留店：2026H1 在营且 2025 同期在营
  SELECT store_id,
         SUM(CASE WHEN ym BETWEEN '2026-01' AND '2026-06' THEN rev ELSE 0 END) AS rev_26h1,
         SUM(CASE WHEN ym BETWEEN '2025-01' AND '2025-06' THEN rev ELSE 0 END) AS rev_25h1
  FROM {brand}_store_monthly
  WHERE store_id IN (SELECT store_id FROM {brand}_store WHERE is_open_2026h1 = 1)
  GROUP BY store_id
)
SELECT round(100.0*(SUM(rev_26h1)-SUM(rev_25h1))/SUM(rev_25h1),1) AS retained_store_growth
FROM store_ret;
-- 判读：retained_store_growth 若 > 2.73%（直营增速），说明直营增长含"关店剥离低基数"成分需剔除再看真实店效
```

- **大店模型**：上海南京西路旗舰店超两成业绩来自海外消费者（媒体估算，张江平采访）；新增旗舰店/集合店 45 家（2025）——"关小店开大店"的结构迁移可用店均营收/坪效交叉验证（财报 2026Q1 直营店数口径 ~1542、单店坪效 +18.7%，置信度：媒体估算）。

### 3. 存货周转与"售罄率代理链"

太平鸟财报未披露售罄率，用存货-周转-供应链指标代理（区别于卡宾直披露售罄率）：

| 指标 | 数值 | 口径 | 置信度 |
|------|------|------|--------|
| 期末存货（2025FY） | 14.35 亿 | -17.30% | 财报 |
| 存货（2026H1 隐含） | 持续降（媒体：同比 -17%） | 快反+TOC 消化 | 财报/媒体估算 |
| 期货准交率 | 96% | 供应链响应 | 财报 |
| 追单周期 | ≤30 天 | 快反 | 财报 |
| 高峰库存历史 | ~25 亿 → 降近半 | 张江平采访 | 媒体估算 |
| 老货处理通道 | 电商/奥莱/唯品会/部分加盟 | 有管理去化 | 财报 |

> **口径注意**：媒体"存货同比 -17%"与财报"2025FY 期末 14.35 亿 -17.30%"为同一数据不同引用时点；2026H1 中报未单列存货同比时，用 kb_benchmarks / 存货跌价准备 1.04 亿（2026H1 计提）做间接交叉。

**库销比/周转 SQL 模板**（对齐 kb 库存健康红线与 [[库存三大核心指标]]）：
- 太平鸟 2025 营收 63.34 亿 ÷ 期末存货 14.35 亿 ≈ **4.4 次/年**周转（财报口径粗算）——对照 kb turnover_rate_healthy_min=4.0，**刚过健康线**；但注意 A 股存货含经销商铺货口径，与卡宾 246 天(1.5x)不可直比，须先对齐"含不含加盟库存"。
- 深度滞销判定（同 [[cabbeen_brand_analytics_2026|卡宾页]] 逻辑）：库龄>90 天 ∧ 近 14 天零销 ∧ 覆盖>120 天——太平鸟 2026H1 存货跌价准备 1.04 亿即该组合的财报侧证据。

### 4. 盈利质量穿透（非经常性损益是必查项）

太平鸟 2026H1 盈利结构（置信度：财报）：

| 指标 | 数值 | 解读 |
|------|------|------|
| 归母净利润 | 1.02 亿 (+30.89%) | 表面拐点 |
| 扣非归母 | 5071 万 (+269.9%) | 真实主业：低基数高增速 |
| 非经常性损益 | 5100.91 万 | **占净利半壁**：政府补助 3597.82 万 + 金融资产收益 |
| Q2 单季归母 | -3492 万 | 主业单季仍亏 |

- **穿透模板（[[earnings_quality_nonrecurring_2026|盈利质量]] 应用）**：扣非/归母 = 5071/10200 ≈ **0.497**——扣非不足归母一半，任何"利润拐点"结论必须带"剔除 5100 万非经常后主业仍薄"限定词；Q3 观察点是单季扣非能否转正。
- **费用刚性穿透**：销售费用率 2022-25 36.8%→41.6%（09-04 A3 源），2026Q2 三费率 52.92%——"关店省租金 vs 费用率刚性上升"对利润的净效应需单店模型验证：单店店效提升（坪效 +18.7%）是否跑赢费用率上行（+4.8pp/三年）。

### 5. 数字化体系对多品牌系统的样板映射

- 投入：近三年 **1.8 亿**、**50+ 项目**、35 套系统（IBM/华为共建架构，置信度：财报/官方口径）；全球时尚研发中心 **6 亿**（财报）。
- 组织："前台灵活、中台强大、后台稳健"——与 [[multi_brand_unified_analytics|多品牌统一架构]] 四层设计、[[brand_config_driven_system|品牌配置驱动系统]] 同构（中台持数据资产、前台消费数据能力）。
- 数据闭环：全域 CRM 千万级画像 + TOC 以销定产 + 门店"脉搏"实时回传（媒体估算）→ 数字化成效最终裁判仍是售罄率/周转，财报侧 2026H1 存货降幅与准交率 96% 是仅有的两个硬证据。
- **样板意义**：太平鸟是品牌墙 26 品牌"数据基建理想态"的参照物（他们缺的正是这套体系），也是多品牌系统"按品牌配置数字化成熟度分级"的 L1 样例。

## 结论

1. **太平鸟品牌级分析的第一性问题是盈利质量，不是增速**：H1 归母 +30.89% 叙事下，扣非 5071 万占归母不到一半、Q2 单季仍亏 -3492 万——任何 BI 看板若只呈现"归母 +30.89% 利润拐点"而不穿透非经常性损益，都会系统性高估改革成效（呼应 [[brand_risk_signals_2026]]"拐点叙事需穿透"）。
2. **渠道分析必须三拆且分累计/单季口径**：直营 +2.73%、线上 +3.06%、加盟 -10.32% 拼出"关加盟、保直营、靠线上毛利提升"的完整结构叙事；而"Q1 直营 +7.9%"是单季口径，与 H1 累计混用即误判。口径表先行是所有渠道 BI 的前提。
3. **售罄率披露缺口决定了太平鸟分析模板与卡宾不同构**：卡宾可直算售罄率趋势（73.8%/48.4%），太平鸟只能用"存货 14.35 亿 -17.3% + 准交率 96% + 追单 30 天 + 跌价准备 1.04 亿"代理链——这也是"多品牌统一分析"必须按品牌披露颗粒度做适配层而非一刀切模板的直接证据。
4. **双核品牌级覆盖至此全部闭环（3/35）**：[[cabbeen_brand_analytics_2026|卡宾]]（售罄率直算型）+ 本页太平鸟（代理链型）+ [[crocs_financial_benchmark_template_2026|Crocs]]（财报对标模板型）覆盖三种披露形态，为 P1 上市公司组（dkny/tommy/karl/salomon/hoka/levis/diesel）提供可直接复用的三种模板骨架。
