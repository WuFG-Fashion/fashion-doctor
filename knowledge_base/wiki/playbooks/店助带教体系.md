# 店助带教体系

> **一句话摘要**：店助岗位的"认知→职责→流程→带教"四件套培训体系——角色认知（我是谁）、岗位职责（做什么）、日工作流程（一天怎么过）、带教技巧（怎么带新人），店助既是执行者也是带教者。
> **来源**：human 培训课件 6.3 店助培训四件套（企业内部课件，置信度：品牌自宣）
> **最后更新**：2026-08-25

## 结论

1. **店助 = 店长分身 + 导购带教者**：[[2026-08-25_human_店助岗位职责]] 定义其"执行政策/拆目标/管日常"，[[2026-08-25_human_店铺带教技巧]]（标题级）补充其"带新人"职责——店助是店铺能力传导的关键枢纽。
2. **四件套顺序即培训路径**：先角色认知（解决"为什么做"）→ 再岗位职责（"做什么"）→ 日流程（"怎么做"）→ 带教技巧（"怎么带人"）——与 [[导购培训闭环体系]] 的"新人 7 天上岗"可对接为店助进阶版。
3. **日工作流程埋着分时段数据跟踪**：[[2026-08-25_human_店铺日工作流程]] 与 [[2026-08-25_human_卖场温度计]] 的"时段报数"呼应——店助按流程执行即完成数据采集动作。

## 适用场景

- 店助晋升培训 / 店长储备培养
- 新人入职带教（店助为带教执行人）
- 门店岗位职责说明书与考核设计

## SOP 结构

### 1. 角色认知（先于职责）
- 角色 = 地位认知 + 行为规范 + 权力义务
- 让店助认同"我是店长分身、团队枢纽"，再谈具体职责

### 2. 岗位职责（执行层）
- 职责一：执行企业政策与指标（宣布/解释/执行制度，制定销售目标计划，完成经营指标）
- 职责二：店铺日常运营模块（详见 [[2026-08-25_human_店助岗位职责]] 原文表格）

### 3. 日工作流程（时间轴）
- 以 9:00-21:30 班次为例：开市（准备/陈列/晨会）→ 营业（迎宾/补货/交接/销售跟踪）→ 闭店（盘点/结算/总结）

### 4. 带教技巧（传导层）
- 老带新：店助带教新导购（正文已补转 2013-07，见 [[2026-08-25_human_店铺带教技巧]]）

## 关键指标

- 店助转正率、店助→店长晋升率
- 新人带教达标率（带出的新人 7 天上岗达标）
- 店助目标完成率（按岗位职责考核）
