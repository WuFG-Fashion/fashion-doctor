# 店长现场与会议管理

> **一句话摘要**：店长日常管理的双引擎——现场管理（人店货三要素 + 目标层层拆解到时段）+ 会议管理（例会意义→会前准备→高效会议→流程演练），配套岗位认知与数据培训，构成店长"管理+数据+沟通"能力底座。
> **来源**：human 培训课件《金牌店长特训营·现场管理篇/会议管理篇》《黄石东尚店长培训》（企业内部课件，置信度：品牌自宣）
> **最后更新**：2026-08-25

## 结论

1. **现场管理管"时段"，会议管理管"节点"**：现场管理把目标拆到每日每时段（[[2026-08-25_human_1_4金牌店长特训营之现场管理篇]]），会议管理在晨会/交接/晚会节点同步进度（[[2026-08-25_human_1_3金牌店长特训营之会议管理篇]]）——双引擎配合即店长日经营节奏。
2. **店长 = 管理 + 数据 + 沟通三合一**：[[2026-08-25_human_黄石东尚店长培训_讲义]] 明确定义店长需具备传达（政策）、统筹（人店货）、数据（分析落差）、沟通（建桥梁）四能力——数据能力已是店长必修，与 [[卖场管理SOP]] 的温度计指标呼应。
3. **目标拆解链是现场管理的灵魂**：一年→每月→每周→每日→时段，与 [[目标与时间管理]] 的个人目标四层拆解同构——企业目标与个人目标用同一套拆解逻辑。

## 适用场景

- 新店长上岗培训（岗位认知 + 现场管理）
- 门店晨会/周会体系搭建（会议管理）
- 目标未达成时的"目标拆解→时段追踪"复盘

## SOP 结构

### 1. 现场管理（人店货）
- 定义：既定时间内围绕目标进行的人店货三要素综合管理
- 目标拆解链：年→月→周→日→时段→单
- 巡店三维：人（状态/技能）、店（卖场/氛围）、货（结构/陈列）

### 2. 会议管理（例会）
- 例会意义 → 会前准备（议程/数据）→ 高效会议（节奏/参与）→ 流程演练
- 晨会定调 / 交接会同步 / 晚会复盘

### 3. 岗位认知（店长四能力）
- 传达者：公司政策传达（衔接 [[店铺运营制度]]）
- 统筹者：人店货统筹
- 数据者：商品数据分析落差（衔接 [[卖场管理SOP]] 温度计）
- 沟通者：团队沟通桥梁（衔接 [[FPA性格色彩与沟通]]）

## 关键指标

- 目标时段达成率（拆解后追踪）
- 例会执行率与质量评分
- 店长数据诊断能力（商品落差分析准确性）
