# 会员价值提升打法

> **一句话摘要**：把"会员运营体系"落成三个可执行的经营动作——新客七日激活、沉睡会员精准唤醒、VIP 分层权益升级，每条都带步骤、指标与指向的 SOP 页。

## 结论

1. **会员价值提升不是"发券"而是"分阶段做对动作"**：新客靠七日激活阶梯（复购 25%→70%）、沉睡客靠 RFM 筛 + AI 优先名单（唤醒贡献激活收入 76%）、VIP 靠分层权益升级（VIP 复购 35-45% vs 整体 28%）——三件事对应客户生命周期的不同阶段，不能混为一谈。
2. **动作必须配"剂量"和"指标"，否则变骚扰**：企微 ≤2 次/周、短信 ≤4 次/月；监控企微打开 <50% / 核销 <30% / 沉睡激活 <20% 即预警调优。没有指标的动作只是在烧客户信任。
3. **本打法承接体系页 `[[会员与VIP运营体系2026]]` 的铁三角**，是"结论 → 行动"的终点页：体系页讲 why/what，本页讲 how。

## 打法一：新客 → 复购激活（七日激活阶梯）

**目标**：首单后 7 天把复购率从 25% 拉到 70%
**步骤**：
1. 首单后 1-2 天（探索期）：首单满赠活动 + 入会无门槛券
2. 首单后 3-5 天（稳定期）：积分翻倍激励 + 搭配推荐
3. 首单后 6-7 天（爆发期）：引导完善资料、参与互动
4. 消费后第 7 天自动推送复购券（企微触发型计划）
**指标**：7 日留存 >25%、首单后 30 日复购率 +10pp
**详述**：[[会员复购率提升策略]] / [[私域运营方法论]]

## 打法二：沉睡会员精准唤醒（RFM + AI）

**目标**：沉睡唤醒率 >15%（优秀值）
**步骤**：
1. 用 RFM 筛"高金额近期无动静"+"频次稳但突然断掉"两类（约占沉默会员 20-30%，贡献绝大部分激活收入）
2. AI 生成每日优先联系名单 + 差异化话术 + 场景化搭配推荐
3. 前 15 天只做服务（售后回访 / 穿着建议 / 保养提醒 / 换季搭配），不硬卖
4. 90 天未消费触发个性化回归福利 + 专属满减
**指标**：消息触达线索 +167%、跟进业绩 +79%、老客收入 +45%（唤醒贡献 76%）、导购任务执行率 40%→95%
**详述**：[[RFM会员分层运营实战]] / [[sleeping_member_reactivation|沉睡会员唤醒策略]] / [[2026-08-05_有赞_高端男装RFM沉默会员AI唤醒]]

## 打法三：VIP 分层权益升级（提升 LTV）

**目标**：VIP 复购率 35-45%、会员销售占比 >60%
**步骤**：
1. 建立累计门槛型五级（银 5k / 金 15k / 白金 30k / 黑金 50k / 钻石 100k+），相邻门槛保持 2-3 倍牵引
2. 年度降级机制（未达当级门槛 80% 降级）防止会员池虚胖
3. 差异化权益：高价值→限量优先购 / 专属售后 / 年度礼包；潜力→满额升级 / 积分翻倍；沉睡→回归专属券
4. 权益"内容化 + 具象化 + 情感化"：短视频讲品牌、量化权益价值、生日定制，避免纯折扣堆砌
**指标**：VIP 年均消费为普通用户 5.7 倍（FIDUE）、头部 30% 贡献 80% 线下（江南布衣）
**详述**：[[vip_tier|VIP分层模型]] / [[全渠道会员一体化]] / [[2026-08-07_MOCo_EPO会员五级分层与VIP复购基准]]
