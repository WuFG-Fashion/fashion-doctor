# 决策日志模板

> 重要经营决定统一记录，形成"为什么这么定"的可追溯链路。这是作战手册层的"复盘底座"——任何手册的修订、任何重大业务选择，都该在此留痕，避免"当时为啥这么干"失传。

## 何时记一笔

- 清仓折扣特批（见 [[清仓决策树]] 四级）
- 订货会 OTB 重大调整（见 [[季初订货节奏]]）
- 导购考核标准变更（见 [[导购培训SOP]]）
- 任何"拍板"且影响跨周/跨店的动作

## 模板（复制下方表格填写）

```markdown
## [YYYY-MM-DD] 决策标题

- **决策人**：
- **背景**：（遇到了什么问题 / 什么机会）
- **可选方案**：A / B / C
- **最终选择**：
- **理由**：（数据 / 经验 / 约束）
- **预期结果**：
- **复盘日期**：YYYY-MM-DD
- **实际结果**：（复盘时填）
- **相关手册**：对应 playbook 页面 / 对应 concept 页面
```

## 写作纪律

1. 一决定一记录，不合并。
2. 必须填"理由"——没有理由的决定不值得记。
3. 复盘日到期必须在"实际结果"回填，形成闭环（否则日志失去意义）。
4. 与 `human/` 人工区互补：本模板是"结构化决策"，`human/` 是"自由笔记"，互不替代。
