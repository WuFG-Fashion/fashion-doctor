# Streamlit 2026全版本更新：v1.53-v1.58 官方发布说明

> **来源**：Streamlit官方文档, "2026 release notes", 2026-01～2026-05
> **URL**：https://docs.streamlit.io/develop/quick-reference/release-notes/2026

## v1.58.0（2026-05-28）— 并行Fragment + 分页组件

### 新特性
| 特性 | 说明 |
|------|------|
| `@st.fragment` parallel=True | Fragment并行执行，后台工作流更流畅 |
| `st.pagination` | 全新分页组件（数据框分页等） |
| `streamlit skills` CLI | AI Agent技能安装命令行工具 |
| `st.App` 自定义异常处理 | 附加自定义异常处理器 |
| `st.expander`/`st.status` 新type | 更紧凑视觉样式 |

### 安全与修复
- `st.markdown`阻止`javascript:`和`vbscript:` URL（XSS防护）
- OAuth修复：升级1.57后MismatchingStateError解决
- OAuth PKCE恢复（Starlette认证流程）
- `st.login` Cookie恢复30天持久化
- FIPS兼容：`blake2b`哈希`usedforsecurity=False`
- `st.multiselect`超大选项列表禁用"全选"防止性能问题

### 移除
- 弃用的`element.add_rows`
- LangChain回调处理器集成

## v1.57.0（2026-04-29）— Starlette正式化

### 架构升级
| 特性 | 说明 |
|------|------|
| **Starlette成为默认** | 替换Tornado，更好的ASGI兼容/性能/现代Python异步生态 |
| `st.bottom` | 固定底部容器（聊天输入/工具栏/持久控件） |
| `:shimmer[]` Markdown | 闪烁动画加载文本 |
| `st.App` 程序化配置 | st命名空间直接可用，含secrets参数 |
| AI Agent技能集成 | pip包捆绑Streamlit开发AI助手技能 |
| Alert元素`title`参数 | st.info/warning/error/success支持粗体标题 |

### 性能优化
- **Polars直接转Arrow**：绕过pandas，提升Polars DataFrame性能+类型保真度

### 移除
- `st.plotly_chart`/`st.vega_lite_chart`弃用参数
- 弃用的`_get_websocket_headers`

## v1.56.0（2026-03-31）— 全新组件 + pandas 3.x

### 新组件
| 特性 | 说明 |
|------|------|
| `st.menu_button` | 下拉按钮+可定制弹出容器 |
| `st.iframe` | 直接嵌入外部URL或HTML |
| `st.selectbox`/`multiselect`搜索过滤 | `filter_mode`参数 |
| `st.dataframe`程序化选择 | `selection`参数设置选择状态 |
| `"single-row-required"`模式 | 始终保持恰好一行选中 |
| `AudioColumn`/`VideoColumn` | 数据框内直接播放音视频 |
| `st.Page`外部URL | 导航侧边栏添加外部链接 |

### 平台支持
- **正式支持pandas 3.x**

## v1.55.0（2026-03-03）— 动态容器 + 组件绑定

### 关键特性
- **动态容器**：`st.tabs`/`st.popover`/`st.expander`支持`on_change`参数
- **组件绑定**：`bind`参数简化组件状态与查询参数同步
- **st.image可点击**：`link`参数支持HTTP/HTTPS
- 组件标识简化：`st.pills`/`st.segmented_control`仅用key标识
- 应用菜单重新设计（无障碍改进+版本复制按钮）

## v1.54.0（2026-02-04）— 图表增强 + 安全修复

### 关键特性
- 图表颜色支持基础调色板 + `theme.chartDivergingColors`
- `st.logo`支持Material图标/Emoji
- 组件标识扩展：dataframe/chart/date_input/radio等仅用key标识
- 安全修复：SSRF和路径遍历漏洞防护

## v1.53.0（2026-01-14）— st.App ASGI入口

### 关键特性
- **`st.App`实验性ASGI入口**：自定义HTTP路由/中间件/生命周期钩子
- **Starlette实验支持**：`server.useStarlette`配置
- 会话作用域缓存：`st.cache_data`/`st.cache_resource`支持session级
- OIDC Token暴露+`st.logout`身份提供商登出
- `st.spinner`变为瞬态元素（不再包含在重运行中）

## 2026年六大趋势

1. **Web框架现代化**：Tornado→Starlette/Uvicorn，拥抱ASGI生态
2. **AI/Agent集成**：内置AI编码助手技能、`streamlit skills` CLI
3. **组件身份简化**：基于key的标识防参数变更导致状态重置
4. **性能优化**：Polars零拷贝Arrow、并行Fragment、超大列表保护
5. **安全增强**：SSRF防护、XSS阻止、FIPS兼容、OAuth完善
6. **UI一致性**：组件样式统一、无障碍改进、响应式优化
