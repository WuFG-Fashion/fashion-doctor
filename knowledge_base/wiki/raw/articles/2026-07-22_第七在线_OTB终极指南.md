## 核心数据

| 指标 | 数值 |
|------|------|
| 全球零售库存失衡损失 | 1.7万亿美元(占零售总额6.5%) |
| OTB公式 | 计划销售额 + 计划期末库存 - 期初库存 - 已下采购订单 |
| 期货OTB占比 | 75-85%（订货会前锁定） |
| 快反OTB占比 | 15-25%（全季保持可用） |
| 更新频率 | 每周（5亿+品牌）/ 两周（中小品牌） |
| 安全水位 | 月计划销售额的10-15% |
| AI毛利率提升潜力 | >25%（IHL预测至2029） |

## 动态OTB vs 静态OTB

| 维度 | 静态OTB | 动态OTB |
|------|---------|---------|
| 更新频率 | 每季一次 | 每周/每月 |
| 响应速度 | 季度滞后 | 实时调整 |
| 过买风险 | 高（信息衰减） | 低（自动约束） |
| 补货灵活度 | 低（预算锁死） | 高（滚动释放） |

## 中国鞋服三大特殊挑战

1. **期货+快反双轨制**：需分两个OTB池独立管控
2. **经销商库存穿透难**：总部对经销商库存数据掌握不完整
3. **多平台电商分仓**：天猫/京东/抖音/小程序 → 全渠道库存可视化是前提

## OTB管理五最佳实践

1. 按周更新（≥5亿品牌每周；中小品牌两周）
2. 区分期货OTB和快反OTB两个池子（快反15-25%）
3. 强制关联实际销售数据（实时看板）
4. 设定OTB红线和预警（余额<月销售额10-15%自动预警）
5. 按品类和渠道分级管理（各品类独立管控，不互借）

## OTB超额处理步骤
1. 暂停未签合同新增订单
2. 协商已下订单延期/减量
3. 加速库存消化（调拨/折扣）
4. 分析根因修正下周期参数
