# 季前采买前置承诺vs预留追单的2026实操（A/B/C分位与OTB储备）

- 来源: https://eightx.co/blog/preseason-inventory-buying
- 采集日期: 2026-08-13
- 主题: 商品企划 / OTB / 季前采买 / 追单储备

## 核心要点

1. **三分位承诺比例（按 SKU 属性，非品牌自上而下）**
   - Replenishable basics（可补基础款）：前置承诺 75–85%，OTB 储备 15–25%
   - Seasonal core（季节核心款）：前置承诺 60–75%，OTB 储备 25–40%
   - High-fashion / experimental（时尚/实验款）：前置承诺 40–60%，OTB 储备 40–60%
   - 逻辑：需求可预测、over-buy 下行小→深买； novelty/时尚色/TikTok 引流款→浅买，只追赢家。

2. **A/B/C rank 实操**：按销量与毛利排序 SKU，只给 A 类深买；C 类丢弃或代发，B 类浅买；整体买货拆分由分位叠加得出，非顶层拍板。

3. **OTB 公式（零售口径）**
   - OTB = 计划销售 + 计划 markdown + 计划期末库存 − 期初库存 − 在途库存
   - 实例：Q4 夹克计划销售 $1,000,000 + markdown $100,000 + 期末库存 $150,000 − 期初 $300,000 = $950,000 零售买力；先按零售算，再乘 (1−毛利率) 转成本（50% 毛利 → 约 $475,000 成本）。
   - 70/30 政策：$665K 零售进前置承诺，$285K 零售留季内追单。

4. **储备金纪律**：季末前储备金不低于品类 10–15%；按周售罄分 2–4 波释放，不在第 2 周一次性追光首个爆款。

5. **加深前置承诺的三股力量**：交期 > 半季（生产+运输 90–120 天 vs 8–10 周峰值，追单错过峰值→承诺提至 80%）；工厂 MOQ 强制；EOQ。

## 备注

- 海外 DTC 服饰视角，与 [[动态OTB管理]]、[[柔性供应链与商品企划]] 互补；三分位承诺比例、70/30、储备 10–15% 为 kb 未固化可落库的新基准。
