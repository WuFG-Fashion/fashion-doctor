### 关键KPI

- 电商女装退换货率：50%以上
- 爆款追单周期：7-14天
- 营收50亿企业周转降低30天 = 释放数亿元现金流
- 缺货挽回营收：3%-8%
- 投资回收期(Payback)：1.5-2.5年
- RFID盘点准确率：99.9%（从"全员熬夜盘两天"到"一人一小时"）

## OTB（采购限额计划）

### 核心公式
OTB = 科学规划各品类/波段的采购预算，防止盲目超买

### 数字化OTB方法
1. 趋势洞察：CV分析流行色/图案/领型 + NLP提取消费者核心诉求
2. 历史销售矩阵：基于"价格带-品类-风格"识别空白与红海市场
3. 需求共识：AI基线预测 + 人工营销日历/促销计划干预

## 售罄率管理

### 分生命周期策略

| 阶段 | 策略 |
|------|------|
| 导入期 | 正价销售，监控试销数据 |
| 成长期(爆款) | 触发追单，正价或满减提升客单 |
| 成熟期(平销) | 9折或"第二件半价" |
| 衰退期(滞销) | 奥莱/内购/折扣平台清算 |

## 核心方法论

### 四级滚动计划
年度规划 → 季度调整 → 月度滚动 → 周度微调

### 延迟制造(Postponement)
"备坯不备色"：先采购白坯布 → 首单测试爆款颜色 → 再定向印染

### 供应商分级
- 战略核心：基础款大单
- 柔性快反：时尚款小单
- 应急外包：应急补充

### 数字化ROI公式
ROI = (库存资金利息节约 + 缺货挽回利润 + 降本增效利润) ÷ (软件授权费 + 实施咨询费 + 硬件IoT投入 + 内部人力成本)

## 五大避坑

1. 重系统轻数据 → 先治数据再上系统
2. 大而全不敏捷 → MVP先行3-6个月
3. IT主导业务旁观 → COO/供应链VP任Sponsor
4. 忽视利益分配 → 配套资金占用费/利润分成
5. 迷信AI万能 → AI副驾驶+人机长Override
