# 季前商品计划制定流程：从经营目标到上市规划落地

> **来源**：百家号 | 2026-06-29
> **URL**：https://baijiahao.baidu.com/s?id=1869293386560721555

## 核心拆解链路

```
销售目标 → 渠道目标 → 品类目标 → 波段目标 → 波段内OTB预算 → SKU数量与款深
```

## 关键原则
- **波段是OTB管理的基本单位**，不是过渡层
- SKU是波段内OTB计算之后的输出结果，不是计划起点
- OTB首先是预算约束线，其次才是动态管理机制

## OTB拆解路径
```
年度OTB → 产品季OTB → 品类OTB → 波段OTB（关键层级，不可跳过）→ 首单OTB + 快反OTB池
```
- 首单OTB（期货）：约70%-80%
- 快反OTB池：约15%-25%，全季保留不提前锁定

## SKU款深决策
### 三维框架
| 维度 | 内容 | 失衡后果 |
|------|------|---------|
| 品类结构 | T恤/衬衫/裤装/外套销售份额 | 品类间竞争失调 |
| 价格带结构 | 低价引流/中价销售/高价形象利润 | 消费选择空间削弱 |
| 款式结构 | 引流/核心/利润/形象款配比 | 波段定位失焦 |

### 四种款型
- 引流款：深度较浅，快速测试
- 核心款：深度最深，主力销售
- 利润款：控制深度，维持利润率
- 形象款：深度最浅，制造稀缺

## 上市倒推
```
计划上市时间 → 供应商生产交期(如10周) → 物流时间 → 仓库处理 → 最晚下单截止日 → OTB授权完成时间
```
- OTB授权必须在订货会启动前至少2-3周完成
- 系统应提前14天预警OTB未授权风险

## 常见错误
- SKU当作计划起点而不是输出结果
- 品类OTB直接跳到供应商OTB（跳过波段）
- OTB还在走审批，供应商交期窗口已关闭→货晚30天→整个销售季失败
