## 概述

鹿映星河时尚智能镜是一款面向**服装零售门店**的 AI 智能硬件产品。它**不是**传统试衣镜或智能屏，而是一套面向服装门店的完整 **AI 经营系统**，集智能搭配、AI 试衣、导购辅助、门店管理、商品诊断与经营建议生成功能于一体。

## 核心功能模块

### 1. 智能搭配推荐
- 自研时尚搭配算法
- 综合考量：顾客身材、脸型、肤色、风格偏好
- 结合门店**实时货品**（当前可售商品、库存）
- 输出真实可售的穿搭方案（图片/视频形式）

### 2. AI 试衣呈现
- 试穿前直观看到整体搭配效果
- 提升试穿意愿，缩短决策路径

### 3. 门店实时货品联动
- 搭配推荐与门店库存实时关联
- 确保推荐商品为门店实际可售

### 4. 导购辅助与成长分析
- 记录导购每日接待过程并进行 AI 分析
- 多维度复盘：商品讲解、风格判断、搭配推荐、试穿引导、成交推进
- 为每位导购生成**个性化提升建议**
- 培训不再完全依赖店长经验或人工观察

### 5. 门店经营数据分析
| 数据类型 | 分析目的 |
|---------|---------|
| 顾客关注 | 哪些款式更吸引顾客 |
| 试穿触发 | 哪些搭配更容易促成试穿 |
| 导购推荐 | 哪些导购动作更容易推动成交 |
| 商品曝光与成交转化 | 哪些商品曝光高但转化弱 |
| 滞销款识别 | 需通过搭配/陈列/话术重新激活的商品 |

### 6. 经营建议生成
- 今日建议主推商品
- 推荐上墙展示的搭配组合
- 不同顾客类型话术方向
- 需要补货/调货/重新陈列的商品
- 滞销款场景化搭配方案

### 7. 商品调补配决策
- 基于数据分析提供调货、补货策略

### 8. 滞销款激活方案
- 针对滞销商品生成场景化搭配方案

## 覆盖的零售场景

| 场景 | 应用 |
|------|------|
| 顾客进店 | 风格识别、需求判断 |
| 智能搭配 | 基于顾客特征与门店货品生成推荐 |
| 试穿引导 | 缩短决策路径，提升试穿转化 |
| 导购复盘 | 接待过程记录与分析 |
| 商品诊断 | 识别曝光高/成交弱、滞销等问题商品 |
| 调补配策略 | 补货、调货决策支持 |
| 滞销激活 | 重新搭配、陈列建议 |

## AI 能力总结

| AI能力 | 说明 |
|--------|------|
| 时尚搭配算法 | 自研，结合顾客身体特征与门店货品 |
| 数据分析引擎 | 从前端试穿到后端成交的全链路分析 |
| 经营建议生成 | 将数据转化为"下一步怎么做"的执行清单 |
| 导购成长AI分析 | 多维度复盘导购服务，生成个性化提升建议 |

## 对服装门店的核心价值

1. **补齐过程数据**：传统 POS 只能看到销售结果，该系统记录销售全过程
2. **从经验判断转向数据复盘**：让门店经营有据可依
3. **不只发现问题，更给出解决方案**：告诉门店"下一步可以怎么做"
4. **提升导购能力**：用真实接待数据驱动培训与成长
5. **激活滞销款**：通过搭配和陈列策略重新激活滞销商品
