# 季中OTB为什么总是失控：鞋服零售商品企划的核心矛盾与解法

## 核心数据

| 指标 | 数据 |
|------|------|
| 季中OTB采购金额偏离计划 | 15%以上 |
| 爆款识别信息滞后 | 7-14天 |
| 传统追单决策周期 | 7-10天 |
| 数据驱动追单周期 | 3-5天 |
| 有经验买手判断准确率 | 70%-75% |
| 第七在线AI系统尾货率改善 | 15%-20%（部分客户反馈） |
| 中型品牌决策复杂度 | 300店×3000SKU=百万级组合 |

## 三大核心矛盾

1. **信息更新频率 << 市场变化速度**：200家门店品牌，商品团队按周/月汇总，爆款起量后7-14天才被识别
2. **OTB预算分配粒度 ≠ 实际销售粒度**：季前按品类分配（"女鞋类800万"），季中需款式级追单决策
3. **多渠道库存结构不透明**：线上仓+线下门店+在途库存缺乏清晰系统支撑

## 关键洞察

> "OTB管理的难点从来不是'设一个预算上限'，而是'在信息不完整的情况下，持续做出最接近最优解的追单和减单决策'。"

## 对服装零售的适用性

- 动态OTB管理方法论可直接应用于商品企划
- 追单决策周期缩短方法论
- AI辅助商品管理的ROI量化参考（尾货率15-20%改善）
- 信息滞后7-14天的行业基准数据
