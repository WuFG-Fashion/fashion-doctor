# Streamlit 2026 全版本新特性深度总结 (v1.53 → v1.58)

> 来源：Streamlit 官方 Release Notes (https://docs.streamlit.io/develop/quick-reference/release-notes/2026)
> 采集日期：2026-06-14

---

## 架构变革：从 Tornado 到 Starlette

| 版本 | Starlette 状态 | 关键变化 |
|------|---------------|---------|
| v1.53 (2026-01-14) | 实验性 `server.useStarlette` | 新增 `st.App` ASGI入口点，支持自定义HTTP路由/中间件/生命周期钩子，可与 FastAPI 集成 |
| v1.57 (2026-04-29) | **正式默认** | 默认服务器从 Tornado 迁移到 Starlette/Uvicorn |

**Starlette 架构收益**：
- 更好的 ASGI 兼容性
- 可访问现代 Python 异步生态系统
- 底层服务器通过 `st.App` 暴露，支持高级配置
- `st.App` 新增 `secrets` 参数支持程序化传递密钥

## 性能优化

| 版本 | 优化 | 说明 |
|------|------|------|
| v1.53 | Spinner瞬态化 | Spinner不再包含在重运行元素刷新中，避免残留 |
| v1.57 | **Polars Arrow零拷贝** | Polars DataFrame直接转为Arrow格式，完全绕过Pandas，提升性能和类型保真度 |
| v1.58 | **`@st.fragment` 并行执行** | `parallel=True` 参数，片段并发运行，支持后台工作流 |

## st.dataframe 重大增强 (v1.56)

- 支持通过 `selection` 参数**程序化设置选中项**
- 新增 `"single-row-required"` 选择模式，始终保持一行选中
- 列配置新增 `alignment` 参数控制文本对齐
- 列可见性菜单**始终可见**
- 新增 `AudioColumn` / `VideoColumn` 列类型
- **支持 pandas 3.x**

## Widget 身份机制过渡 (v1.54+)

多数组件在有 `key` 时**仅基于 key 识别**，防止参数变化导致状态重置，涉及：
`st.dataframe`, `st.area_chart`, `st.bar_chart`, `st.line_chart`, `st.scatter_chart`,
`st.altair_chart`, `st.vegalite_chart`, `st.pydeck_chart`,
`st.date_input`, `st.datetime_input`, `st.radio`, `st.select_slider`

## 关键 API 增强

- `st.cache_data` / `st.cache_resource` 支持**会话级缓存作用域** (v1.53)
- `st.cache_resource` 新增 `on_release` 参数用于资源清理 (v1.53)
- `st.set_page_config` 支持配置侧边栏默认宽度 (v1.53)
- `st.Page` 支持外部URL链接 (v1.56)
- `st.Page` 支持 `visibility` 参数在导航菜单隐藏页面但保留路由 (v1.55)
- `st.container` 新增 `autoscroll` 参数 (v1.56)
- `st.link_button` 新增 `on_click` 回调 (v1.56)
- `st.selectbox`/`st.multiselect` 新增 `filter_mode` 参数 (v1.56)

## 对服装零售多品牌看板的意义

1. **Starlette 生产级部署**：v1.57 默认 Starlette/Uvicorn，可直接对接企业级 ASGI 中间件（认证/限流/监控）
2. **Polars 零拷贝**：Polars 数据管道直接渲染到 Streamlit，避免 Pandas 转换开销，适合超大SKU数据
3. **`@st.fragment` 并行**：多品牌 Dashboard 可并行加载各品牌数据，首屏速度提升
4. **`st.menu_button`**：品牌切换菜单增强交互
5. **`st.pagination`**：长列表 SKU 数据分页展示
6. **`st.bottom`**：固定底部按钮适合移动端零售看板
