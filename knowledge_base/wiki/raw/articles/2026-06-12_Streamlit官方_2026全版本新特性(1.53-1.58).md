## 1. 服务器架构：Tornado → Starlette（v1.53→v1.57）

**v1.53**：实验性支持 `server.useStarlette` 配置，推出 `st.App` ASGI 兼容入口
- 支持自定义 HTTP 路由、中间件、生命周期钩子
- FastAPI/Starlette 集成、OIDC 令牌在 `st.user.tokens` 中可用
- 支持 Snowflake 会话级调用者权限连接

**v1.57**：Starlette 成为默认 Web 服务器（替代 Tornado）
- 通过 Uvicorn 运行，ASGI 兼容，现代 Python 异步生态
- `st.App` 在 st 命名空间中可用，支持 `secrets` 参数程序化传递密钥
- **Polars 直转 Arrow**：完全绕过 pandas，提升性能和类型保真度

## 2. 并行执行：@st.fragment parallel=True（v1.58）

```python
@st.fragment(parallel=True)
def data_loader():
    # 后台加载数据，不阻塞 UI
    df = load_large_dataset()
    st.dataframe(df)
```

- 片段并发运行，实现后台工作流和响应式应用
- 不会阻塞主应用的其他片段

## 3. 新组件矩阵

### v1.57 st.bottom
固定在应用底部的容器，适用于聊天输入、工具栏和持久化控件。

### v1.56 st.menu_button + st.iframe
- `st.menu_button`：可自定义弹出容器的下拉按钮，用于菜单/工具栏
- `st.iframe`：嵌入外部 URL 或原始 HTML

### v1.56 DataFrame 增强
- `selection` 参数程序化设置选择
- `"single-row-required"` 模式：始终保持恰好一行被选中
- `AudioColumn` 和 `VideoColumn`：在数据框中直接播放音视频
- 列配置 `alignment` 参数控制文本对齐
- 支持 pandas 3.x

### v1.55 动态容器
- `st.tabs`、`st.popover`、`st.expander` 通过 `on_change` 参数触发重运行
- 配合 `key` 参数可程序化控制打开/关闭
- 控件新增 `bind` 参数：简化控件状态与查询参数同步

### v1.58 st.pagination
构建分页界面的原生组件，支持数据框分页。

## 4. 缓存与会话管理升级

**v1.53**：
- `st.cache_data` 和 `st.cache_resource` 支持**会话级作用域**
- `st.cache_resource` 新增 `on_release` 参数（关闭连接等资源清理）
- `BaseConnection` 全局或会话级连接作用域

**v1.54**：
- `.streamlit/config.toml` 文件创建后无需重启服务器
