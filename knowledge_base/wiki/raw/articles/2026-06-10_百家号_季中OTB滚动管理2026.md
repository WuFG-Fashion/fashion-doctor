# 季中OTB为什么总是失控：鞋服零售商品企划的核心矛盾与解法

> **来源**: 百家号, 2026-04-29
> **原文URL**: https://baijiahao.baidu.com/s?id=1863785638571331826

## 核心要点

1. 季中OTB偏离计划15%以上的三大核心矛盾: 信息更新滞后(7-14天)/预算分配粒度不匹配/多渠道库存不透明
2. 滚动OTB解法: 每周根据实际销售进度+当前库存+未来预测重新计算剩余OTB
3. 关键指标: 追单周期可从7-10天缩短至3-5天, 季末尾货率改善15-20%
4. AI系统支撑: 人工判断准确率70-75%, 系统可处理百万级"款式×门店×渠道"组合
5. 核心认知: OTB管理难点不是"设预算上限", 而是"持续做最接近最优解的追单/减单决策"

## 详细内容

### 三大核心矛盾

| 矛盾 | 描述 | 影响 |
|------|------|------|
| 信息频率 < 市场速度 | 按周/月汇总, 爆款识别滞后7-14天 | 缺货→流失→转化率下降 |
| 预算粒度 ≠ 执行粒度 | 品类级预算(如800万) vs 款式级决策(如追加3000双) | 预算用在次优款式上 |
| 多渠道库存不透明 | 线上仓+门店+在途库存流转不清 | OTB重复计算或漏算 |

### 滚动OTB方法

- **周期**: 每周一次
- **输入**: 实际销售进度 + 当前库存水位 + 未来销售预测
- **输出**: 每个品类/渠道的剩余可买金额重新分配
- **关键**: 不是"预算-已用", 而是基于真实数据的动态重新评估

### 三类必须打通的实时数据

1. **销售进度数据**: 哪些品类超速/落后? → 追单/减单决策
2. **库存结构数据**: 各品类/款式/渠道库存分布 + 周销率
3. **剩余可用OTB**: 前两者整合得出的真实可用金额

### SKU生命周期判断

| 阶段 | 特征 | 决策 |
|------|------|------|
| 导入期 | 刚上架 | 观察 |
| 成长期 | 周销率持续上升 | 追单黄金窗口 |
| 成熟期 | 周销率平稳 | 谨慎追单 |
| 衰退期 | 周销率下降 | 停止追单/清仓 |

### 关键数据指标

| 指标 | 数值 |
|------|------|
| OTB季中偏离率 | 15%+ |
| 传统追单周期 | 7-10天 |
| 数据驱动追单周期 | 3-5天 |
| 人工判断准确率 | 70-75% |
| 季末尾货率改善 | 15-20%(第七在线系统) |
| 中型品牌SKU×门店组合 | 百万级(300店×3000SKU) |

### AI系统价值

- 系统承担数据整合+初步决策建议, 商品团队专注判断和执行
- 常规决策覆盖面→人工无法企及水平
- 人的判断仍在: 新品类/新市场/异常销售波动
- 复盘频率: 每月→每周甚至每三天

> **注意**: 本文提及第七在线AI商品管理系统, 有推广倾向。但OTB方法论和矛盾分析框架具有独立参考价值。
