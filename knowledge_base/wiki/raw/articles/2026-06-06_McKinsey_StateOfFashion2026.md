# McKinsey State of Fashion 2026 报告核心发现

> 来源：McKinsey & Company / BoF Insights 2026-02
> 采集日期：2026-06-06

## 核心数据

### 经济环境
| 指标 | 数据 |
|------|------|
| 高管认为关税是2026最大议题 | **76%** |
| 关税导致服装成本上涨约 | **35%** |
| 预计2026年行业状况恶化的高管 | **46%**（+8pp vs 2025） |

### AI趋势
| 指标 | 数据 |
|------|------|
| AI被高管评为首要机遇 | **排名第一** |
| AI项目未能实现规模化落地 | **高达90%** |
| AI六大核心应用场景 | 预测需求、动态推荐、自动内容生成、广告优化、库存智能、规模化个性化 |

### 消费者行为
| 趋势 | 数据 |
|------|------|
| 二手时尚市场增速 vs 新品 | **2-3倍**（持续至2027） |
| 珠宝品类增速 vs 服装 | **约4倍** |
| 战略转向 | 从"折扣驱动销量"到"价值驱动忠诚度" |
| 电商进入 | **第三代"发现时代"**：内容+电商+社群 |

## 五大主题

1. **关税波动** — 全球供应链重新洗牌，地理多元化成为必需品
2. **AI规模化** — 从实验到落地，90%项目未能规模化的"90%困境"
3. **消费者价值重置** — 相关性、透明度、体验取代单纯折扣
4. **二手市场崛起** — 增速2-3倍于新品市场
5. **选择性国际化** — 跨境扩张收益超过品类扩张

## 对服装零售的启示

- 关税推高成本，国内品牌需关注供应链弹性和成本控制
- AI是第一优先级但90%项目无法规模化 → 数据基础是关键瓶颈
- 二手市场和新商业模式正在分流传统零售
