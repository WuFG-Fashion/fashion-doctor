# 买手店库存救命稻草：OTB落地全攻略

## OTB 核心公式

```
本月可采购额（OTB）= 本月销售成本 − 现有库存成本 ÷ 年周转次数
```

### 计算示例（女装买手店）

| 变量 | 取值 |
|------|------|
| 本月目标销售额（零售价） | 100,000元 |
| 定倍率 | 2倍 |
| 现有库存成本 | 80,000元 |
| 年周转次数 | 5次 |

| 步骤 | 计算 | 结果 |
|------|------|------|
| 第一步：计算销售成本 | 100,000 ÷ 2 | **50,000元** |
| 第二步：库存本月计划消化额 | 80,000 ÷ 5 | **16,000元** |
| 第三步：本月OTB | 50,000 − 16,000 | **34,000元** |

> 结论：本月所有新订货物，总采购价不能超过 34,000元。

## 动态OTB机制

- 月初OTB用完 → 卖出多少成本 → 释放多少补货额度
- 卖1件（成本100元）→ 释放100元补货额度
- 卖得快、补得多；卖不动、不补

## 五条执行铁律

1. **OTB定死，绝不超支** — 再好看、再爆款、档口再催，超预算不拿
2. **全部按成本计算** — 拿货看成本，卖货看售价，口径统一
3. **只补动销款，不补感觉款** — 卖得快的多补，不动销的立刻停补
4. **滞销不清，OTB不降** — 库存越乱，可拿货额度越少
5. **每周复盘一次** — 卖多少、剩多少、能补多少

## 关键参数参考

| 参数 | 买手店参考值 |
|------|-------------|
| 定倍率 | 2～2.5倍 |
| 年库存周转次数 | 4～8次 |
| OTB复盘频率 | 每周一次 |

## 适用场景

- 中小型买手店
- 组货店
- 服装品牌零售
- SPA模式品牌
