# 数据要素流通六大变化与高质量数据集建设（十五五）

## 核心要点

1. 2026 快消零售数智创新峰会（2026-07-08），清华孟庆国《智能体时代数据要素流通利用的六大变化》："十五五" 以"数据要素 + 人工智能"双引擎驱动，强化"基础供给、全方位赋能、发展生态"三大核心任务；"数智化" = 数字化 + 数据智能。
2. **高质量数据集**类比"米其林餐厅食材供应链"——非单纯追求规模/质量/完整性/多样性/合规，还要满足**场景针对性、动态适配性**；为大模型训练和智能体开发打造"备好切好的食材"。
3. **六大变化**：①数据形态：传统结构化表串 → 被赋予语义/知识/明确指令的多模态形态；②价值释放：从分析预测 → 生成/推理/执行；③数据流通：从交易数据本身 → 提供模型能力和智能链条；④利用主体：从人读数据 → 机器理解数据；⑤安全治理：从数据本身 → "数据-模型-应用"全链路治理；⑥价值计量：走向词元（Token）计量方式。
4. 关键转向：不再"把数据流出去"，而是"把数据转化为可调用、可治理、可计量、可分润的智能化生产力"。
5. 零售数据资产化浪潮 2026 达沸点，每一次点击/浏览/加购成为可确权、估值、变现的核心生产要素。

## 企业级智能体三大流派

| 流派 | 核心特征 | 代表 |
|------|----------|------|
| 无界务实派 | "决策-执行"闭环，不受 API 生态限制，直接操作软件界面 | 实在 Agent |
| 生态集成派 | 深度绑定自有云/SaaS 生态 | 腾讯云 / Salesforce Agentforce / Microsoft Copilot |
| 灵活开发派 | 高度灵活开发框架或零代码平台 | Dify / 字节 HiAgent |

## 对服装零售数据资产化的启示

- 选型第一步：回答"你的数据散落在多少系统？核心业务系统是否有 API 接口？"——多品牌服装集团 ERP/POS/CRM/WMS 高度异构，需优先打通数据孤岛。
- 高质量数据集建设应面向具体场景（如智能补货、会员推荐、售罄预测），而非泛化规模，与数据资产管理"面向 AI 数据供给"维度一致。
