# raw/ — 原始资料层

> **规则**：此目录下的所有文件 AI 只读不写。只有你可以增删修改。

## 目录说明

| 目录 | 用途 | 支持格式 |
|------|------|---------|
| `articles/` | 网页剪藏、PDF 导出的 Markdown | .md |
| `reports/` | 行业报告、财报原文 | .md, .pdf |

## 使用方式

1. 把文章/报告丢进对应目录
2. 对 AI 说：`kb-ingest raw/articles/xxx.md` 或 "把这篇文章加入知识库"
3. AI 会自动提取实体、概念、数据，写入 wiki/
4. 原始文件保留不动，供未来回溯

## 命名建议

- 文章：`YYYY-MM-DD_来源_标题.md`，如 `2026-05-11_证券时报_太平鸟2025年报分析.md`
- 报告：`YYYY_机构_报告名.pdf`，如 `2025_艾瑞咨询_中国男装市场报告.pdf`
