# 原始资料 — Nautica 中国代理权结构性变更：ABG 终止联亚授权、联亚起诉、上海荟众接手

来源：
- Authentic Brands Group (ABG) 公告与媒体转述（2026-06 / 2026-07-28）
- 联亚集团（Lianya Group）诉讼披露 / 纽约州最高法院立案记录（2026-07-01）
- 商业媒体转述（WebSearch 综合 2026-08-19）

关键事实：
- 终止授权：品牌方 ABG 拟于 2026-06-30 前终止联亚集团对 Nautica 与 Spyder 的授权（licence），并向联亚索取相关费用。
- 法律行动：联亚集团于 2026-07-01 在美国纽约州最高法院（Supreme Court of the State of New York）对 ABG 提起诉讼，就终止授权及索费争议提出主张。
- 新运营伙伴：2026-07-28，ABG 宣布上海荟众（Shanghai Huizhong）成为 Nautica 与 Spyder 在中国内地及香港、澳门市场的核心运营伙伴。
- 原有基数（已入库，核对用）：联亚运营下 Nautica 中国门店约 124 家（2026 春夏口径，见 2026-08-17 源页）。
- 结构含义：同一品牌方在同一区域同时推进"终止旧代理 + 指定新运营伙伴"，且旧代理已进入诉讼，属代理权交接期的高风险状态（库存归属、门店续租、会员数据迁移、员工安置均待明确）。
- 待验证：诉讼进展与是否和解；124 家门店在交接中的去留；Spyder 与 Nautica 是否同步切换；上海荟众的授权范围与期限。
