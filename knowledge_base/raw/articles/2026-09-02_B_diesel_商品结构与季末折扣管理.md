# Diesel 商品结构与季末折扣管理（2026-09-02 采集）

## 检索来源
1. Diesel 产品组合拆解（丹宁核心 + 1DR bag hero 款、价格阶梯、季末 markdown、奥莱分区、授权品类）
2. FW26 树脂压褶丹宁 / 3D 丹宁 / 50,000 档案物件大秀
3. 授权品类矩阵（L'Oréal 香氛、Marcolin 眼镜、Fossil 手表）

## 核心事实
- **产品组合结构**：
  - 核心：丹宁（品牌根基）+ **1DR bag hero 款**（单款引爆单品，承接话题与引流）。
  - 价格阶梯：入门配饰（引流）→ core 丹宁（主销）→ 皮革/鞋履/runway capsules（形象与毛利），形成"低-中-高"三档。
  - 季末策略：集中 markdown（统一大促时点）保护正价售罄率——"正价期不轻易打折，季末集中出清"。
  - 奥莱分区：折扣商品进奥莱分区，与正价渠道物理隔离，防止价格体系混乱。
- **授权品类**：L'Oréal 香氛 / Marcolin 眼镜 / Fossil 手表——非核心品类用授权模式扩品类面（低投入、吃授权费+品牌曝光）。
- **FW26 大秀**：树脂压褶丹宁、3D 丹宁工艺 + 50,000 档案物件场景——用秀场维持品牌叙事与溢价（媒体评价销量数据趋好）。

## 可操作要点
- hero 款策略：单款引爆（1DR bag）承担引流与话题，主力款承接转化——"话题款 + 主销款"双轨。
- 价格阶梯管理：入门-主销-形象三档配比，形象款保毛利与品牌调性。
- 季末集中 markdown + 奥莱隔离：保护正价期售罄率，避免"天天打折"侵蚀品牌与毛利（对照卡宾 27.9% 深折扣困境）。
- 授权扩品类：非核心品类（香氛/眼镜/表）授权外包，避免库存与运营成本。
