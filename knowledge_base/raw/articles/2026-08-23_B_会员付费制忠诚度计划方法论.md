# 付费会员制与忠诚度计划方法论（B轮 通用方法论·会员与VIP运营）

> 来源：WebSearch 聚合（Costco / 山姆中国 / 唯品会 公开报道与财报解读，2026）
> 采集日期：2026-08-23（B轮 通用方法论：会员与VIP运营域）
> 置信度：媒体估算（付费会员经营数据多来自品牌自宣与媒体拆解，非审计披露）

## 核心信息

### 1. 付费会员制的核心财务逻辑：会员费 = 高利润营收
- Costco：会员费占净利润约 70%；2026 财年 Q2 会费收入约 13.55 亿美元，全球付费会员约 8210 万，续费率 90%+。
- 山姆中国（2025）：销售约 1400 亿+，付费会员约 1070 万，卓越会员续卡率 92%。
- 唯品会 SVIP：付费会员贡献 >50% 线上销售额。
- 启示：付费会员制本质是"前端低毛利获客、后端会员费变现"，会员费通常是零售企业最稳定、利润率最高的收入来源，与"靠商品差价赚毛利"的免费积分模式有结构性差异。

### 2. 续费率是忠诚度计划的"生命线"指标
- 高续费率（90%+）意味着会员体系已嵌入用户生活习惯，而非靠促销拉新。
- 分层会员（普通 / 卓越）通过差异化权益（如山姆卓越会员的免费洗牙、视力检查、运费券）提升高价值用户续费意愿。

### 3. 付费会员 vs 免费积分会员的本质差异
- 免费积分会员：靠消费累积积分换券，用户迁移成本低、忠诚度弱，易被竞品促销挖走。
- 付费会员：用户"已付费"产生沉没成本心理，到店/复购意愿更强，且平台可借会员费反哺供应链与选品。
- 风险点：强制入会（如名创优品曾被约谈）违反个保法，付费门槛需与真实权益价值匹配，否则引发舆情。

### 4. 对 Fashion Doctor 的适用口径
- 服装零售付费会员尚处早期，多数品牌仍以"免费注册会员 + 等级权益"为主；可关注"付费会员"作为高净值用户分层与 LTV 提升的进阶手段。
- 评估品牌会员体系时，应区分"会员规模（注册数）"与"付费/活跃会员质量（续费率、ARPU）"，后者才是忠诚度计划的真实健康度。
