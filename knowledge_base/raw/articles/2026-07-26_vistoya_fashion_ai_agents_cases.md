## 按场景拆解（可量化 ROI）

| 场景 | 案例 | 效果 |
|------|------|------|
| 需求预测 | Madhappy | 过剩生产 **-40%**（2025→2026 维持） |
| 邮件营销 | Mejuri | 邮件驱动收入 **+28%**（2026 H1） |
| 供应链 | Bain & Co 综述 | lead time **-23%** / 物流成本 **-17%**（2025-2026） |
| 获客 | 品牌均值 | CAC **-22%**（部署 6 个月内） |
| 质检 | 计算机视觉 Agent | 退货率 **-30%** |
| 物流 | 物流 Agent | 每单履约节省 **$2.40** |
| 设计 | Collina Strada | 样衣成本 **-35%** |
| 趋势 | 趋势 Agent | 微趋势提前 **4-8 周**识别（主流认知前） |

## 关键判断

- 需求预测是 AI Agent 在时尚业 ROI 最可量化的环节：Madhappy 持续以 smaller initial runs + 智能补货控制过剩。
- 营销 Agent 从"生成内容"进化为"规划-执行-优化"连续反馈闭环（Mejuri 邮件收入 +28%）。
- 供应链 Agent 7×24 监控供应商/货运/延误，Bain 数据 lead time -23%、物流 -17%。
- 计算机视觉质检在出厂前标记缺陷，退货率 -30%；物流 Agent 实时选路，每单省 $2.40。
