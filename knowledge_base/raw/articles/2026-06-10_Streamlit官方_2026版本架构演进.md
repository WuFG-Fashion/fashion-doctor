# Streamlit 2026版本架构演进（v1.53→v1.57）

> **来源**：Streamlit官方Release Notes (docs.streamlit.io/develop/quick-reference/release-notes/2026)
> **采集时间**：2026-06-10
> **原始URL**：https://docs.streamlit.io/develop/quick-reference/release-notes/2026

## 摘要

Streamlit在2026年发布5个版本（v1.53→v1.57），完成两大里程碑：**架构从Tornado迁移到Starlette/Uvicorn**（ASGI兼容），以及**Polars DataFrame零拷贝Arrow支持**。新增st.bottom、st.menu_button、st.iframe等核心组件，废弃4个experimental API。

## 重大架构变更

### Tornado → Starlette/Uvicorn 迁移

- **v1.57.0 (2026-04-29)**：Starlette正式成为默认Web服务器
  - 更好的ASGI兼容性
  - 性能提升
  - 可访问现代Python异步生态系统
  - 底层通过`st.App`暴露，支持高级配置
  - 相关Issue: #439, #861

- **v1.53.0 (2026-01-14)**：Starlette以实验性功能引入
  - 新增`server.useStarlette`配置选项
  - `st.App`作为ASGI兼容入口点：自定义HTTP路由、中间件、生命周期钩子
  - 与FastAPI/Starlette等Python Web框架集成

## 新增API组件

| 版本 | 新功能 | 说明 |
|------|--------|------|
| 1.57.0 | `st.bottom` | 固定在应用底部的容器，适用于聊天输入、工具栏 |
| 1.57.0 | `:shimmer[]` | Markdown动画加载文本指令 |
| 1.57.0 | `st.App.secrets` | 程序化传递secrets，不依赖secrets.toml |
| 1.56.0 | `st.menu_button` | 可定制弹出容器的下拉按钮 |
| 1.56.0 | `st.iframe` | 嵌入外部URL或原始HTML |
| 1.55.0 | 动态容器 | st.tabs/st.popover/st.expander支持on_change |
| 1.55.0 | Widget bind | 简化与查询参数同步 |
| 1.53.0 | `st.logout` | 从身份提供者登出 |
| 1.53.0 | `st.user.tokens` | 暴露OIDC ID和访问令牌 |

## 性能优化

| 版本 | 优化 | 影响 |
|------|------|------|
| 1.57.0 | **Polars直接转Arrow** | 完全绕过pandas，性能+类型保真度提升 |
| 1.56.0 | pandas 3.x支持 | 兼容最新版pandas |
| 1.53.0 | 缓存会话作用域 | st.cache_data/cache_resource限定到会话级别 |
| 1.53.0 | cache_resource.on_release | 资源释放清理回调 |

## API废弃

| 版本 | 废弃项 | 替代方案 |
|------|--------|---------|
| 1.57.0 | st.plotly_chart的spec/use_container_width/sharing | 移除 |
| 1.57.0 | _get_websocket_headers | st.context.headers |
| 1.54.0 | st.experimental_get/set_query_params | st.query_params |
| 1.54.0 | st.experimental_user | st.user |

- v1.57.0: `server._async` 配置项移除，由新架构自动处理
- v1.57.0: Streamlit在pip包中内置AI agent技能和模板
