# Retail Inventory Optimization: The Complete Guide for DTC and Omnichannel Brands

> 来源：Green Retail Consulting https://www.greenretailconsulting.com/blog/retail-inventory-optimization-the-complete-guide-for-dtc-and-omnichannel-brands
> 采集：2026-08-05（Round B / L2_05 商品企划）

## 核心结论

库存是多数零售与 DTC 品牌资产负债表上最大的单项；营收 2000 万美元以下的品牌普遍是"被动管理"而非"战略管理"。

**Green Retail Consulting 为客户实现的平均库存优化改善幅度为 28%**——靠的不是软件大改造，而是更好的 OTB 计划、更聪明的分货、以及诚实的 SKU 精简。

## 库存管理失当的四类真实成本

| 问题 | 代价 |
|------|------|
| 畅销款断货 | 收入永久流失；获客成本已付出，顾客转向竞品 |
| 滞销 SKU 积压 | 现金占用无法再投资；仓储成本累积；最终被迫促销，训练顾客等打折 |
| 需求预测失准 | 基于去年数据的采买错过趋势迁移、季节波动与营销投入对售罄速度的影响 |
| 跨渠道分货失衡 | 货在错的地方；某仓某码积压而另一门店断码；Shopify 与 Amazon 争抢同一批货且无协调 |

## 六项核心健康基准（Key metrics every retail brand should track）

| 指标 | 衡量内容 | 健康基准 |
|------|---------|---------|
| Sell-through rate 售罄率 | 期间内已售 / 已收货比例 | **季末 80%+** |
| Weeks of supply (WOS) 供给周数 | 按当前销售速度现有库存可支撑周数 | **多数品类 6–8 周** |
| Inventory turn 库存周转次数 | 一年内库存售出并补充的次数 | **DTC 服装 4–6 次/年** |
| In-stock rate 在库率 | 任一时点可售 SKU 占比 | **在售货盘 95%+** |
| Markdown rate 折扣销售率 | 打折产生的销售额占比 | **健康毛利品牌低于 20%** |
| Open-to-buy (OTB) | 给定周期可用采购预算 | **按销售预测编制，而非凭直觉** |

## OTB 框架：大多数品牌缺失的一环

OTB 是财务规划工具，基于销售计划、库存目标与既有承诺，告诉你在给定周期究竟能买多少货。

- 这是大型零售组织的标准做法
- 在营收 1000 万美元以下的 DTC 品牌中几乎完全缺失
- **构建基础 OTB 模型不需要复杂软件**：一张结构良好、每周更新的表格，就能交付企业级规划工具 80% 的纪律性

## 库存优化六步实操流程

1. **审计当前 SKU 表现**：按售罄率与毛利贡献排序全量货盘。**多数品牌会发现 20%–30% 的 SKU 贡献了 70%–80% 的利润**，其余在稀释现金、注意力与库存容量。
2. **精简货盘**：识别持续低效 SKU（低售罄、高退货、低毛利），明确决定退出/改造/继续。精简释放出的 OTB 预算用于加码真正有效的部分。
3. **按品类建立需求预测**：从品类级历史售罄率出发，按计划营销投入、季节变动与已知趋势信号调整。预测不需要完美，只需优于凭感觉，并随季推进持续更新。
4. **按周期设定 OTB 目标**：用销售预测与期初库存位置，计算每个计划周期可收货量而不超出 WOS 目标。这就是采买约束线——每一笔采购决策都要对照这条天花板评估。
5. **执行每周复盘**：库存优化是持续过程而非季节性动作。每周复盘 SKU 级售罄率、在库率与 WOS，让补单与调拨决策在还来得及行动时发生。
6. **提前规划折扣策略**：折扣应是库存战略的计划组成部分，而非恐慌反应。**每季开始时就定义清楚：售罄率达到什么阈值触发折扣、折扣深度多少、通过哪个渠道执行。** 计划性折扣保护毛利。
