## DuckDB 1.5.0 (Variegata) 核心特性

### 1. 全新 CLI 客户端
- 全新配色方案（暗色/亮色模式），与文档统一
- 动态提示符：显示当前数据库和 schema (如 `my_database.my_schema D`)
- `.tables` 命令：列出所有 catalog、schema、表和列
- `DESCRIBE` 语句查看表结构
- `_` 下划线访问上一次查询结果

### 2. VARIANT 类型 (JSON 原生支持)
- 原生 VARIANT 数据类型，替代 JSON 扩展
- 支持嵌套结构、半结构化数据的高效查询
- 1.5.4 修复了 VARIANT 过滤条件错误读取的 bug

### 3. GEOMETRY 类型 (空间支持)
- 内置 GEOMETRY 类型（不再依赖 Spatial 扩展）
- Parquet 统计修剪支持原生几何类型

### 4. 其他关键特性
- Parquet Row Group Append：增量写入性能提升 10-100x
- Iceberg 扩展：MERGE INTO 支持、分区表 INSERT/UPDATE、ALTER TABLE
- jemalloc 静态链接：Linux 默认启用，简化与其他动态扩展的共存

## Quack 成为核心扩展 (v1.5.3)

- Quack 是 DuckDB 的 **客户端-服务器协议**，通过 HTTP 让多个 DuckDB 实例共享同一数据库
- v1.5.3 起 Quack 成为**核心扩展**：任何 DuckDB 客户端首次使用时自动安装和加载
- DuckDB 2.0 (2026 秋季) 计划推出生产就绪版本

## DuckLake 1.0 (湖仓最后一公里)

## 服装零售多品牌场景映射

| 特性 | 服装零售用例 |
|------|-------------|
| CLI 动态提示符 | 多品牌数据库切换管理（如 `peacebird_db D USE sales_schema`） |
| VARIANT 类型 | 各品牌 JSON 格式会员标签/埋点数据的统一分析 |
| Quack 客户端-服务器 | 多个 Streamlit Dashboard 共享同一 DuckDB 分析库 |
| Parquet Row Group Append | 每品牌增量写入日销售 Parquet，性能 10-100x |
| DuckLake | 替代传统 Hive Metastore，零运维湖仓目录 |
| Iceberg MERGE INTO | 品牌级别增量更新全量表（无需全量重写） |
| GEOMETRY 类型 | 门店选址分析、商圈热力图 |
