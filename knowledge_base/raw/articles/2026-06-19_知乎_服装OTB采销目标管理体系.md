## 核心摘要

OTB管理包含商品销售计划、销售跟踪、滚动库存管理三部分，以销售计划为龙头，销售跟踪为纽带，链接销售与采购，使销售与采买、库存管控达到动态平衡。

## OTB核心公式

```
补充采购量 = 总采购量 - 已采购量
总采购量 = (已实现销量 + 未来销量) / 预计售罄率
```

- 季中/季尾售罄率不同，须参考历史数据
- 已上市款式补货量 = 可销售周数 × 每周销量 - 当前可用库存

## 关键方法论

### 销售预测三要素
1. 前期业绩表现分析
2. 天气因素修正（骤然变冷/迟迟不冷的影响）
3. 品类结构变化追踪（消费者风向变化）

### 库存管控策略
- 提前30-60天进行品类季度库存限额管控
- 品类存在库存缺口 → 补充采购（新品或已上市补货）
- 品类无库存缺口 → 严格控制采买
- 季末严格控制库存总量及结构

### 动态调整原则
- 销售与库存"一体两面"：销售引领库存，库存影响销售
- 品类占比实际与计划差异 → 调整采买结构
- 天气导致品类结构变化（如大衣减/羽绒增）

## 关键指标

| 指标 | 说明 |
|------|------|
| 预计售罄率 | 分季中/季尾两档 |
| 品类库存缺口 | 触发补充采购 |
| 可销售周数 | 计算补货量 |
| 品类季度库存限额 | 提前30-60天设定 |
