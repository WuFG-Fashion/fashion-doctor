# 第七在线：季前商品计划制定流程——从经营目标到上市规划落地

> **来源**：第七在线 7thonline (https://www.7thonline.com.cn/hangyeganhuo-2534.html)
> **采集日期**：2026-07-11
> **分类**：L2_05 商品企划

## 核心论点

商品计划的本质不是预测未来，而是把经营目标转化为可执行的商品动作。季末的经营结果，本质上是季前商品计划质量的体现。

## 五步流程

### 第一步：目标拆解——六层链路

```
销售目标 → 渠道目标 → 品类目标 → 波段目标（含上市时间+波段销售占比）
→ 波段内OTB预算 → SKU数量与款深
```

**关键原则**：波段是OTB管理的基本单位。同一个品类不同波段的交期压力、款式结构、快反窗口完全不同。SKU是波段内OTB计算的输出结果，不是起点。

**拆解示例**（10亿年目标）：
- 春季承担2.5亿 → 女装2亿 → 连衣裙3500万
- 连衣裙3500万拆为：春一波2000万(2月上市)、春二波1000万(3月上市)、促销波500万(4月上市)

### 第二步：商品结构规划（三维度）

| 维度 | 内容 | 作用 |
|------|------|------|
| 品类结构 | T恤/衬衫/裤装/外套各自销售份额 | 避免品类竞争或需求空缺 |
| 价格带结构 | 低价引流、中价走量、高价利润+品牌 | 拓宽消费者选择空间 |
| 款式结构 | 引流款/核心款/利润款/形象款 | 波段差异化配置 |

### 第三步：OTB预算规划

**OTB双重作用**：① 采购限额（预算约束线）② 动态管理机制

**正确拆解路径**：
```
年度OTB → 产品季OTB → 品类OTB → 波段OTB（关键层级，不可跳过）
→ 首单OTB（期货，约70%-80%）+ 快反OTB池（约15%-25%，全季保留不提前锁定）
```

**常见错误**：品类OTB直接跳到供应商OTB，跳过了波段层级，导致无法追踪波段预算消耗，也无法触发快反决策。

### OTB与上市时间联动

以春季第一波为例：计划2月1日上市，供应商平均生产交期10周

**关键原则**：波段OTB额度必须在下单截止日前完成授权——**OTB决策必须在订货会启动前至少2-3周完成**。订货会是执行下单的场合，不是决定买多少的场合。

### 第四步：上市规划——倒推链路

从计划上市时间出发，根据供应商生产交期、物流时间、仓库处理时间倒推每个关键动作的最晚完成时间。OTB授权时间是最上游约束。

**致命问题**：OTB授权时间与下单截止日脱节→OTB还在走审批，供应商交期窗口已关闭→货晚到30天→整个销售季失败。

### 第五步：计划评审

评审围绕可量化指标，不围绕"款式是否好看"的定性讨论。任何修改都不能动摇经营目标（销售/毛利/库存）。

## AI如何重构季前商品计划

第七在线AI商品决策系统能力：

| 阶段 | AI能力 |
|------|--------|
| 目标拆解 | 基于历史销售数据自动生成波段销售预测，拆解至波段OTB建议区间 |

| 计划执行协同 | 商品计划/采购订单/供应链进度实时联动，OTB变更自动触发采购授权状态更新 |
