# State of Apparel Merchandising Planning 2026（RetailNorthstar，2026）

> 来源：retailnorthstar.ai/resources/research/state-of-apparel-planning-2024（RetailNorthstar 研究，2026）
> 主题：商品企划成熟度、规模阈值、尺码曲线、单一计划模型、中端市场工具缺口

## 核心发现

### 单一计划模型
高效团队把 OTB、assortment、buy quantities 放在同一模型（非需反复对账的链接文件），数据同源。

### 尺码曲线基于"卖了的"而非"买的"
高绩效买手按 **sold%（卖出占比）** 而非 bought%（买入占比）做尺码分布——这一转变本身即持续提高售罄率。

### 季中可见性（48 小时）
高效团队在 data availability 后 **48 小时内** 有售罄数据，足以在销售窗口内行动（非周报周期）。

### 规模阈值
- 50–150 SKU：靠纪律可管理对账开销
- **>200–250 active SKUs**：对账负担开始超出团队承受（分析工作被淹没）
- 平台采用触发：小错误累积（对账误差/错过季中信号/季前截止压力）+ 团队成长（2人→3人协同成本超连接系统成本）

### 中端市场缺口
- 企业级商品企划平台：实施 12–24 月，总成本中小品牌难承受
- ERP 分配模块不解决季前 assortment/OTB 规划；PLM 解决产品开发非规划
- 缺口在"精细表格"与"企业平台"之间，由 apparel-native 中端工具填补（周级实施/2-5人规划团队/OTB+assortment+buy 一体）

### 运营缺口量化（$10M 品牌/季）
| 缺口 | 成本 |
|------|------|
| 无 OTB 框架 | $150K–$300K 超买 |
| 错误尺码曲线 | $80K–$150K 尺码残次 |
| 无追单能力 | $100K–$200K 赢家漏单 |
| 手动分配 | $50K–$100K 错配 |
| 无复盘 | 错误年复一年 |
| **合计** | **$380K–$750K/季**；修复可提毛利 **4–8pp** |

## 关键洞察

- 规模阈值 200-250 SKU 与 kb_benchmarks `sku_abc` 的"20% A 类 SKU 贡献 65% 销售"互补：绝对 SKU 数量到阈值后管理复杂度非线性上升。
- 单一计划模型（OTB/assortment/buy 同源）是 [[动态OTB管理]] "持续运行模型"的落地形态。
