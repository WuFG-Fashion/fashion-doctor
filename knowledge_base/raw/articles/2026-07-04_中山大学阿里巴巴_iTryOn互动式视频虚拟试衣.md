# 中山大学&阿里巴巴 iTryOn：互动式视频虚拟试衣

> 来源：腾讯新闻 / ICML 2026 论文（PMLR Vol.306）

> 发布时间：2026-05-27

## 项目背景

中山大学深圳校区 × 阿里巴巴淘宝天猫事业群联合研究，发表于ICML 2026（首尔）。首次提出"互动式视频虚拟试衣（Interactive VVT）"任务定义，以及对应框架 **iTryOn**。

## 核心创新

当前VVT技术只能做"模特穿上衣服走秀"，无法处理人主动拉扯、拉拉链、卷袖子等互动。iTryOn填补了这个空白。

### 三层技术架构

1. **3D手部先验（空间指引）**：用HaMeR模型重建手部三维网格，避免2D骨骼的深度信息丢失。关键设计：不用深度图（会信息泄露），只用纯粹的手部几何。

2. **A-RoPE动作感知旋转位置编码（语义指引）**：带时间戳动作描述 + 放大系数k=4，精确对齐"第N帧=拉拉链"的语义映射。

3. **AC loss动作感知约束损失函数**：互动帧额外加权惩罚（λ=0.5），解决"稀疏事件学习困难"（互动帧仅占视频1-5%）。

### VVT-Interact数据集

- 首个互动式VVT大规模数据集
- 5292个高质量视频-服装配对（训练5160/测试132）
- 6类互动：调整领口、调整下摆、卷/放袖子、穿/脱、揪拉、其他（拉拉链等）
- 标注：Qwen-VL-32B自动标注 + 形态学平滑处理

## 核心结果

| 指标 | iTryOn | 最佳竞品 |
|------|--------|---------|
| **ISR (互动成功率)** | **61%** | CatV?TON 48.38% |
| 配对VFID | **22.46** | CatV?TON 26.99 |
| SSIM | **0.78** | - |
| FVD | **380.56** | MagicTryOn 431.79 |
| LPIPS | **0.12** | - |

- iTryOn仅2B参数，14B的MagicTryOn得分12.20 → 小参数大效果
- 非互动场景同样领先：VFID 8.43 vs MagicTryOn 12.20

## 局限

1. 不懂服装语义：无法判断衣服有没有拉链，对T恤做"拉拉链"会产生哑剧效果
2. ISR只能判断语义成功，不能量化物理准确性
