# OTB 商品财务规划方法论（B轮 通用方法论·商品企划）

> 来源：WebSearch 聚合（鞋服零售 Merchandise Planning 手册、Shopify OTB 指南、MFP 商品财务计划，2026）
> 采集日期：2026-08-23（B轮 通用方法论：商品企划域）
> 置信度：第三方数据（OTB 框架为零售通用标准，具体系数按品牌校准）

## 核心信息

### 1. OTB（Open-to-Buy）公式
- OTB =（计划销售 + 计划 markdown + 计划期末库存）− 计划期初库存。
- 三种规划口径：①零售口径（按吊牌价，适合时尚/季节性品牌，对齐收入与 markdown）；②成本口径（按现金流，适合成长品牌控working capital）；③数量口径（按件数，适合高量/多店）。成熟零售商常混合（零售 OTB 定策略 + 成本 OTB 控支票）。

### 2. MFP（商品财务计划）→ OTB 翻译链
- 销售目标 → 分解（按货期/品类/渠道/门店级别）→ MFP 翻译成采购预算（OTB），同步锁定毛利目标、期末库存目标、初始加价率（IMU）。
- 断点：商品部与财务部"各说各话"常在 MFP 环节割裂，需三方（商品/销售/财务）对齐。

### 3. 货品结构配比（在 OTB 框架内）
- 主力款 50-60% / 引流款 15-25% / 形象款 10-20%。
- 形象款与引流款虽毛利低，但对客流与品牌认知不可替代；结构直接影响整体毛利率。

### 4. SKU 宽度与深度管理
- 宽度 = 品类/款式数；深度 = 单款库存量。减少 SKU 泛滥（合并历史滞销色/码）可简化补货、提升周转。
- ABC 分类：A 类约 20% SKU 贡献 70-80% 营收（每周盘点/精准预测）；B 类 30% SKU / 15-20% 营收；C 类 50% SKU / 5-10% 营收（季度盘点/考虑淘汰）。

### 5. 对 Fashion Doctor 的适用口径
