# Bain - Agentic AI in Retail: How Autonomous Shopping is Redefining the Customer Journey

> **来源**: https://www.bain.com/insights/agentic-ai-in-retail-how-autonomous-shopping-redefining-customer-journey/
> **日期**: 2026-05-14
> **采集日期**: 2026-06-22

## 核心发现

AI代理正在接管消费者购物流程，从推荐、比价、寻货到寻找替代品，影响从研究到购买的每一个环节。

### 关键数据

| 指标 | 数据 |
|------|------|
| 从ChatGPT开始购物 | 约8%美国消费者 |
| 使用GenAI进行产品比较 | 约30%美国消费者 |
| AI推荐流量占比 | 高达25%推荐流量，但不到总流量1% |
| ChatGPT购物推荐流量增长 | 过去一年翻倍以上 |
| Amazon Rufus增量年化销售 | 近120亿美元 |
| Rufus月活增长 | +115% |
| Rufus用户购买可能性 | 高出60% |
| 消费者信任自有代理 vs 第三方 | 3倍 |
| 零售媒体站内广告支出 | 约65%投放于站内 |

### 三大战略回应

1. **深挖"客户护城河"**：独家产品、忠诚度积分、增值服务（如百思买Geek Squad）
2. **重新定义零售媒体变现**：元数据成为新广告资产，"赞助代理推荐"、"代理影响费"、API费用
3. **赢得推荐，保留控制权**：水印/分层访问保护数据、守住履约和结账环节

### 对时尚零售的启示

- 探索式购物是核心战场，代理可完全颠覆品牌推荐
- 元数据优化成为新型SEO
- 独家性与服务是护城河
- 品牌忠诚度弱化，结果导向为王
