# 服装订货会精准策划方法论

> **一句话**：订货会四阶段闭环+波段订货法+黄金三角款结构+售罄率KPI体系，从"凭感觉"到"算精准"。

## 核心要点

1. 波段订货：先导10-15%/主力60-70%/补充15-20%
2. 款型三角：引流10-20%/利润60-70%/形象10-20%
3. 订货量公式：同期销量×增长率±偏差±活动±渠道
4. 售罄率目标：春夏75-85%/秋冬70-80%
5. 四阶段闭环：会前→会中→会后→上市后

## 关键数据

| 指标 | 目标 |
|------|------|
| 先导款占比 | 10-15% |
| 主力款占比 | 60-70% |
| 售罄率(春夏) | 75-85% |
| 售罄率(秋冬) | 70-80% |
| 核心尺码占比 | 70% |

## 结论

订货会精准策划的价值在于把「凭感觉订货」转成可复算的配额结构：波段订货（先导 10-15% / 主力 60-70% / 补充 15-20%）与款型三角（引流 10-20% / 利润 60-70% / 形象 10-20%）。这两个比例的作用不是精确预测，而是给订货会现场提供一个「偏离即需解释」的约束，防止全凭爆款直觉压货。
