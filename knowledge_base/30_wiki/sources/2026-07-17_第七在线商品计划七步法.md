# 第七在线 商品计划七步法 MFP+OTB完整链路

> **一句话摘要**：第七在线发布中国鞋服商品计划完整手册——8步流程+12核心KPI+AI重构（预测准确率WMAPE<15%），覆盖从MFP到OTB滚动的全链路。

> **来源**：第七在线（7thonline），2026-06-05

## 核心要点

1. **MFP→OTB翻译**：商品财务计划将销售目标翻译成采购预算，锁定毛利/库存/IMU
2. **货品结构532**：主力款50-60%、引流款15-25%、形象款10-20%
3. **12个核心KPI**：GMROI（≥2.0为优秀）为终极指标
4. **AI决策加速**：从周级→小时级，预测准确率WMAPE从25-35%→<15%

## 详细内容

### 8步全流程

| 步骤 | 内容 |
|------|------|
| ① 数据回顾与市场洞察 | 历史+外部趋势 |
| ② 销售目标设定与分解 | 货期/品类/渠道/门店 |
| ③ MFP与OTB计算 | 销售→采购预算翻译 |
| ④ 品类规划与货品结构 | 532比例 |
| ⑤ 波段计划与上市节奏 | 3-6波段 |
| ⑥ SKU规划与选款采购 | 颜色/尺码/首单 |
| ⑦ 配货与补货执行 | 首配+补货触发 |
| ⑧ 在季追踪与OTB滚动 | 周级动态调整 |

### 中国三大特殊挑战
1. 双货期制度（同推两套计划/秋冬跨财年）
2. 期货+快反双轨（分层OTB管理）
3. 经销商穿透（50-80%门店库存不透明）

## 结论

第七在线这份商品计划手册把中国鞋服商品企划拆成8步流程+12个核心KPI，并以GMROI（≥2.0为优秀）为终极指标，方法论的完整度在国内供应商材料中属上乘。其真正有洞察的部分是「中国三大特殊挑战」：双货期制度（同推两套计划/秋冬跨财年）、期货+快反双轨、经销商穿透（50-80%门店库存不透明）——这三点解释了为什么国际通用的MFP/OTB框架直接搬到中国会失效，也是国内品牌商品企划难做的结构性原因。AI重构部分给出WMAPE从25-35%压缩到<15%、决策周期从周级到小时级的目标，量级合理但属目标值而非实测值。
