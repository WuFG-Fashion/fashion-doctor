# Streamlit 2026 全版本新特性(v1.53-v1.58)

> **一句话摘要**：Streamlit 2026 完成 Tornado→Starlette 架构迁移，新增 parallel fragments/pagination/st.bottom/st.menu_button 等 20+ 生产级组件，Polars Arrow 零拷贝直转，支持 pandas 3.x，AI 代理技能内置。

> **来源**：Streamlit 官方 2026 Release Notes（https://docs.streamlit.io）
> **最后更新**：2026-06-12

## 核心要点

1. **架构迁移**：v1.53 实验→v1.57 默认 Starlette/Uvicorn 替代 Tornado，ASGI 兼容，`st.App` 入口
2. **并行执行**：v1.58 `@st.fragment(parallel=True)` 支持片段并发，后台工作流不阻塞 UI
3. **新组件**：`st.bottom`(固定底部)、`st.menu_button`(弹出菜单)、`st.iframe`(嵌入外部)、`st.pagination`(分页)
4. **Polars 零拷贝**：v1.57 Polars 直转 Arrow，完全绕过 pandas，提升类型保真度
5. **AI 代理**：v1.57 捆绑 AI 代理技能，v1.58 `streamlit skills` CLI，`:shimmer[]` 动画文本

## 详细内容

### 版本时间线

| 版本 | 日期 | 核心 |
|------|------|------|
| v1.53 | 2026-01-14 | Starlette实验、会话级缓存 |
| v1.54 | 2026-02-04 | 图表配色、热加载配置 |
| v1.55 | 2026-03-03 | 动态容器(on_change)、控件bind |
| v1.56 | 2026-03-31 | menu_button/iframe、pandas 3.x |
| v1.57 | 2026-04-29 | Starlette默认、st.bottom、Polars零拷贝 |
| v1.58 | 2026-05-28 | Parallel Fragments、pagination |

### 服务器架构变化
- Tornado → Starlette (Uvicorn): ASGI兼容、现代Python异步生态
- `st.App` ASGI入口：自定义路由/中间件/生命周期钩子
- FastAPI/Starlette 集成、OIDC 令牌支持

### 缓存与状态
- 会话级缓存作用域 (`st.cache_data`/`st.cache_resource`)
- 资源释放回调 (`on_release`)：关闭连接
- 控件身份机制重构：仅基于 key 确定身份

### DataFrame 生产增强
- `selection` 参数程序化选择
- `"single-row-required"` 模式：始终选中一行
- AudioColumn/VideoColumn：数据框中播放音视频
- 列配置 `alignment` 对齐控制
- pandas 3.x 支持

### 破坏性变更
- v1.54: 移除 `st.experimental_*` 系列
- v1.57: 移除 `st.plotly_chart`/`st.vega_lite_chart` 弃用参数
- v1.58: 移除 `element.add_rows` 和 LangChain 回调

## 结论

本页与 [[2026-06-14_Streamlit_2026v1.53-1.58全版本新特性]] 覆盖同一主题，**属同源双页**。相比另一页，本页在**技术细节上更完整**：不仅列出「什么变了」，还分组说明了架构、缓存与状态、DataFrame、破坏性变更四类影响。

**对本库最有直接价值的仍是三项**：
- **Starlette/Uvicorn 默认（v1.57）+ `st.App` ASGI 入口**：可挂载自定义路由与中间件，**这意味着 Streamlit 看板可以接入企业级认证**（本库若需做权限分级或 SSO，这是可行的技术路径）；
- **`@st.fragment(parallel=True)`（v1.58）**：多品牌看板并行加载；
- **Polars 直转 Arrow 零拷贝（v1.57）**：消除 Pandas 中间层。

**本页独有的高价值内容是「破坏性变更」清单**：
- **v1.54 移除 `st.experimental_*` 系列**
- **v1.57 移除 `st.plotly_chart` / `st.vega_lite_chart` 的弃用参数**
- **v1.58 移除 `element.add_rows` 和 LangChain 回调**

**这三条对已有系统的升级决策至关重要** —— **升级 Streamlit 版本时若使用了上述 API，代码会在运行时失败而非给出弃用警告。** **本页明确列出这些移除项，比只讲「新增了什么」的发布说明更有实用价值。** **对本库这类依赖 Streamlit 构建的看板，升级前必须先扫描代码中的 `experimental_*` 与 `add_rows` 使用点。**

**「控件身份机制重构：仅基于 key 确定身份」是另一条需要注意的变更**：**它修复了「同一组件在不同位置被识别为不同实例」导致的状态重置问题，但也意味着依赖旧行为（位置参与身份判定）的代码可能出现状态维持异常。** **这类变更在升级时表现为「看起来能用但状态行为变了」，最难排查。**

**缓存与状态部分（会话级作用域 + `on_release` 资源释放回调）对多品牌看板的资源管理有实际意义**：**`on_release` 让连接/句柄在会话结束时被正确释放**，**对本库这类需要同时连接多个品牌数据库（卡宾、太平鸟）的场景，可避免连接泄漏。**

**需注意两页 Streamlit 材料在「版本时间线」的细节上存在差异**（如对 v1.54/v1.55 的亮点描述不同），**且均未标注该差异原因**。**建议对照官方 Release Notes 核验后合并。**
