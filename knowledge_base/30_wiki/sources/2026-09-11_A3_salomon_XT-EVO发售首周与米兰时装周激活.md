## 核心要点
- **首周声量（新数据点）**：小红书"XT-EVO"关键词**首页 40 条结果几乎全部产生于这半个月内**，从专柜实拍到街头上脚——被球鞋媒体定性为"萨洛蒙今年推新里密度最高的一波"；渠道侧武汉门店（9/8）、长沙柜员（9/9）自发晒款，B 站开箱称"新王登基"（置信度：媒体估算）。
- **产品定性：鞋面重造、大底复用 XT-6（关键口径）**：三处改动全部在鞋面——① **液态橡胶叠层/cage 鞋面**（保留 XT-6 大网眼 + 外层流动感橡胶，官方称"雕塑感先锋外观"）；② **歪斜鞋带走线**（斜置绑带系统，拉紧即内侧包裹压缩）；③ **SensiFit® 贴合系统全覆盖鞋身**（比 XT-6 的压胶挡泥板更整体化）。**大底与 XT-6 完全一致**（博主 RocTsui/FRESH 口径），官方给这些升级的定位是"面向**先锋潮流群体**的机能球鞋"——**XT-EVO 是潮流生活鞋，不是越野跑鞋的迭代款**（置信度：媒体估算）。
- **中国定价未公开（渠道弹性）**：截至 2026-09-09 **萨洛蒙中国官网没有公布全国统一标价**——"现在谁说国内一定是某个数，都是替品牌先嘴"（置信度：媒体估算）。
- **海外三口径（不可直比）**：微博海外渠道口径 **$190**；KicksUnderCost（美国）口径 **$200**（三色同价）；Media Key（意大利）口径 **€190**——差异来自区域/渠道定价，引用须标区域（置信度：媒体估算）。
- **首发 SKU（可核对）**：L45404200（全黑）· L45419100（Black/Fiery Red）· L49177900（Alloy/Castlerock），均为男码（置信度：媒体估算）。
- **米兰时装周激活（新事件）**：**9/25** Salomon Store Brera（Corso Garibaldi 12）改造为沉浸式体验空间，按 campaign 视觉宇宙引导参观者认识 XT-EVO；特别嘉宾 **Veronica Yoko Plebani**（残奥运动员/演讲者/内容创作者，长期推动"运动作为发现、自由与包容的工具"）——把 Sportstyle 从球鞋圈推向时装周体系（置信度：媒体估算）。
- **Kith 合作谱系**：XT-EVO 是 Kith（Ronnie Fieg）与 Salomon 继 XT-Voyager 2 / XT-4 / XT-6 / XT-Whisper 之后的最新一支；8/4 Ronnie Fieg 上脚先行曝光，品牌把新鞋型的"第一次零售登场"交给 Kith 探路（置信度：媒体估算）。

### 2. "鞋面重造 + 大底复用"的产品企划逻辑
- 保留：XT-6 大底 + Quicklace 快速系带 + agileCHASSIS™ 稳定结构 + Mud Contagrip 外底（**性能底台零改动**）。
- 重造：鞋面材质（液态橡胶 cage/叠层）+ 鞋带几何（斜置）+ 包裹结构（SensiFit 全覆盖）。
- 媒体定性："值不值取决于你付的是**设计费的账**还是**性能费的账**"——即 XT-EVO 卖的是设计语言溢价，不是性能增量。
- 对照：8/24-25 官方口径为"速度张力转化为大胆鲜明的设计语言"，与"潮流生活鞋"定位自洽。

### 3. 米兰激活与 Sportstyle 叙事升级
- 米兰站选择 Brera 门店（非秀场）做"沉浸式体验"——**门店即媒介**：借米兰时装周的城市流量为单店导流，成本远低于办秀。
- 嘉宾选择（残奥运动员而非流量明星）延续 Salomon 的"真实运动者"叙事，与其专业越野基本盘不冲突——与 09-05 源"杨祐宁以普通跑者身份出战 UTMB"同一逻辑。
- 与 [[hoka_one_one]] 的对照：HOKA 走"专业跑者社群（Run Club/Run It Again）+ 精选店"，Salomon 走"潮流联名（Kith/Goodbai）+ 时装周"——**同赛道两种品牌资产路径**。

## 结论
1. **XT-EVO 是"底台复用 + 鞋面重造"的平台化开发范本，对中国品牌产品企划可直接迁移**：性能底台（XT-6）不动，只换鞋面材质/系带几何/包裹结构，就能造出"新鞋型"——开发周期短、模具/测试成本低、性能风险为零，且能用同一底台反复派生潮流款。这正是国内品牌做"专业线底台 → 潮流款派生"时可照搬的最小成本路径（前提：原底台已有性能口碑）。
2. **"中国官网不公布统一标价"是一种主动的渠道价格治理，不是遗漏**：给线下精选店/抖音旗舰店留出区域与渠道价差空间，避免全网比价击穿门店毛利；代价是消费者信息不透明、比价摩擦上升。对照国内品牌常见做法（全网统一定价 + 严格控价），这是**用价格弹性换渠道积极性**的另一种选择，值得作为"上新期定价策略"的对照样本。
3. **首周只有"声量"没有"销量"——不能把热度当业绩**：小红书首页 40/40 条集中在半月内、门店自发晒款、B 站开箱"新王登基"，全是**声量指标**；萨洛蒙官方至今未给任何售罄/销量口径。**引用时须严格区分"声量密度"与"首销实证"**，这与 09-05 源"Kith 联名款先行售罄"属不同层级证据。
4. **9/25 米兰激活说明 Salomon 正在把 Sportstyle 从"球鞋圈"上移到"时装周体系"**：与 08-19~09-05 库内"专业越野 + 潮流化变现"双叙事一致，但潮流侧权重在继续加码——风险面（库内 09-02 源已记录"专业稀释/配货争议/伯希和平替"三大隐忧）随之上升，需持续监测专业客群口碑。
