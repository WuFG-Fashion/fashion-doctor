# 第七在线商品计划完整手册

> **一句话摘要**：第七在线发布中国鞋服零售商品计划七步完整手册，从数据回顾到配货执行，含货品结构模板（主力50-60%/引流15-25%/形象10-20%）。
> **来源**：2026-07-19_第七在线_商品计划完整手册.md
> **最后更新**：2026-07-19

## 核心要点

1. 七步流程：数据回顾→销售目标→MFP/OTB→品类规划→波段计划→SKU规划→配货补货
2. 货品结构：主力款**50-60%**/引流款**15-25%**/形象款**10-20%**
3. 波段：每货期**3-6个波段**，核心价值是"用商品新鲜感替代折扣"
4. 直播电商需波段计划与直播排期深度协同

## 详细内容

### 七步流程

| 步骤 | 关键产出 |
|------|----------|
| 1. 数据回顾 | 基线数据 |
| 2. 销售目标 | 按货期→品类→渠道→门店分解 |
| 3. MFP/OTB | 锁定毛利/库存/IMU |
| 4. 品类规划 | 货品结构设计 |
| 5. 波段计划 | 3-6个波段上市节奏 |
| 6. SKU规划 | 颜色/尺码/首单/期货vs快反 |
| 7. 配货补货 | 首次分配+补货触发 |

### 货品结构模板

| 类型 | 占比 | 说明 |
|------|------|------|
| 主力款 | 50-60% | 销售主力 |
| 引流款 | 15-25% | 带来客流(毛利较低) |
| 形象款 | 10-20% | 品牌认知(不可替代) |

## 结论

本页是商品计划七步流程的完整版（数据回顾→销售目标→MFP/OTB→品类规划→波段计划→SKU规划→配货补货），其中两个结构参数最具落地价值：货品结构模板（主力款50-60%/引流款15-25%/形象款10-20%）与波段节奏（每货期3-6个波段）。后者的核心逻辑被明确表述为「用商品新鲜感替代折扣」——这解释了为什么波段规划不只是上市节奏问题，而是折扣率的前置控制手段。
