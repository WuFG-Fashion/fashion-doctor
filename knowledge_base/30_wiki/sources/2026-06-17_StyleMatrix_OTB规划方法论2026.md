# StyleMatrix OTB规划方法论2026

> **一句话摘要**: 现代OTB=计划销售额+期末库存+降价金额−期初库存−在途订单，双重计量（金额+单位）+OTR协同+AI趋势发现。
> **来源**: StyleMatrix 2026-06

## 核心要点
1. OTB核心公式：**OTB = 计划销售额 + 计划期末库存 + 计划降价金额 − 期初库存 − 在途订单库存**
2. 双重计量：金额OTB（高价值品类）+ 单位OTB（畅销基本款，防断货）
3. OTB必须与OTR（预期收货）对齐，避免空货架和过剩库存
4. 现代OTB：AI需求预测→品类/款式级精准目标+自动化补货预警+供应链同步
5. ⚠️ 本文偏方法论，未提供具体售罄率/周转天数KPI阈值

## OTB计算公式详解
| 要素 | 说明 |
|------|------|
| + 计划销售额 | 预期销售目标 |
| + 计划期末库存 | 期末希望保留的库存水平 |
| + 计划降价金额 | 促销和清仓预留额度 |
| − 期初库存 | 当前已有库存 |
| − 在途订单库存 | 已下单但尚未到货 |

## 结论

本页给出了 OTB 的**标准计算公式：OTB = 计划销售额 + 计划期末库存 + 计划降价金额 − 期初库存 − 在途订单库存**，这一表述比 [[2026-06-19_服装OTB采销目标管理体系]] 的采购量公式更完整，因为它**显式包含了两个容易被漏掉的项目：计划降价金额（预留的促销空间）与在途订单库存（已下单未到货）**。

漏掉「计划降价金额」的后果是采购计划偏乐观——**没有为促销让出预算，实际只能靠追加降价来清库存，而追加降价往往发生在季末，折价幅度更大**。漏掉「在途订单库存」的后果是重复采购——**账上没有的货不表示没有买**。这两项是 OTB 实操中最常见的两个错误来源。

**双重计量（金额 OTB + 单位 OTB）** 是本文最有技术含量的判断：高价值品类用金额 OTB（关注资金占用），畅销基本款用单位 OTB（关注断货风险）。**因为这两类品类的失败模式不同**——高价值品类怕积压（资金占用大、折价损失重），基本款怕断货（销量稳定、缺货即确定损失）。用单一口径管理所有品类，必然在其中一类上出错。

「OTB 必须与 OTR（预期收货）对齐」这一点揭示了 OTB 的常见失效原因：**预算有了、采购也下了，但到货节奏与销售节奏错位**——空货架（该到没到）与过剩库存（提前到货）可以同时存在于同一品类。
