# 第七在线库存优化 — 五根因+三层协同+六核心指标

> **一句话摘要**：中国鞋服平均库存周转180天（比国际高30%），五根因（预测/结构/OTB/配货/孤岛）+三层协同（事前/事中/事后）+六核心指标（GMROI≥2.5等），AI将优化从"事后诊断"升级为"事前预防"。

> **来源**：10_web/articles/2026-07-15_第七在线_库存优化终极指南三层协同.md
> **最后更新**：2026-07-15

## 核心要点

1. 中国服装零售企业平均库存周转180天，比国际平均水平高约30%
2. 五大根因：需求预测偏差(WMAPE>30-40%)/货品结构失衡/OTB失控/配货失误/渠道孤岛
3. 三层协同治理：事前规划→事中管控→事后修正
4. 六个核心指标：库存周转/售罄率/GMROI/库销比/动销率/尾货率
5. GMROI是最综合的单一指标：同时考察毛利率和库存周转率，中位数2.5

## 详细内容

### 五大根因

| 根因 | 量化表现 |
|------|----------|
| 需求预测偏差 | WMAPE >30-40% |
| 货品结构失衡 | 低毛利款卖光、高毛利款积压 |
| OTB采购失控 | 实际采购量系统性超计划 |
| 配货补货失误 | 好门店配少/差门店配多 |
| 渠道数据孤岛 | 多渠道库存无法统一优化 |

### 三层协同框架

**事前规划**：AI需求预测(WMAPE→<20%) / OTB期货75-85%+快反15-25% / 主力款50-60%+引流15-25%+形象10-20% / 3-5波段

**事中管控**：周度实销vs计划 / 第4周售罄<20%触发预警 / 动态调拨 / 越早干预毛利损失越小

**事后修正**：货期末前1-2月启动折扣(7-8折) / 季后复盘→输入下季模型

### 六核心指标

| 指标 | 行业基准 | 优秀目标 |
|------|----------|----------|
| 库存周转天数 | 180天 | 60-90天 |
| 季末售罄率 | — | ≥75% |
| 货期末售罄率 | — | ≥85% |
| GMROI | 1.86-3.01（中位数2.5） | ≥2.5 |
| 月动销率 | — | ≥70% |
| 尾货率 | 部分门店18% | <15% |

### AI重塑库存优化

- AI预测：SKU×门店×波段级
- AI滞销预警：上市第1周即监控
- AI调拨：分钟级全渠道最优方案
- AI动态OTB：周度自动更新

### 中国特有挑战

双货期交叉/期货快反双轨/多平台分仓/经销商不透明/直播大促冲击

## 结论

这份指南把库存治理拆成可执行的三层：事前（AI需求预测WMAPE<20%、期货75-85%+快反15-25%、货品结构532、3-5波段）→事中（周度实销对计划、第4周售罄<20%触发预警、动态调拨）→事后（货期末前1-2月启动7-8折、季后复盘反哺模型），并给出六核心指标（库存周转180天→60-90天目标、季末售罄≥75%、GMROI≥2.5、月动销≥70%、尾货率<15%）。最有判断价值的是它明确了「越早干预毛利损失越小」这一时间价值原则——第4周识别滞销与季末清货，毛利损失量级完全不同。中国特有挑战（双货期交叉/期货快反双轨/多平台分仓/经销商不透明/直播大促冲击）是该框架必须本地化适配的原因。
