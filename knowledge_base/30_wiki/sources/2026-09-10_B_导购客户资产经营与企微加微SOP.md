# 导购客户资产经营与企微加微运营 SOP（B轮·2026-09-10）

> **一句话摘要**：导购的"客户资产经营"是从"加微 → 打标签 → 三次触达 → 社群栏目 → 任务化激励"的完整动作链——核心前提是**把客户从导购个人微信迁到企业微信**（解决"人走客户走"）；可核对案例值：门店企微添加率约 **90%**、老客销售额 **+22%**、触达转化率 **13%–16%**、导购人均业绩月增约 **4,000 元**。
> **来源**：10_web/articles/2026-09-10_B_导购客户资产经营与企微加微SOP.md（有赞案例中心 / 丽晶软件 / 群应用 SCRM / 有赞门店私域 聚合）
> **置信度**：媒体估算（私域 SCRM 服务商与单品牌案例口径，**不可外推为行业基准或自身目标线**）
> **brand_specific**：false（行业通用方法论，双链至 concept 不链品牌）

## 核心要点
- **第一性判断：客户资产必须留在品牌侧，不能留在导购个人微信**——服装店最大的结构性问题就是"导购流动大，人一走微信里的老客也跟着走"；案例（lululemon × 丽晶"企业微信 + 导购无忧"）把私域客户资源全部搬到企微，**彻底解决"人走客户走"**。
- **加微最佳时机 = 人最满意的一刻**：试衣间出来照镜子、或买单结账的瞬间；话术示例"您今天选的这款特别衬您气质…我们有专属会员福利群，优先分享新品资讯和穿搭技巧…"。
- **一次扫码三沉淀（"33 原则"）**：多码合一——加微信 + 关注公众号 + 注册会员一次完成；钩子如"扫码加微信立减 3 元"、"扫码进群领 50 元无门槛券"。
- **包裹卡是线上加微的最强入口**：包裹卡引导加微转化率 **10%–15%**。
- **加微后必须自动承接**：**新客 3 次必触达**——第 1 次加微当天（欢迎语 + 新人券 + 爆款推荐）→ 第 2 次 1–3 天（使用/保养指南 + 售后说明）→ 第 3 次 7 天内（关联商品 + 小额复购券，测试二次购买意愿）。
- **标签五类**：风格偏好（通勤/休闲）、常穿尺码、消费档次、到店频率、品类倾向——来源是"导购聊两句补偏好 + 系统自动记行为"；标签的终点是**精准触达而非一刀切群发**。
- **导购任务化 + 激励数字化**：系统自动分发触达任务、话术素材与搭配内容，结合完成情况与销售结果设动态激励——**降门槛比加考核更有效**。

## 详细内容

### 1. 加微动作设计（把"收银动作"改成"加微动作"）

| 环节 | 做法 |
|---|---|
| 时机 | 试衣间照镜子 / 买单结账瞬间（人最满意、最愿意听一句） |
| 门店物料 | 收银台、货架、桌贴统一放二维码；多码合一（加微 + 公众号 + 注册会员一次完成） |
| 钩子 | "加微信立减 3 元 / 送小零食"、"进群领 50 元无门槛券" |
| 线上入口 | 店铺首页、详情页、**包裹卡（转化率 10%–15%）**、小红书/抖音评论区与直播口播 |
| 承接 | 系统自动发欢迎语 + 新人券，引导"关注公众号查看券""进群领更多福利" |

**自动化 SOP 模板**：加微当日新人礼包 → 1–3 天使用指南 → 7–30 天复购提醒 → 唤醒关怀。

### 2. 新客 3 次必触达（锁住关系）

| 次序 | 时点 | 内容 |
|---|---|---|
| 第 1 次 | 加微当天 | 欢迎语 + 新人券 + 店内爆款推荐 |
| 第 2 次 | 1–3 天 | 使用/保养指南、售后服务说明，顺带强调"有问题微信找我" |
| 第 3 次 | 7 天内 | 按首单品类推一个关联商品 + 小额复购券，测试二次购买意愿 |

### 3. 打标签：从"加了人"到"分得清"

- **标签五类**：风格偏好（通勤/休闲）、常穿尺码、消费档次、到店频率、品类倾向（爱买上衣还是裤子）。
- **用途**：分清"谁近期要买、谁只是随便逛"——"通勤、常来、月薪族"标签的职场装上新优先推；"只逛不买"的别硬发券，先养着。
- **门店维度标签**也常用："XX 门店-午高峰客/晚餐客"，便于按门店投放不同活动。
- 顾客画像在每次交易后持续完善，形成正向循环。

### 4. 社群运营 SOP

- **按人群建主题社群**（宝妈群、上班族群、穿搭群等），而非一个群塞所有人。
- **每周固定 2–3 个栏目**：新品预告 / 搭配建议 / 使用教程 / 店长答疑。
- **内容配比 80% 内容 + 20% 轻促销**——群不能只发广告。
- **分层做福利**：新客 → 离店 1–3 天发二单立减券；在店常客 → 每月囤货日/会员日、多件多折；高价值会员 → 专属客服、预约优先权、节日礼，**少打折、多营造尊贵感**，鼓励提前锁单或预储值。

### 5. 可核对案例数据（服务商口径）

| 案例 | 关键指标 | 数值 |
|---|---|---|
| LIME 莱茵（中淑女装，客单 2,000–4,000 元，百余家店） | 门店顾客企微添加率 | 约 **90%** |
| 同上 | 包裹卡好友沉淀率 | 约 **3%** |
| 同上 | 老客销售额整体提升 | 约 **+22%** |
| 同上 | 月度首单转化率 | 约 **16%** |
| 同上 | 老客分层运营触达转化率 | **13%–16%** |
| 同上 | 导购人均业绩月增 | 约 **+4,000 元** |
| 同上 | AI 工具月贡献销售额 | 近百万元 |
| UR（轻奢快时尚，300+ 门店） | 导购任务系统驱动线上营销 | 一季度线上带货近 **10 万件**，千万级线上业绩增量 |

### 6. 老带新（把老客变成获客渠道）

- **筛选**：复购 ≥2 次、常在群里互动/评价的顾客 → 打"KOC/团长候选"标签，单独建群/企微标签便于统一发任务与素材。
- **机制**：老客带新客进群或加微，**新客首单减 X 元，老客得积分/代金券/实物小礼**；或设"老客拼团价/内购价"，只在微信发起，老客分享专属海报。
- **素材**：总部准备"3 句就能转发"的标准文案、产品卖点图、真实案例截图——**素材可用性决定老带新的执行率**。

> ℹ️ **基准核对**：①本页"企微添加率约 90%"与 kb_benchmarks.membership.member_coverage=0.713（会员覆盖率）为**不同指标**（企微好友添加率 vs 会员覆盖），非矛盾，但 90% 为单品牌案例值不写入基准；②"老客销售额 +22%"与 kb_benchmarks.membership 各复购率档位不同维度（销售额增幅 vs 复购率），不构成冲突；③本页与 [[2026-09-08_B_导购流失率与客户资产保护]] 为同一问题的两面——09-08 讲"客户资产**保护**（归属规则、防带走）"，本页讲"客户资产**获取与经营**（加微、标签、触达 SOP）"，**先有获取再有保护**，两页互补不重复；④"新客 3 次必触达"与 [[2026-09-08_B_会员标签体系与自动化营销旅程2026]] 的 MA 旅程（D1/D3/D7）节奏同构，可交叉复用。

## 结论
1. **"客户资产留在谁手里"是导购管理的第一性问题**：私域放在导购个人微信 = 资产随人流失；搬到企业微信才把"导购的能力"转化为"品牌的资产"——**加微率这个指标本身就该算在导购考核里**，它是后续所有复购动作的前提。
2. **加微是动作设计问题，不是意愿问题**：把加微绑定在"试衣间照镜子 / 结账瞬间"两个高满意度时点 + 多码合一 + 明确钩子，比反复开会强调"要多加微"有效得多；**包裹卡 10%–15% 的转化率说明线上入口的性价比被普遍低估**。
3. **触达的节奏比内容更重要**：加微当天 → 1–3 天 → 7 天内的三次触达节奏，本质是"在客户还记得你的窗口期内建立第二次接触"，错过 7 天窗口后唤醒成本显著上升（与 [[sleeping_member_reactivation]] 的唤醒 ROI 逻辑一致）。
4. **对 Fashion Doctor 的落地含义**：本页可落成"导购客户资产 SOP"三件套——①加微话术与钩子卡 ②新客三次触达自动任务（1/3/7 天节点）③标签五维字典；指标侧建议在导购看板增加"加微率 / 企微好友数 / 绑定会员贡献销售额"，与会员看板打通。
