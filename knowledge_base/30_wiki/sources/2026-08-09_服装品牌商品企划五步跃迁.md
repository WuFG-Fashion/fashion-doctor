# 服装品牌商品企划五步跃迁

> **一句话摘要**：从经验到战略的五步跃迁，3+3+3+3 滚动波段使首单 70%→40%、售罄 +8–12pp、净利 +3–5pp。
> **来源**：toutiao.com/article/7659258016688062986（WebSearch 2026-08-09，Round B / L2_05）
> **最后更新**：2026-08-09

## 核心要点

1. **品类角色评价**：心智 / 规模 / 利润 / 形象 / 搭配，分类管理资源优先级。
2. **价格带规划**：2–3 个核心锚点，避免"中段价格带过宽"两头不讨好。
3. **3+3+3+3 滚动波段**：首单占比 **70%→40%**、整体售罄 **+8–12pp**、折扣深度 **-5–10pp**、净利 **+3–5pp**。
4. **OTB 滚动决策日历**：每周追/缩单 **±20%**、每月品类纠偏 **±10%**、每季结构复盘。
5. **分货与店群管理**：货品到对的地方，最后一公里精细化。

## 关键数据

| 指标 | 变化 |
|------|------|
| 首单占比 | 70% → 40% |
| 整体售罄率 | +8–12pp |
| 折扣深度 | -5–10pp |
| 净利率 | +3–5pp |
| OTB 周调整幅度 | 单款 ±20% |
| OTB 月纠偏 | 品类 ±10% |

## 结论

本页把商品企划从「经验驱动」到「战略驱动」的跃迁量化为可验收的五步：核心机制是「首单收缩 + 快反补充」——首单占比由 70% 降至 40%，把采购风险敞口砍掉近一半，同时依靠 3+3+3+3 的滚动波段持续补充，最终达成整体售罄率 +8–12pp、折扣深度 -5–10pp、净利率 +3–5pp。其关键设计是 OTB 的双层纠偏机制：单款周调整幅度 ±20%、品类月纠偏 ±10%，使企划从「一次性买断决策」变为「持续滚动的纠偏过程」。

## 前沿

待验证：首单 70%→40% 的切换需供应链快反能力同步到位（30–45 天返单周期），若快反产能不足则首单收缩会直接造成断码缺货——落地前应先核验快反产能占比。
