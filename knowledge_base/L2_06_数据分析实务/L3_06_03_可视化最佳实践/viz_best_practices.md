## 1. 图表选择指南

| 分析目的 | 推荐图表 | 不推荐的图表 | 原因 |
|----------|----------|--------------|------|
| 时间趋势 | 折线图 / 面积图 | 饼图 | 无法展示时序关系 |
| 占比构成 | 饼图 / 环形图 / 堆叠柱状图 | 单纯表格 | 直观性不足 |
| 对比排名 | 条形图 / 横向柱状图 | 3D柱状图 | 歪曲数据真实比例 |
| 分布情况 | 直方图 / 箱线图 | 饼图 | 分类过多导致不可读 |
| 相关性 | 散点图 / 气泡图 | 表格 | 难以发现规律 |
| 地域分布 | 地图热力图 | 纯文字列表 | 缺乏空间感 |

## 3. Streamlit 图表最佳实践

```python
# ✅ 推荐写法
import plotly.express as px
fig = px.bar(df, x='shop', y='sales', 
             title='各店销售额',
             color_discrete_sequence=['#1f77b4'])
fig.update_layout(margin=dict(l=0,r=0,t=30,b=0))
st.plotly_chart(fig, use_container_width=True)

# ❌ 避免写法
st.pyplot()  # 除非必须用matplotlib
fig.update_layout(width=800)  # 不要固定宽度
```

---

## 4. 响应式设计要点
- 所有图表 `use_container_width=True`
- 表格数据超过10行时启用分页或虚拟滚动
- 手机端适配：字体≥12px，图表高度自适应
- KPI数字卡片：一行最多4个

---

## 5. 常见错误清单
- ❌ Y轴不从0开始（夸大差异）
- ❌ 3D饼图（难以准确判断比例）
- ❌ 颜色过多（>7种颜色难以区分）
- ❌ 图表无标题/坐标轴无标签
- ❌ 数据未排序就画条形图
- ❌ 时间轴不均匀（缺失数据点未标记）
