## 五、过程中的技术问题与修复

### 5.1 段 3 JSON 裸换行（阻塞 → 已修）

- **现象**：`_b7_check.py 3` 报 `json.decoder.JSONDecodeError: Invalid control character at line 3 column 130`。
- **诊断路径**：先排除 CRLF（实测 `CR: 0 LF: 412`），再打印 `repr(s[170:200])`，确认字符串值内部存在**裸换行 LF**。
- **根因**：写 JSON 时 `c`/`l`/`f` 字段值中的换行**未转义为 `\n`**。
- **修复**：逐字符扫描（跟踪 `instr` / `esc` 状态），**仅在 JSON 字符串值内部**把裸 `\n` 替换为 `\\n`，再 `json.loads` 验证落盘。
- **复验**：PASS。

### 5.2 段 4 写入截断（阻塞 → 已修）
