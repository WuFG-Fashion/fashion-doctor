## 四、最终结论

### 能区分能力的指标

| 指标 | 区分度 | 原因 |
|------|--------|------|
| **复购率** | ⭐⭐⭐⭐⭐ | TOP3持续比全员高3-7pp |
| **新开卡占比** | ⭐⭐⭐ | TOP3更依赖老客（占比<50%） |
| **客单价趋势** | ⭐⭐⭐ | 长期全员更高，TOP3靠量取胜 |

### 无法区分能力的指标

| 指标 | 原因 |
|------|------|
| **TOP10关联率** | 差距太小（±3pp），受商品结构影响 |
| **VIP订单率** | 几乎100%，无区分度 |
| **高价值占比** | 全员为0%（无正价商品） |
| **客单价/连带件数** | 长期来看全员反而更高 |

### 明星导购冠军公式

```
TOP3成功 = 高订单量 + 高复购率 + 宽SKU覆盖
```

**李志婕的核心能力**：243个SKU × 22.7%复购率
